V5 结构与规范
· 层级（唯一权威）：底部导航 仪表盘 │ 高频 │ 交易；高频 下分 实盘/模拟，交易 下分 实盘/模拟。
· 环境切换控件（.envtabs）：App 栏正下方，44dp 高，两段式，中缝 1px 分隔；每个按钮内自带该环境的权益简值与涨跌，切换前即可比较。
· 身份色：实盘 = #ef4444 红；模拟 = #8b5cf6 紫。切换控件、状态条、徽标、横幅、危险按钮全部同色，形成强条件反射。
· 同一套页面结构复用：高频(实盘/模拟) 与 交易(实盘/模拟) 各自是同一布局换环境变量；落地时由 env 参数驱动，不写两套组件。
· Agent 决策链中立：它被两个环境共用，因此不放在任何一个环境下，放在「交易」模块内的关系视图（1.7 / 1.8），并在分叉点画出两个落点。
· 流式渲染压力策略：缓冲上限 200 行、100ms 合帧、自动滚动 + 上滑冻结、点击行看 raw 原文。
· 数值为 mockup 示意；节点名/分组/四态/边健康取自 backend/services/agent_wall.py，接口 /api/agent-wall/state|tail。
