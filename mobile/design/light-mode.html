AlphaArena · 日间模式设计 V6 日间 / 夜间 / 跟随系统

此前只有夜间模式。本稿把主题做成一套语义令牌 × 三档开关：令牌名不变，只换值； 开关三档 —— 跟随系统（默认）/ 日间 / 夜间。 浅色不是深色「减淡」，而是按光环境重定对比度基准（下面逐个令牌给了理由）。

--bg
#f6f8fb
不用纯白做页面底：纯白刺眼，且卡片浮不起来
--card
#ffffff
卡片纯白 + 细边 + 轻投影，层次靠"白压灰"而非"亮压暗"
--card-2
#f1f5f9
卡内次级块（stat / 输入 / 表头）
--border
#d6dee8
浅色下边框是主要分隔手段，不能太淡
--profit
#059669
盈利绿压深：夜间那个 #00dc82 在白底上几乎看不见
--live
#dc2626
实盘红 / 亏损；白底上比 #ef4444 更实
--paper
#7c3aed
模拟紫：白底上 #8b5cf6 偏飘，压深一档
--primary
#2563eb
交互蓝，白底对比度 4.9:1，正文级可读
--warning
#d97706
stale / 未生效；#f59e0b 在白底上不达标
--muted
#64748b
次要文字，需满足 4.5:1
--text
#0f172a
主文字：不用纯黑，降低眩光
--scrim
深纱 38%
夜间是黑纱 64%；浅色下遮罩要更轻，否则整屏像断电

3.2 开关的三种图标态appbar states

跟随系统
App 栏上的三种状态
跟随系统
系统当前是日间 → 显示太阳图标；系统转夜间会自动变月亮。不写字也知道在跟随。
日间
强制日间：太阳图标，文字说明是强制态。
夜间
强制夜间：按钮自身也用深色（提前预示切换结果）。
实现要点
令牌--terminal-*（名字不变）
作用域html.light / html.dark
跟随系统matchMedia + change
持久化localStorage: theme
首帧防闪index.html 内联脚本
主题必须在 initTheme() 里同步落地（body 渲染前），否则深色用户会看到一闪的白。
「跟随系统」不能只显示一个静态图标——要让用户看到它此刻实际解析成了什么（太阳/月亮随系统变），否则无法判断跟随是否生效。
日间模式设计要点
· 三档开关：跟随系统（默认）/ 日间 / 夜间；持久化到 localStorage.theme，首帧前同步落地防白闪。
· 令牌名不变，只换值：--bg / --card / --card-2 / --border / --profit / --live / --paper / --primary / --muted / --text / --warning， 外加两个只在浅色下需要的 --scrim（遮罩浓度）与 --shadow（卡片投影）。
· 浅色不是减淡，是重定基准：盈利绿必须压深（#00dc82 → #059669），否则白底上不可读； 模拟紫压深一档；警告橙换成 #d97706。
· 四个浅色专属坑：① 页面底不用纯白（刺眼且卡片浮不起来）；② 遮罩浓度从 64% 降到 38%； ③ 流式日志的深底要换成浅底；④ 断流态不能用降透明度（浅灰文字会消失），改用 saturate(.35) 去色。
· 层次手段不同：夜间靠发光与亮压暗；日间靠白压灰 + 1px 细边 + 极轻投影。
