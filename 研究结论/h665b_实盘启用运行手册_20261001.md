# 实盘做市启用运行手册(h665,2026-10-01)

> 全部代码/页面/风控已就绪并验证;启用只剩 API Key + 三行命令。
> 本手册是"用户给 Key 后的唯一步骤序列",任何一步失败都停在原地,不进入下一步。

## 0. 前置(用户完成一次)

**Asterdex V3 API Key**(官方文档 github.com/asterdex/api-docs,V3 Recommended;
2026-03-25 起新 Key 只有 V3,旧式 Binance 兼容 HMAC Key 已停发):

- 创建:asterdex.com → **api-wallet → 顶部切 Pro API** → 得到三件套:
  ① `user`(主钱包地址)② `signer`(API 钱包地址)③ `privateKey`(API 钱包私钥);
- ⚠️ privateKey 是**钱包私钥**,等同于资产权限,只放 `.env`,绝不进代码/仓库;
- ⚠️ 2026-09-01 起:鉴权接口要求主钱包完成过**入金**,否则返回 -5050;
- 配置(方式A 推荐):`.env` 追加三行
  `ASTERDEX_V3_USER=0x...` / `ASTERDEX_V3_SIGNER=0x...` /
  `ASTERDEX_V3_PRIVATE_KEY=0x...`;
- (旧式兼容)仍可配 `ASTERDEX_API_KEY/API_SECRET`,但仅对 2026-03-25 前的老 Key 有效。

> 实现已就绪:`asterdex_v3_client.py`(EIP-712 钱包签名 + 微秒 nonce 重放保护 +
> 429/418 退避)已接入执行桥(V3 优先、旧式回退),签名往返测试通过(恢复地址==signer)。
> 限频提醒:每账户 1200 单/分;连续 429 会 IP 封禁 2 分钟~3 天,桥已内置熔断退避。

## 1. 激活步骤(严格按序)

1. `python scripts/sync_live_cfg.py`(**配置同步硬要求**:实盘必须与模拟同配置;
   漂移时"启动"接口会 409 拒绝,见 h665c);
2. `python scripts/_restart_backend_clean.py`(重载 Key);
3. 确认实盘 worker 在跑:`logs\live\mm_lane_worker.log` 有
   `start lane=mm_asterdex_live`(若无:双击 `scripts\mm_lane_worker_live.bat`);
4. 页面 `/hft/live` → 确认 API Key 状态条消失、总权益显示真实余额;
5. 页面点"启动"→ 输入确认词 `启动` → 车道 status=active;
6. 观察 10 分钟:挂单表出现 post-only 单、持仓表与交易所一致、
   熔断计数 0、总名义 ≤ $500。

## 2. 首跑纪律(预注册)

- **最小规模**:live_caps 默认 total $500 / per-symbol $150 / 日亏 $30(如需更小,
  先 `mm_apply_params --lane mm_asterdex_live` 改 live_caps 再启动);
- **12h 判决**:`python scripts/d1_verdict.py --lane mm_asterdex_live --baseline-hours 12`
  (同 Welch 口径);不通过 → 页面"停止"或 kill switch,回滚参数;
- 任何异常 → 页面"一键撤单"(确认词 `撤单`)→ 车道自动停止。

## 3. 风控兜底(已写死,无需人工)

- 未配 Key / 车道非 active ⇒ 桥 no-op,不挂任何真实单;
- 总名义/单币名义/日亏超限 ⇒ 停加仓(自动);
- 连续拒单 ≥3 ⇒ 熔断 60s;
- kill switch ⇒ 撤全部挂单 + status=stopped。

## 4. 与模拟的隔离清单

- 模拟 `/hft` = 车道 mm_asterdex(paper),实盘 `/hft/live` = 车道 mm_asterdex_live;
- 参数/启停/账本/心跳/判决全部分离(lane_id 区分;日志 logs vs logs\live);
- 实盘页所有危险操作带确认词;模拟页无实盘按钮。
