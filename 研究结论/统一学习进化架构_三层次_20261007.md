# 统一学习进化架构:高频 × 中线 × 长线,一个大脑

**生成:2026-10-07 02:3x | 用户:"把 FinRL 用在整合学习进化上,中线/长线也用,高频并入整个项目的学习模块,形成一个整体,相互联系"**

---

## 0. 现状盘点(决定架构的事实)

| 层 | 现有载体 | 数据 | 现状 |
|---|---|---|---|
| **高频**(tick~0.5s) | `mm_asterdex` 车道(active_flow) | 逐笔+100ms 盘口 | 在跑;学习=统计裁决(DSH 白名单+三关) |
| **中线**(分钟~小时) | `liq_reversal`(清算反转)、`carry_basis` 的部分腿 | 1m/5m/1h K 线(可从逐笔聚合) | 车道注册但**未验证/未跑** |
| **长线**(日级) | `carry_basis`(基差/资金费 carry) | 日线+8h 资金费 | 注册未跑 |
| **学习模块** | 40+ 个 HFT 任务(self_tuner/era_verifier/EWA/bandit/trial 链) | — | **全部只服务高频**,中线/长线没有学习模块 |

⇒ 要做的事:①FinRL 式影子学习者接入三层;②三层共享一个进化内核(同一套
"提出→影子试跑→OOS 三关→晋升/回滚"管线);③三层**互相喂信号**(不是三个孤岛)。

## 1. 整体架构(三层一个大脑)

```
┌────────────────────────── 数据层(共享) ──────────────────────────┐
│ 逐笔/盘口(高频)| 1m/5m/1h 聚合(中线)| 日线+资金费(长线)              │
│ 同一张特征表派生三套聚合:微价/OFI/趋势/深度/队列/跨币宽度/资金费     │
└──────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────── 统一进化内核(新模块) ───────────────────────┐
│ evolution/unified_learner.py                                        │
│  · HorizonEnv 接口(reset/step/obs/action/reward) —— gym 风格        │
│  · ShadowLearner(FinRL 式:PPO/SAC,借其算法与训练循环,不借其环境)    │
│  · 统一晋级门:OOS 每腿净 > 基准 × 0.8 且 挂单率不塌 且 强平=0,       │
│    连续 N 小时 ⇒ 晋升;否则回影子重训(与现有 should_rollback_flow 同款)│
│  · 统一往返账本:era ∈ {hft, mid, long}(同一 flow_roundtrip_log 家族)│
└──────────────────────────────────────────────────────────────────┘
          ↓                  ↓                  ↓
┌─ S_HFT(高频学习者)─┐ ┌─ S_MID(中线学习者)─┐ ┌─ S_LONG(长线学习者)─┐
│ state=微价/OFI/    │ │ state=15min 流+    │ │ state=日线趋势+资金 │
│  趋势/深度/队列    │ │  资金费+跨币宽度   │ │  费+仓位+高/中线信号 │
│ action=挂单侧+    │ │ action=liq_reversal │ │ action=carry_basis  │
│  价位档+名义档    │ │  进出场+仓位档      │ │  仓位档(0~3x)       │
│ reward=往返 y     │ │ reward=每腿净 bp    │ │ reward=日 Sharpe     │
└───────────────────┘ └────────────────────┘ └────────────────────┘
```

## 2. 横向联系(相互喂,这是"整体"的关键)

```
① 长线 → 中线 → 高频(自上而下的先验):
   S_LONG 输出的日级 regime(趋势/震荡/基差状态)
   → S_MID 的方向先验(顺大势还是博反转)
   → S_HFT 的方向否决/强化(与现有 300s/10min 趋势否决同一挂点,
     换成"三层次先验"加权)
② 高频 → 中线(自下而上的实况):
   S_HFT 的流读数(OFI 失衡/深度真空/毒性成交率)按 15min 聚合
   → S_MID 的进出场时机特征(中线进出场时,盘口实况好不好)
③ 长线 ↔ 中线(资金费纽带):
   carry_basis 的资金费读数 → S_MID 的持仓成本特征;
   S_MID 的清算反转触发频率 → S_LONG 的基差回归时机
④ 统一裁决:三层的"提出→试跑→裁决"走同一条管线;
   一层晋升的参数可被另一层引用(如 S_HFT 学出的"深档偏好"写入中线的成本模型)
```

## 3. FinRL 借什么、不借什么(每层同口径)

| | 借(FinRL 现成) | 不借(自己写) |
|---|---|---|
| 算法 | PPO/SAC 实现+训练循环(import agent 代码) | — |
| 环境 | gym 接口抽象 | **三层环境**(FinRL 的 bar 环境吃不了 tick/队列;成本/成交模型全错) |
| 指标 | Sharpe/MDD/Calmar 套件 | 往返 y / 每腿净 / 挂单率(我们已有) |
| 数据 | — | 我们自己的库(asterdex_trades/book_ticker/资金费) |

## 4. 实施顺序(五个里程碑)

```
M1 骨架:evolution/unified_learner.py —— HorizonEnv + ShadowLearner + 晋级门
M2 高频影子:包装 active_flow + 账本 replay 为 env;离线 3~6h 数据跑通 PPO 训练;
           OOS 对比当前规则集(目标:往返 y 不输 + 挂单率不塌)
M3 中线影子:从逐笔聚合 15min bar;liq_reversal 车道接 ShadowLearner
           (先影子,不实盘)
M4 长线影子:日线+资金费;carry_basis 接 ShadowLearner
M5 三层互联:S_LONG regime → S_MID 先验 → S_HFT 否决;统一裁决上线
```

**纪律(沿用现有):任何影子学习者必须 OOS 连续 N 小时胜过基准才晋升;
数据已证明 tick 级 markout ≈ 0,RL 最容易学成过拟合 —— 晋级门是唯一的闸。**
