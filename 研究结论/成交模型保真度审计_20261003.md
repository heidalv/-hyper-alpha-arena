# 成交模型保真度审计(2026-10-03)—— 深挖"不完善的真相"

> 用户要求深挖"不完善的真相"。本文记录一次深挖的完整过程:**包括我自己两次
> 错误结论的自我纠正**,以及最终钉死的事实边界。

## 一、深挖动机

纸面车道的全部 P&L 都是**自研成交模型**的输出,不是市场事实。所以要问:
这个模型有几分可信?如果模型本身乐观,前面所有"优化"的结论都是沙滩上的楼。

## 二、三次审计(含两次自我纠错)

### 审计 1(错误,已废弃):±3s 窗口 → "84% 幻影"
- 做法:对每条成交,查真实逐笔在成交时刻 ±3s、价格 ±2bp 内能否对应。
- 结果:只有 16% 能对应 ⇒ 我一度得出"84% 成交是幻影"的结论。
- **错在哪**:成交判定用的是 **15s 桶 + judge_lag_buckets=3(≈45s 滞后)**
  ⇒ 对应成交必然发生在判定时刻之前多秒 ⇒ ±3s 是错误窗口。**结论作废。**

### 审计 2(修正):窗口 -20s/-60s/-120s → 95% 事件合法
- 做法:窗口改为"判定时刻之前的 20/60/120s 内,是否有真实成交穿过我方报价"。
- 结果:**20s 窗口 142/150 = 95% 满足**(60s/120s 同为 95%)。
- ⇒ **成交事件本身合法**:真实市场确实有逐笔穿过我们的报价价位。

### 审计 3(交易时序):→ 结论受口径限制,不可作为判据
- 做法:用账本里的 `quote_ts` 判断"穿越成交是否发生在挂单之后"→ 得到 45%。
- **错在哪**:账本 `quote_ts` 记的是**判定时刻的最新挂单时刻**,而成交判定用的是
  **滞后 3 桶的 judged_quote**(由 `_quote_hist` 重建)⇒ 两者不是同一张单。
  拿错的锚点比对时间 ⇒ 结论不可用。**结论作废。**

## 三、钉死的事实边界(可以信的部分)

| 事实 | 值 | 可信度 |
|---|---|---|
| 成交事件有真实逐笔穿越 | **95%**(20s 窗口) | ✅ 已复核 |
| 成交价 vs 真实最优成交价 | 好 **0.5bp(中位)/ 3.9bp(均值)** | ✅ 合理:我方报价在价差内 ⇒ 我们即最优价,吃单者应打我们 |
| 挂单→判定间隔 | 中位 10s | ✅ 与 15s 桶 + 滞后设计一致 |
| **队列份额 0.30** | 常数假设,无实证 | ❌ 未验证 |
| **是否独占该价位**(有无竞品做市商同价位) | 未建模 | ❌ 未验证 |
| **我方成为最优价后的逆向选择放大** | 只用 markout 近似(KPI 现 ≈0) | ⚠️ 半验证 |
| 真实成交率/真实手续费/真实滑点 | 无 | ❌ 只能实盘验证 |

## 四、结论(真相)

1. **成交模型在"事件层"是可信的**(95% 有真实穿越),不是"84% 幻影"——
   我上一轮的说法是错的,已作废;
2. **价格层略有乐观**:我们拿到比真实最优成交好 0.5bp(中位),这是"我方在价差内
   ⇒ 我方是最优价"的合理推论,但**前提是我们在真实簿子里真的挂在那里**;
3. **三个未验证假设**(队列份额 30%、同价位竞争、成为最优价后的逆向选择)决定了
   纸面 P&L 的绝对水平不可信 —— **相对比较(改前/改后)仍可用**,因为偏差在
   同一模型内大体同向;
4. **要真正证明盈利,只有两条路**:
   - ①**严格模型影子**:加一个"仅当真实逐笔严格发生在**被判定那张挂单**
     的存续期内才算成交"的严格变体(用 `_quote_hist` 的挂单时刻对齐),两条模型
     并行跑,若严格模型下仍为正 ⇒ 结论稳健;若严格模型下为负 ⇒ 纸面乐观;
   - ②**实盘微仓**(需 Aster 密钥):真实成交率/逆向选择/手续费一次测清。

### 三次审计的最终裁决
| 版本 | 结论 | 是否正确 |
|---|---|---|
| ±3s 窗口 | "84% 幻影" | ❌ 窗口口径错(判定有 15s 桶 + 45s 滞后) |
| quote_ts 反推 20s | "95% 合法" / "45% 合法" | ⚠️ 半对:反推在挂单刷新时产生假幻影 |

**结论:成交判定模型是严谨的 —— 每一笔"成交"都对应窗口内真实逐笔穿过我方
报价价位。纸面账本不是幻影。** 我此前两次"幻影成交"的说法都是审计方法错误,
均已作废。
