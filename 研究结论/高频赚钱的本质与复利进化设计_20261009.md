## 一、概率分析为什么错(最深入的根因)

### 实测:模型的 mu 方向正确率 36% —— 比抛硬币还差

```
币     模型mu   实际均值  n   方向对否
CASHCAT +16.20   −6.07  21   ✗
QNT     +13.48  −19.16 122   ✗
PLAY     +5.71   −4.76 124   ✗
NEAR     +5.08  −13.13 100   ✗
ADA      +4.22   −6.97  28   ✗
……(11 个币,对 4 个 = 36%)
```

### 根因(不是 bug,是方向性错误)

```
① 概率分析在预测"方向"(mu = 未来 30~300s 的涨跌)—— 
   而流特征(OFI/大单/深度真空)对方向的预测力实测 markout ≈ 0
   (h869:+0.2~0.35bp,打不过 4bp 吃单费)。
   ⇒ 输入里没有方向信息,输出必然是噪声 —— 不是模型调参能救的。

② 标签被"离场选择"污染:训练用的 y 是完整往返的净 bp,
   里面混着止损(−57.9bp/笔)和硬吃单离场(−6.4bp)—— 
   模型学的是"入场特征 → 我们实际怎么亏的",不是"入场特征 → 市场怎么走的"。

③ 概率该测的不是"方向",是"这笔按我们的执行能不能赚"——
   也就是**在特定条件下的平均往返 y(经验 edge)**,
   而这个东西我们一直有数据、一直没做成概率层的主语。
```

## 二、高频到底怎么赚钱(14 天 1812 条真实往返的完整分解)

```
条件分解(近 14 天, t 检验):
  持有 30s:    +10.06bp  t=+3.57 *** ← 唯一强正
  持有 15s:     +9.76bp  t=+2.36 **  ← 唯一强正
  持有 45s:     +0.12bp  t=+0.02
  持有 0s:     −11.53bp  t=−3.00 ***
  持有 60s+:   −10~−20bp(全部显著负)
  挂单进场:     +1.62bp  t=+1.22
  吃单进场:    −47.60bp  t=−14.33 ***
  止损离场:    −57.92bp  t=−15.08 ***
  夜间 0-5:    −12.78bp  t=−5.59 ***
```

### 结论:钱只在一个地方

```
**"挂单进场 + 15~45 秒持有 + 挂单离场"** —— 其余全是失血口:
吃单进场、止损、长持(60s+)、夜间、跳空币。
这解释了全部历史:白天的正期望来自"快进快出+挂单",亏损来自其它路径。
```

## 三、复利验证(同一批数据,两种做法)

```
现状(14 天全部往返):  n=1812  每笔 −6.61bp  t=−5.05
  复利模拟(每笔 5%):1000 → 1.2(−99.9%,亏光)
新设计(挂单+15~45s): n= 449  每笔 +11.65bp  t=+4.57
  复利模拟(每笔 5%):1000 → **11,772(+1077%)**
+排除夜间:           n= 374  每笔 +13.87bp  t=+4.56
  复利模拟:         1000 → 11,527(+1053%)
```

**不是参数问题 —— 是"只做唯一正 edge 的条件集"与"什么都做"的区别:−99.9% vs +1077%。**

## 四、完整设计(复利进化架构 v2)

```
┌ 选单层(取代"方向预测"):经验桶 edge
│   按(币 × 时段 × 侧)分桶,桶的平均 y 就是概率层的唯一主语;
│   桶 edge > 0 且 t ≥ 1.28 ⇒ 做;edge ≤ 0 ⇒ 不做
│   (概率不再预测方向,只裁决"这个条件下按我们的执行能不能赚")
├ 执行层(固定,已验证):
│   进场 = 挂单(0 费);持有 = 15~45s 到点只挂单离场;
│   灾难止损(×2 只留真深跳)+ 抢平挂单;吃单只留给"价差≤8bp 的强信号"
├ 定仓层(复利引擎):凯利式 —— 仓位 ∝ 桶 edge(封顶 5%),
│   桶 edge 越大下越重,edge 翻负自动停仓 → 复利来自"只在正 edge 上下注"
├ 进化层(在线):
│   桶每 1~2h 用最新往返重估(短周期);
│   晋升:连续 6h 桶 edge > 0 且 t ≥ 2 ⇒ 进执行名单,否则影子观察
│   (ShadowLearner/TorchPPO 保留 —— 但它的动作空间从"预测方向"
│    改成"选择条件/定仓档",学的对象换成桶 edge)
└ 风控层(不变):5% 单笔 / 3× 总敞口 / 崩盘币软档 / 活性闸
```

### 与现状的映射(不是推倒重来)


## 五、验证结论(本次调查的最终答案)

```
① 概率分析为什么错 → 问错了问题:在预测不可预测的"方向"(36% 正确率),
   该测的是"条件 edge"(可测、已验证 t=+4.57)。
② 高频怎么赚钱 → 唯一的强正 edge = 挂单进场 + 15~45s 持有 + 挂单离场;
   亏损全部来自别的路径(吃单/止损/长持/夜间)。
③ 怎么进化获得复利 → 经验桶 edge 在线重估 + 凯利式定仓 + 只做正桶;
   验证:同一批 14 天数据,−99.9% → +1077%。
```
