## 0. 执行摘要

**一句话**:我们已建成一个**七层闸门 + 自适应速度 + 方向分数 + 滚动选币**的完整做市引擎
(核心代码 12,810 行,配套研究脚本 200+),在 Aster DEX 永续上以 maker 0 费率运行;
2026-10-01 收盘前 4.4 小时的修复窗口实测**每腿 +$0.0218**,但**前 12 日累计仍为净亏损**,
当前处于"机制已通、规模未起"的阶段。

**三个关键结论**:
1. **收入天花板不在价差,在返佣**:Aster 的做市商计划 MM1 档 maker 返佣 **−2.5 bps**
   (即每笔 maker 成交**倒收** 2.5bp),是我们当前单腿价差捕获(约 0.6bp)的 **4 倍**。
   策略设计必须转向"**返佣驱动**",而门槛是**月名义 ≥$150M**(我们当前约 $1.1M/月)。
2. **方向判定已找到盈利方向**:当日 1304 腿实测——**逆势(fade)买 +1.15bp/腿(t=+5.7)**,
   **顺势 −1.55bp/腿(t=−7.8)**;据此翻转趋势闸(2026-10-01 21:10 上线)后,
   实测每腿净从 −0.4bp 提升到 **+3.1 ~ +15.3bp**。
3. **风险已量化并加装硬顶**:止损尾部曾出现 −127bp(WLD)/−310bp(ENA)的失控成交,
   根因是 maker 宽限单在崩盘中"追价下移";已加 `stop_taker_bp=100` 硬距离 fail-fast。

## 3. 意义(Significance)

### 3.1 对资金:低相关性、可扩展的现金流

做市的收益来源是**流动性提供本身**(价差 + 返佣),与方向性策略(趋势/事件)
相关性低。在当前组合里,它是唯一**双向收费**的引擎(价格涨跌都可赚价差)。

### 3.2 对项目:从"策略使用者"到"流动性提供方"

- 掌握自营做市能力 ⇒ 不依赖第三方做市商即可为自己的标的提供深度;
- 返佣档位一旦达到(MM1 = $150M/月),**单位交易的成本结构反转**:从付费变收费;
- 做市引擎的产出物(盘口特征、毒性指标、微价因子、队列模型)**可复用**到其他策略。

### 3.3 战略结论:**必须按"返佣驱动"重设默认假设**

公开费率表(附录 A)显示:在 Aster,MM1 档的返佣(−2.5bp)≈ 我们当前价差捕获的 4 倍。
⇒ 引擎的优化目标应从"单腿价差最大化"改为"**在满足报价义务前提下最大化有效 maker 量,
同时把每腿净额守住 ≥0**"。

## 5. 数学模型(Math Model)

### 5.1 报价模型(半价差相对 + 多层偏斜)

我们不用绝对 bp 报价,而用**价差相对报价**,以保证跨币一致性与成交概率:

```
基础半宽  base = spread_mult × per_symbol_spread_mult × (half_spread)
相对地板  base ≥ min_edge_frac × half_spread            (h698:永不在价差内侧)
波动上限  base ≤ max_width_bp
趋势偏斜  k_trend:涨 ⇒ bid 挂远/ask 挂近(顺势出货)
库存偏斜  k_inv / inv_skew_abs_bp:多头 ⇒ 买远卖近(鼓励减仓)
减仓侧    spread_mult_reduce / exit_skew_k(按 adverse 收拢)
方向倾斜  add_size_mult = {bid: 1+kD, ask: 1−kD}          (h692)
```

当前参数:`spread_mult=1.0`、`per_symbol=1.8`、`min_edge_frac=1.2`、`max_width_bp=3.0`、
`w_base_bp=5.0`、`k_vol=0.3` ⇒ 正常市实测挂宽 **1.06–1.62bp**。

**与 Avellaneda–Stoikov 的对应**(公式经 Hummingbot 官方文档确认,见附录 A):

| A-S 项 | 我们的对应 |
|---|---|
| 保留价 `r = s − q·γ·σ²·(T−t)` | 库存偏斜 `k_inv` / `inv_skew_abs_bp` + 趋势偏斜 `k_trend` |
| 最优价差 `δᵃ+δᵇ = γσ²(T−t) + (2/γ)ln(1+γ/κ)` | `base = w_base·(1+k_vol·σ) × spread_mult`(σ 项即 A-S 的 γσ² 项) |
| 风险厌恶 γ | `k_vol`(0.3)与 `size_vol_decay`(腿量随 σ 收缩) |
| 到达强度 κ | 由 `vol_le_bid / vol_ge_ask`(价位真实量)与队列份额 `_QUEUE_SHARE` 隐式刻画 |

差异:我们在 A-S 基础上增加了**信号层倾斜**(微价/流/趋势/形态)与**闸门否决层**,
即 A-S 的"纯库存风险定价" + "方向信息择时"。

### 5.2 成交判定模型(paper)

- 订单入队:按价位可见量估计排队位置(队列份额 `_QUEUE_SHARE`);
- 成交:要求**真实逐笔**在同一价位有对手方成交(消灭"桶 low 穿越但无逐笔"的幻影成交);
- 数量:取价位真实可吃量,不再用整桶总量外推;
- 交易所条件模拟(与实盘一致):stepSize/tickSize 对齐、minNotional、
  涨跌停带、订单速率 1200/分(超限 = 429 拒绝)。

### 5.3 信号模型:方向分数 D

```
D = 0.25·c(微价偏离/2bp) + 0.15·OFI + 0.35·c(趋势300s/20bp) − 0.25·c(趋势900s/40bp)
    c(x,s) = clamp(x/s, −1, 1)
```

- **微价**:`(bid·askSz + ask·bidSz)/(bidSz+askSz)` 相对中价的偏移(bp);
- **OFI**:近 60s 主动买失衡 `(bv−sv)/(bv+sv)`,由**原始逐笔**计算(聚合表实测漏数据);
- **趋势 300s**:延续项(正权重);**趋势 900s**:fade 项(负权重)。

**样本外验证**(7572 样本,前半拟合/后半测试):

| 尺度 | 样本外 IC |
|---|---|
| 5s | +0.037 |
| 15s | +0.051 |
| 30s | +0.051 |
| 60–120s | **负** |

⇒ 融合只在**秒级**有效(与我们的挂单生命周期一致)。

### 5.4 速度模型:Q 速控

```
Q = 0.35·spread_ok_share + 0.25·min(1, 腿速/10) + 0.25·min(1, 捕获/0.3bp) + 0.15·(1−|逆选择|/1bp)
    − 毒性罚分;近 30 分钟止损类腿 ≥2 ⇒ Q 强制 ≤0.39(尾部风暴钳)
动作:pause(Q<0.4, 加仓量 0) / probation(暂停 10min 后半速复入,退避 ×2) / half(0.4≤Q<0.7) / full(≥0.7)
```

### 5.5 选币模型:v5 滚动质量雷达

```
候选 = 深度采集池 ∩ 通过 L1(价差可行性 ok_share ≥0.4)∩ L2/L3(形态×币 edge)
淘汰 = Q 快判据(60min 非满速占比 ≥60% 或 Q 均值 <0.5)
       ∪ 亏损淘汰(60min 逐腿净 < −1bp 且 n≥20)
       ∪ 敞口衰减(名义 >80% 上限 或 浮亏 < −30bp)
替换 = 衰减驱动立即换;择优替换需 2h 驻留(edge 差 ≥1.5bp 可提前)
新币 = 12h 微试跑仲裁(n≥30)
```

### 5.6 出口模型

| 出口 | 触发 | 方式 |
|---|---|---|
| 止盈 | 浮盈 ≥ `take_profit_bp`(30bp) | taker |
| 止损 | 浮亏 ≥ `stop_loss_bp`(40bp) | **先 maker 宽限 300s → taker**;浮亏 ≥ `stop_taker_bp`(100bp) **立即 taker**(h700) |
| 尾随锁利 | MFE ≥ `trail_lock_bp`(20bp) 后回落至阶梯线 | maker/taker |
| 超时 | 持仓 > `timeout_hard_taker_sec`(600s) | 先 maker → taker |
| 变盘 | 趋势反向 ≥ `trend_flip_flatten_bp`(12bp) | 与止损同一流程 |
| OFI 平仓 | 毒性流反向 | maker |

### 5.7 账户恒等式(账务自洽)

```
当前权益 = 起始 + 外部划拨 + Σ 已实现 − Σ 手续费        (残差恒为 0)
```

账本 append-only;删除任何腿必须**同时**回退账户行与分所余额行(否则增量续算会拉回旧值)。
