## 2. 本轮落地:R2"只挂深档"

**做法**:进场的挂单价不再是"盘口最优价",而是**至少偏离中价 `entry_min_capture_bp`(默认 8bp)**:
```
多头:报价 = min(盘口买一, 中价 × (1 − 8bp))
空头:报价 = max(盘口卖一, 中价 × (1 + 8bp))
```
含义:**宁可不成交,也不在贴盘口的位置被逆选吃掉**。成交时天然带着 ≥8bp 的捕获,
正是实测里唯一为正的那一档。

**代价**:成交率下降(深档更难被打到)⇒ 用"腿速换每笔质量"。
**可调**:`data/flow_learn_params.json` 的 `entry_min_capture_bp`(纳入流白名单,可自动裁决)。

   价差在入场那一刻就拿完,逆向漂移按时间累积 ⇒ 持仓越长,净得越少,
   最后只剩漂移 + 止损。
```

## 9. 用户三条深改(全部上线,h878,13:3x)

```

   方向分数是挂单前算的;买单被打到 = 刚有人在卖。成交后用同一套因子

   分数翻到持仓对面 ⇒ flow_mu=-1 ⇒ 下一拍 maker_edge 在对手价挂平(0 费)。
   实现:runner 在 active_flow 之后做一次性重算(flow_rechecked 字段,每仓一次)。

② **止损只留给"真宽"**:
   吃单止损线从 stop 放宽到 **stop × 2**(STOP_WIDE_MULT=2);

   吃单只发生在:浮亏真宽(深跳)或 R4/R5/盘口过期(没人成交)。
