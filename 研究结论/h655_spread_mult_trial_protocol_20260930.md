# H2 贴盘口标定试跑协议(预注册,h655,2026-09-30)

> 隶属《正收益阻碍深度分析_20260930.md》H2。排期:H1 判决之后,单变量顺序执行。
> 验证依据:①h364 实测(d=0.25bp:94.6% 成交、+0.253bp/成交腿双优;d=1:−0.171;
> d=2:−0.242——距离本身即是逆选择);②当前数据:换币后每腿捕获仅 **+0.044bp**,
> 而宇宙全部是宽价差币(半价差 0.65~3.5bp)——挂 1.6~2.5bp 远 ⇒ 成交只在被逆向时发生,
> 并拖出超时强平(H1 的同源病)。

## 1. 假设

把宽价差币的挂单位置从 ~1.6-2.5bp 收贴到 ~0.25-0.5bp(按币价差标定),
捕获从 +0.044bp/腿 升到 h364 的 +0.25bp 量级,成交率同步上升;
新成交腿受方向卡/D1 降损层保护,逆选择不随贴盘口恶化(h364 已证贴=优)。

## 2. 变更(单变量)

| 项 | 值 |
|---|---|
| 参数 | `per_symbol_spread_mult`(F280 已有机制,现仅 ARB/BNB/ENA/NEAR 有旧档):
  按币价差标定 **BNB 0.10 / XRP 0.10 / SUI 0.05 / ENA 0.05**(= w_base 5bp × 系数 ≈
  0.25~0.5bp 半宽;试跑前用每币最新 rel_spread 复核,写进试跑起点记录) |
| 其余 | 全部按住(H1 判决后的参数族、宇宙、方向卡、出场栈) |
| 入口 | `mm_apply_params.py --set per_symbol_spread_mult='{"BNB":0.10,...}' --reason "H2 贴盘口标定试跑预注册"` |
| 回滚 | `per_symbol_spread_mult=null`(恢复全局 spread_mult=0.5) |

## 3. 判决口径(预注册,12h)

- 窗口:12h(trial_active 互斥);
- 主指标:逐腿捕获(spread_bp,名义加权)与逐腿净 bp vs H1 判决后基线;
- 副指标:①腿数 ≥60/h 且成交率上升;②逆选择(price_bp)不恶化;
  ③超时强平腿占比不升;
- 统计:双侧 Welch α=0.10;
- 裁决:净 bp 显著改善且逆选择不恶化 ⇒ 保留;显著恶化 ⇒ 回滚 null;
  不显著 ⇒ 延长 12h。
- 判决文件:`research_l1/out/h655_spread_mult_verdict.json`。

## 4. 注意

- 贴盘口后腿数预计显著上升(触及模型 94.6% 成交),腿量上限
  (max_leg_notional_mult=3)与方向卡照常生效,不为本试跑放宽;
- 与 H1 同源:成交率上来了,超时强平自然减少——两试跑顺序执行是为了
  把"超时延长"与"贴盘口"的贡献分开归因。
