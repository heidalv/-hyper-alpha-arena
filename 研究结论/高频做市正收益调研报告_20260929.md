# 高频影子做市如何赚钱：调研与升级报告（2026-09-29）

> 对象：车道 `mm_asterdex`（Aster 永续纸面做市，maker 费 0、taker 费 4bp）  
> 现象：赚十笔不够亏一笔，还要付高额吃单手续费  
> 账本窗口：2026-09-28 13:00（北京时间）起，至写稿时（约 1619 笔，净约 −$24）

---

## 0. 一页结论（先看这个）

你现在的亏，**不是「不够高频」**，也不是「再拧一下挂宽就能翻正」。

用账本拆开：

| 项 | 金额 / 数字 | 含义 |
|---|---|---|
| 全段净盈亏 | **−$24.29** | |
| 其中止损吃单 | **−$23.52**（62 笔，约 −54 bp/笔） | 几乎等于全部亏损 |
| 其中手续费 | **−$12.11** | 几乎全是吃单 4bp |
| 开仓（maker） | ≈ **$0**（名义加权 −0.01 bp） | 挂单几乎白干 |
| 平均每笔赚 | **+$0.037** | |
| 平均每笔亏 | **−$0.143** | 亏的是赚的 **3.9 倍** |
| 胜率 | 约 **71%** | 胜率不低，仍亏——典型「赢小输大」 |

**数学上必须满足的不等式（做市盈亏恒等式）：**

```text
半价差捕获  −  逆选择(成交后价格朝你不利走)  −  库存漂移  −  净手续费  >  0
```

你这边：半价差往往只有 **0.5～1 bp**；一笔止损吃单要吐 **40～50 bp 价格 + 4 bp 费**。  
所以不是「十笔赚刚好抵一笔亏」，而是 **大约 40～60 笔干净开仓**，才够填一笔止损。

升级方向按优先级（后文展开）：

1. **永远优先用挂单平仓**；吃单只做真正的尾部保险，且频率要极低。  
2. **库存偏斜用绝对基点 + 到量就撤加仓腿**（方向盘要拧得动）。  
3. **只在「捕获 ≥ 预期逆选择 + 费」的币/时段挂**；入场边际为负的币直接下。  
4. **用成交后 markout 曲线当硬门禁**：markout 吸干半价差的流量，当场停挂。  
5. **新闻/跳变时撤双边**，不要用止损去「猜方向」。  
6. 对冲、多资产、强化学习是下一层；**先把费和止损结构改对**，否则上层全是噪声。

## 1. 交易基本面：你在玩的是什么生意

### 1.1 做市商的真收入来源

专业做市（Optiver / Jump / Wintermute 一类）的钱主要来自：

1. **价差捕获**：买一卖一之间的价差（或返佣）。  
2. **库存周转**：尽快把仓位转回接近零，让价差能重复收。  
3. **信息过滤**：少跟「知情单」成交（逆选择）。  
4. **部分场所有 maker 返佣**：返佣可以把「盈亏平衡价差」压到 0 以下。

你这条车道：

- Aster **maker = 0**（没有返佣福利）。  
- **taker = 4 bp**。  
- 报价被锁在买卖价里面，半价差常常 **< 1 bp**。  

⇒ 结构上这是「薄利、零返佣、吃单很贵」的场。能活的条件比有返佣的期货做市更苛刻。

### 1.2 「赚十赔一」的微观解释

开仓腿是 maker，账上平均只剩约 **0**；  
止损腿是「价格已经错了 40bp + 再付 4bp」。  

期望可以粗写成：

```text
E ≈ p_win × 0.5bp_捕获  −  p_stop × (40bp + 4bp)  −  其他吃单费
```

即使胜率 90%，只要止损频率到 2%～3%，净期望仍可为负。  
**所以目标不是提高胜率，而是：大幅降低「付费出场」的频率与名义。**

### 1.3 交易心理上的坑（和你现在的行为对应）

| 心理 | 表现 | 后果 |
|---|---|---|
| 损失厌恶 | 浮亏就想「赶紧砍」 | 把本可用挂单等回摆的仓，变成 4bp 确定亏损 |
| 处置效应 | 小赚赶紧落袋、大亏拖着或硬砍 | 赢小输大（你账本正是这个形状） |
| 过度交易 | tick 越快越好 | 在负期望流上放大换手与费 |
| 叙事执着 | 「高频就该一直挂」 | 毒性时段、新闻时段仍挂，被知情流收割 |

专业做市的纪律是反过来的：**大部分时间可以不挂；挂了就要保证条件期望为正。**

## 2. 底层数学模型（必须对齐的几套）

### 2.1 Avellaneda–Stoikov（2008）——库存随机控制

核心：不做「围着中间价对称挂」，而是围着**保留价（reservation price）**挂：

```text
r = s − q · γ · σ² · (T − t)
最优半价差 δ* ≈ 与 σ、订单到达强度、风险厌恶 γ 有关
bid = r − δ* ,  ask = r + δ*
```

含义白话版：

- 你手里多（q>0）→ 保留价往下挪 → 更愿意卖、更不愿意买。  
- 波动 σ 大或时间紧迫 → 价差自动拉宽。  

**对照你的引擎：**  
库存系数 `k_inv` 曾乘在 **0.5 bp 宽的半价差**上，满仓也只能挪约 0.5 bp——等于方向盘失灵。  
正确做法是：**绝对基点挪报价中心**（你已上 `inv_skew_abs_bp`），并且库存到量就**撤掉加仓腿**。

文献：Avellaneda & Stoikov, *High-frequency trading in a limit order book*, 2008.

### 2.2 Guéant–Lehalle–Fernandez-Tapia（GLFT）——无期限做市

永续/现货没有「收盘必须平」，更适合 GLFT 的渐近公式：

```text
半价差 ≈ c1 + (σ c2)/2
偏斜   ≈ σ c2 · q
```

c1、c2 由强度参数、风险厌恶、波动估计出来。  
**HFTBacktest 教程**用 GLFT + Binance 最高档 maker 返佣回测：很多时候**利润主要来自返佣**；去掉返佣往往只能打平。  
这对你很残酷：**Aster 无 maker 返佣 ⇒ 必须靠「更干净的流 + 更少吃单」赚钱，不能靠刷量领赏。**

### 2.3 盈亏分解恒等式（HFT Book / 实务 TCA）

```text
净盈亏 = 毛价差捕获 − 逆选择 − 库存/对冲成本 − 手续费 + 返佣
```

每一项都要单独能量化。你现在账本六维里：

- `spread_bp` ≈ 毛捕获  
- `price_bp` ≈ 逆选择 + 持仓漂移（混在一起）  
- `fee_bp` ≈ 手续费  

**下一步工程：把 `price_bp` 再拆成「成交后 1s/5s/30s markout」**，才能区分「挂错了」还是「拿太久了」。

### 2.4 盈亏平衡价差

```text
盈亏平衡半价差 ≥ E[逆选择 | 成交] + 净费率 + 库存成本
```

若你捕获 0.5 bp，而 30 秒 markout 平均 −2 bp，则**数学上必亏**，拉高频只会亏更快。

### 2.5 队列价值（Moallemi & Yuan 2016）

同一价位上：

- **队首**：更多噪音单、逆选择较轻；  
- **队尾**：往往是「整档被扫穿」才轮到你 → 逆选择更重。  

大 tick 品种上，队列价值可以和半价差同量级。  
你纸面模型没有真实队列，但线上若将来真下单：**禁止无意义重挂（已有 `quote_hold_tol_bp`）**，否则每秒重挂 = 永远队尾。

## 3. 逆选择、毒性流与「为什么止损那么疼」

### 3.1 什么是逆选择

成交本身是坏消息：愿意主动打你买价的人，往往比你更急或更知情。  
成交后中间价继续朝你不利走，就把价差吃光——这叫 **markout 曲线下沉**。

### 3.2 你账本上的毒性出口

| 出口 | 净 USD | 解读 |
|---|---|---|
| `stop_loss_taker` | −23.52 | 主亏：价格错了还付 4bp |
| `ofi_flatten_taker` | −3.12 | 信号对了却用吃单付费 |
| `trail_lock` / `reversal_decay` | 各约 −2 | 仍是吃单路径 |
| `timeout_hard_taker` | **+5.58** | 说明「拿够久用规则平」并不总是亏 |
| `ofi_flatten_maker` | ≈0 | 正确方向：同信号改挂单 |

**论文与实务一致的处方：**

- 毒性高（OFI/VPIN/微价偏离大）→ **撤加仓或撤双边**，不是「硬扛到止损」。  
- 已经决定离场 → **先挂减仓侧**；吃单只做硬超时保险。  
- 止损阈值本身调宽/调窄，期望往往接近中性；**真正改变符号的是「还付不付 4bp」**。

### 3.3 跳变与新闻

单 tick 十几 bp 的跳变，衰减离场看不见，等 40bp 止损接住时已经深亏（你们自己的 jump 研究也写过）。  

新闻/宏观事件（CPI、ETF、交易所宕机、代币解锁）：

- 做市商标准动作是 **事件窗口撤流动性或极大加宽**；  
- 用止损「猜方向」= 把做市做成方向赌博，再叠加 taker 费。  

建议：接一个事件日历（或链上异常成交速率），**事件前后 N 分钟 `side=none`**。

## 4. 对冲：什么时候需要，什么时候是废话

### 4.1 单币做市的「对冲」其实是库存偏斜

AS/GLFT 里的对冲，第一义不是去期货上开反向单，而是：

- 报价不对称，让对手方帮你减仓；  
- 仓位上限；  
- 超时/硬顶。  

**你已有的方向是对的**：绝对偏斜 + 库存停加仓 + 超时优先挂单。先把这一层做满。

### 4.2 跨品种对冲（下一阶段）

| 方式 | 适用 | 代价 |
|---|---|---|
| 同标的多空腿（现货–永续） | 有现货通道时 | 基差、资金费 |
| β 对冲（用 BTC/ETH 对冲山寨库存） | 山寨库存大 | 对冲误差、双边费 |
| 期权尾部保护 | 有期权的标的 | 权利金贵，纸面难模拟 |

在 **只有单所永续、且 taker 4bp** 的约束下：  
跨品种对冲一腿就要吃价差+费，**很容易比对冲掉的库存波动还贵**。  
结论：**净敞口先用报价压下去；对冲只对「压不下去的尾部库存」做，且要算清费后期望。**

## 5. 交易量策略 vs 做市（别混）

| | 做市 | 交易量/刷量/返佣策略 |
|---|---|---|
| 目标 | 价差 − 逆选择 − 费 > 0 | 量最大 / 领返佣 |
| 在 Aster maker=0 时 | 仍可能正 | **几乎必亏**（无返佣还付 taker） |
| 风险 | 库存与毒性 | 手续费与风控封号 |

竞品里大量「刷量机器人」依赖 **maker 返佣阶梯**。  
你没有这层激励 ⇒ **不要用成交笔数当 KPI**，要用「费后净 bp / 名义」。

## 7. 新闻与基本面对做市的影响（操作级）

1. **计划内事件**（非农、FOMC、重大解锁）：前 5～15 分钟降仓/撤挂，后等波动落回再挂。  
2. **突发推特/交易所公告**：用成交速率突变、买卖失衡突变当地雷，触发 `pause`。  
3. **资金费率极端**：永续单边拥挤时，逆选择上升，应收窄宇宙或只挂减仓。  
4. **不要**把 LLM 读新闻直接变成「追涨买」——做市的新闻用法是 **停**，不是 **猜**。

## 8. 针对本车道的「怎样才能赚钱」路线图

### 阶段 A（本周就能验账）——改结构，不拧玄学参数

1. **硬规则：开仓捕获的滚动中位 < 1 bp 的币 → 只减仓或下架**（账本已证明 BNB/XRP）。  
2. **所有计划内离场默认 maker**；`stop_loss` 保持宽限且统计「宽限内被挂单救回」的比例。  
3. **止损名义加权占比 > 某阈值（如日亏的 50%）→ 自动缩该币 `size_mult` 或踢出宇宙**。  
4. **KPI 改成**：费后净 bp（名义加权）、吃单费占比、止损腿占比；**禁止**用成交笔数表扬自己。

### 阶段 B（1～2 周）——数学模型落地

1. 用 GLFT/AS：**半价差 = f(σ)，偏斜 = g(σ)·q**（绝对 bp），替换「半价差×系数」。  
2. 每笔成交记 **markout@1s/5s/30s**；若滚动 1h 的 markout@30s + 半价差 < 0 → 自动停挂该币。  
3. 事件日历 + 成交速率熔断。  
4. 回放必须带 **maker0/taker4** 与逐笔命中，禁止再用 15s 桶结论调参。

### 阶段 C（中期）——对冲与多层

1. 仅当单币净敞口 > 阈值且减仓挂单吃不掉时，才考虑 β 对冲，并强制费后模拟。  
2. 分体制（平静 / 趋势 / 跳变）不同挂宽与是否允许开仓。  
3. 若未来换所有 maker 返佣，再评估「量」策略；在此之前不做刷量。

### 验收标准（正收益）

连续 ≥ 24h（或 ≥ 500 腿）同时满足：

- 名义加权净 bp **> 0**  
- 吃单费绝对值 **< 价差捕获**  
- 止损腿名义占比 **明显下降**（相对今日约「一笔吃光全部」的状态）  
- 不是靠某一个小时的样本
