## 二、核心假设(先立假,后验证)

- **H1(噪声/机械分解)**:每腿净 bp = 机械项(捕获−费−出场成本)+ 零均值不可预测项。
  机械项可学、可外推;**不可预测项只配做方差控制,不配做收益来源**。(E1/E2 支持)
- **H2(闸门自证)**:趋势/方向/毒性闸的唯一正当存在理由 = **被它挡掉的腿实测是亏的**。
  闸门强度应由"影子反事实"(被挡腿的逐腿盈亏)持续标定,而非由行情特征拟合。
  (E3/E6 支持:H1 证伪了"特征→盈亏"的直接学习,H2 换了一条因果路径)
- **H3(选币=带切换成本的 bandit)**:每个候选币对**我们**的每腿净期望是一个
  慢变参数;换币有实测成本(冷启动档 0-30min 每腿比 2-6h 档低 ~5bp)。最优策略
  = 每币 edge 后验(均值+不确定度)与切换成本的联合优化;当前"点估计+固定阈值"
  等价于忽略不确定性的贪心 ⇒ 必然抖动。(E4 支持)
- **H4(统一语言)**:所有子系统的共同度量 = **"每腿净 bp 的条件期望"**;各子系统
  各自维护一个后验(机械曲面 / 闸门反事实 / 币 edge),元层只做资本与注意力的配置。
- **H5(第二曲线,已被 h717 部分推翻)**:收益增长不靠预测变准,靠**机械层稳定正期望**后的两条规模曲线:①权益复利——**被 3 天 5045 腿数据推翻:每腿净随名义单调递减,两行情一致(L14),复利阶梯改走"小额广度"(更多币×小单,每腿≤$20)**;②返佣阶梯(月名义 $150M ⇒ maker −2.5bp)。规模是结果,不是手段。

## 三、统一语言与目标函数

**战术度量**:每腿净 bp(名义加权),按四元分解:
```
net_bp = capture(挂单价差) − adverse(行情,不可预测) − fee + 出场损益
```
**战略目标**:长周期已实现净 USD,受风控约束(日亏 10%×权益、总/单币上限、
止损硬顶)。**分层**:战术层追每腿净 bp 的条件期望;战略层追净 USD 的复利与返佣阶梯。

## 四、四层自进化架构("机械优先、噪声封顶、后验选币、闸门自证")

### L1 机械曲面自进化(已上线,继续深化)
- **信号**:每腿 capture/成交/净 + 盘口触及率曲线。
- **循环**:每 6h 重拟合(DSH_MM_SURFACE)→ 桥复核 → 单变量调整 → 2h 快判。
- **深化项**(阶段 1):①曲面从"全局全宽上限"升级为**逐币**半宽(每币一个
  触及曲线×捕获档净);②加入第三维"队列份额"(腿量∝成交率),与规模层联动;
  ③捕获档净的估计从分档提升为**平滑拟合**(EIV/核回归),减少档界跳变。

### L2 闸门自证进化(趋势/方向/毒性,新)
- **核心思想**:闸门不再靠"特征→盈亏"拟合(已证伪),改靠**因果反事实**:
  每个闸拦截一条腿时,记入影子账本(已有 `dir_block_shadow.jsonl` 基建);定期
  结算"若没拦,这条腿实际会赚/亏多少"。
- **自证规则**:某闸近 N 次拦截的**影子净 > 0(拦对了,省下亏损)且超过维护成本
  (被拦好腿的机会成本)** ⇒ 维持/加强;影子净 < 0 ⇒ 放宽/关闭。阈值调整自动
  提案,单变量,快判回滚。
- **滞后参数(h711 hold)同理**:影子结算按"拦下时段"归因,hold 时长与行情持续性
  的实测分布对齐,而非固定 900s。
- **方向卡**并入同一框架:方向卡每次"封 side"也是一次拦截,影子结算它。

### L3 选币 bandit 自进化(新)
- **状态空间**:候选池(~28 币,深度采集覆盖);动作=宇宙组合(6 槽)。
- **每币后验**:滚动窗口每腿净 bp 的均值 + 不确定度(样本数/方差);老样本指数
  衰减(edge 会漂移)。
- **决策**:UCB/Thompson 风格(后验上限选取),**切换成本显式入目标**:
  切换收益必须 > 冷启动成本(实测 0-30min 档每腿低 ~5bp × 预计驻留腿数)。
- **驻留**:最短驻留由"后验不确定度"决定(新币/久别币长驻留),而非固定 1h。
- **输出**:提案宇宙组合 → DSH 桥复核 → 落库 → 该组合的每腿净入后验(闭环)。

### L4 元层:记忆 + 协调 + 治理(已有雏形,补齐)
- **记忆**:playbook(定律+证据+翻转史)与经验账本(决策+结果)由**各层自动写入**;
  DSH 桥每次决策前读 playbook 作先验(已实现)。
- **协调**:桥提醒统一收口 A(自进化请求)/B(机械曲面)两个文件(已实现);
  阶段 2 增补 C(闸门影子结算报告)/D(选币 bandit 提案)。
- **治理铁律**(不变):白名单+边界、单变量、rollback 必带、2h 快判、自动回滚、
  paper/live 同配置、lane_ledger 只追加。

## 五、独特之处(与通用 ML/RL 交易系统的区别)

1. **学什么的分界是证据,不是口号**:L12 实测"预测不可为/结构可为"后,系统被
   设计成"机械关系上学习、噪声上只做方差封顶"——不做端到端神经网络预测单腿盈亏。
2. **闸门的因果自证**:通用系统把闸门当分类器训练;本系统把闸门当**受审对象**,
   每笔拦截都要用影子反事实结账。闸门留着,是因为它证明了自己省钱。
3. **bandit 里的切换成本来自本系统的实亏**(L9 冷启动档),不是文献参数。
4. **双车道 + 快判 + playbook** 构成"带记忆的 A/B 试验场":每个决策都是预注册
   试验,失败自动回滚并写进记忆——**系统的进化本身就是可审计的实验史**。
5. **DSH(deepseek v41 flash)是元层推理引擎**,不碰交易热路径:证据→文件→桥
   复核→护栏落地。推理与执行彻底分离。

## 七、风险与不可做清单

- **不可做**:端到端预测单腿盈亏(已证伪);放松已验证的机械护栏换腿速;为追
  预测能力放宽闸门而不做影子自证;dict 参数走 CLI 逗号分裂路径(2 次事故)。
- **主要风险**:①后验被慢漂移欺骗(对策:指数衰减+变点检测);②影子反事实的
  幸存者偏差(被拦腿若没拦,其路径会不同——只做**短窗反事实**,5-15s 内结算);
  ③bandit 探索烧钱(对策:探索预算上限,每日探索腿数封顶)。

## 八、增长路线图(受 L14 约束,2026-10-02 修订)

**铁律(新增 L14)**:每腿净随名义单调递减(3 天 5045 腿,两行情一致)——**规模
增长不能走放大单腿**,只能走**广度**。由此重排全部增长路径:

| 台阶 | 指标 | 动作 | 前提 |
|---|---|---|---|
| 0 稳定正净 | 每腿 +0.5~1bp、连续 5 交易日正净 | 捕获档(c 档 1-2bp)+ 趋势期保护 + 闸门自证 | 当前自进化循环 |
| 1 小额广度 ×2 | 宇宙 6→12 币(每腿仍 ≤$20) | bandit 选币扩槽 + 深度池扩容(已具备 28 币采集) | bandit 影子胜率 >50% |
| 2 日净 +1~2U | s<20 档 × 更多币 | 复利改"广度复利"(币数),每档快判 | 台阶 1 稳定 |
| 3 双车道 | 纸面+实盘同配置跑 | 实盘 Key(待用户)+ 最小试跑 $500 | h665b 手册 |
| 4 月名义 $1M | 当前 $0.86M/月(48 腿/h × $20 × 24h) | 台阶 1+3 | — |
| 5 返佣 MM1 | 月名义 $150M(需 ×174) | **资金规模注入,不是策略改进** | 外部资金 |

**结论**:策略侧的天花板是"稳定小额正净";MM1 返佣是资金规模问题。系统进化的
目标因此**收敛**:把每腿净做正并保持稳定(台阶 0),其余交给广度与资金。
