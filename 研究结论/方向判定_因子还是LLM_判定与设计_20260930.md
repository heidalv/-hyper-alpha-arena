## 0. 一句话结论

**方向判定交给因子(确定性规则),LLM 退出方向判定链路。**

- 路一"LLM 在线判方向":已被你自己的实盘否决(h626 上线即停),而且不是提示词问题,是输入问题(§1.1)。
- 路二"因子判方向":方向证据全部来自你的因子研究(统一流定律、h324、h365、VPIN、形态×流),且**代码全部建好,只是开关全被设成 0**(§1.2)。
- 路三"融合":正确姿势是**分工**——因子在线判方向(秒级、确定性、零成本),LLM 离线当研究员(提案→回测→试跑→判决,对线上报价零权限),可选影子 A/B。**不是**"LLM 在线判方向 + 因子打辅助"。

## 2. 原 LLM 设计错在哪(精确三点)

1. **给它污染输入**:读"最近 60 分钟成交账本"判方向。h369 已证成交时刻归因被被动成交机制机械污染——买腿成交必然发生在卖流砸入时。LLM 读的是这面污染的镜子,方向信息为零,它只能编。提示词写得再好,输入里没有信号。
2. **让它做确定性规则就能做的事**:"ASTER 停卖"= `judge_direction()` 一个函数(已写、已有 5 条测试,min_n=15/worse_bp=−2/gap_bp=2)。LLM 在这件事上只增加 25s 延迟、API 成本、0.2 温度噪声,不增加任何信息,还不可回放。
3. **频率错配**:方向是秒级信息(OFI/趋势/微价),卡是 5 分钟一张;而且这些方向因素在报价器内部**已经算好**,只是闸门全被设成 0——不需要一个外部模型重新发明它们。

## 4. 设计 B:每币×每边慢闸(替换已停的 LLM 方向卡,确定性)

- **直接用已写好的 `judge_direction(min_n=15, worse_bp=−2.0, gap_bp=2.0)`**(`direction_card.py`,已有 5 条测试)替换 `ask_direction_flash` 的调用点。它是确定性的:每币最多停一边、样本不足不停、两边分不开不停。

- 四个硬闸保留(禁停两边/禁停减仓侧/不足 15 笔不停/禁全车道单向)——这四条本来就是规则,LLM 只是夹在中间的噪声,抽掉 LLM 这四条一个不少。
- 收益:0 API 调用、0 延迟、任何一张历史卡都能离线重算验证。

## 9. 与选币宇宙的融合配合(方向层 × 宇宙层,同一哲学:动态、可逆、无禁令)

> 方向卡(5 分钟,逐币×逐边)与选币器(6h,逐币)本质是**同一台质量雷达的两个时间尺度**。
> 融合不是新造一条链路,是把已有件接上同一份事实源与同一套治理。

### 9.1 共同事实源:quote-time 归因成为唯一口径
- h402 已把 `quote_ts` 落进 lane_ledger;d1_verdict 的"移动库存法往返重建 + 挂单时刻趋势分桶"提炼为共享模块 `backend/services/market_maker/attribution.py`;
- 三个消费者共用:①方向卡(judge_direction 输入)②D1/各闸判决脚本 ③宇宙 v5 的 L3 评分与衰减检测;
- 收益:宇宙评分与方向判决从此同一口径,不再"各算各的"(此前 h329 影子模拟与实盘归因就是两套)。

### 9.2 宇宙给方向配闸:`pattern_matrix`(h405 已有接线,零新代码)
- runner 已支持 `meta.pattern_matrix`(分形态×分币种启停表);
- 宇宙 v5 的 L2(形态×币匹配,vr60 滚动)直接写这张表:**反转族币开 P1/P2 闸,动量族币开 P4/P5 闸**,选币即配闸;
- 方向层不再需要自己判断"这币该用哪族形态"——宇宙层每 6h 滚动重算,形态闸跟着换,同一币从反转族变到动量族时闸自动切换(呼应"市场是流动的")。

### 9.3 方向卡参数随宇宙形状自适配(规则化,候选)
- `min_n = clamp(round(0.25 × 该币该边 60 分钟腿频基线), 12, 30)`:大币腿频高 → min_n 上调(20+)减少滞后打脸;宽价差山寨腿频低 → min_n 下调(12)让卡尽早动作;
- 上线方式:作为 D1 判决后的独立单变量试跑,预注册判决口径(封边命中后该边逐腿 bp vs 同期不封反事实),不通过则回退 min_n=15。

### 9.4 治理互锁:一条试跑链,两层共用
- `lane_registry.meta.trial_active`(v5 L0)是两层共享的互斥锁:**任一层的试跑未判决,另一层冻结宇宙且冻结参数**;
- 判决链统一:预注册 → 12h 单变量 → Welch(α=0.10,H372 口径)→ 清标记/回滚置 0;
- 今天的手工 `schtasks /DISABLE`(宇宙)与 D1 试跑(方向)都是这条链的实例,后续由 `trial_active` 统一表达。

### 9.5 统一 KPI 与月度裁决
- 唯一总 KPI = 逐腿净 bp(quote-time 归因口径);分层归因:
  - 宇宙贡献 = 在槽币 L1 可行性(滚动 spread_ok_share)是否达标、换币前后的 bp 差;
  - 方向贡献 = 方向卡/D1 封掉腿的反事实净 bp(用 9.1 共享归因算);
  - 出场贡献 = 出口分类账 + trail_lock 反事实(H387/388 口径);
- 信息闭环:
  ```
  市场数据 → 滚动可行性(L1) → 候选池 → 宇宙提案 → 微试跑 → apply
        ↓
  meta.symbols + pattern_matrix(L2) + 价差档
        ↓
  runner:方向卡(5min) + D1 趋势(秒) + 形态闸(pattern_matrix)
        ↓
  quote-time 归因 → 反向喂 L1/L3 滚动评分 + 各闸判决
  ```
- 落地顺序不变(方向):先 D1 判决(23:50)→ 实现宇宙 v5 预览 → 新币微试跑 → apply;`pattern_matrix` 随 v5 首次 apply 一起写入。
