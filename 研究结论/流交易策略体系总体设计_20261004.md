# 流交易策略体系总体设计(形态 → 策略 → 进化)

**生成:2026-10-04 | 用户指令:"建立一个体系:多种策略形态、数据方位、哪种形态用什么策略、
进行什么腿速、入场和出场,并且策略不断进步和完善。仔细设计。"**

## 0. 一句话架构

```
数据方位(市场状态) → 形态分类器(判当前是什么市) → 策略表(该形态用哪个策略)
→ 执行(入场/出场/腿速/持仓时限) → 往返归因(每策略自己记账)
→ 进化循环(每策略的参数独立裁决 + 形态判据反哺调优)
```

**做市时代是"一个策略对所有市场";新体系是"每种市场状态一个策略,策略之间
互相独立地进步"。**

## 2. 形态分类器(regime,用数据方位判定)

| 形态 | 判据(初版阈值,进化循环会调) | 语义 |
|---|---|---|
| **R1 趋势流** | \|OFI\| ≥ θ_f 且 sign(OFI)=sign(300s 趋势) 且 σ 中等 | 有明确方向的强流市 |
| **R2 平静回归** | \|OFI\| < θ_f 且 \|300s 趋势\| < θ_t 且 σ 低 | 无方向的震荡市 |
| **R3 挤压突破** | σ 从低位抬升 且 OFI 突增(ΔOFI 大) | 蓄力后的爆发 |
| **R4 高波跳空** | σ > σ_hi 或 24h 振幅 > 15% | 危险市(规避/只顺流) |
| **R5 枯竭盘** | 该币成交率 < θ_liq | 没对手方(降频/暂停) |

**判定频率:每 tick(形态瞬时)+ 每 5 分钟(形态持续性窗口)。**

## 3. 策略目录(形态 → 策略 → 入场/出场/腿速/时限)

| 策略 | 适用形态 | 入场(全部 taker 真实价) | 出场 | 腿速 | 持仓时限 |
|---|---|---|---|---|---|
| **S1 流顺势** | R1 | \|OFI\|≥θ_f 且与 300s 趋势同向 → 市价进场 | TP60 / SL40 / 流翻转 / **90s 硬顶** | 高(每个流脉冲一次) | ≤90s |
| **S2 回调接刀** | R1(趋势中的回调) | 60s VWAP 偏离 ≥N bp 且 OFI 回归 → 逆回调进 | TP / SL / 趋势破位 | 中 | ≤180s |
| **S3 均值反转** | R2 | 偏离 60s VWAP ≥N bp 且无强流 → 逆势进 | 回 VWAP 出 / SL | 低 | ≤300s |
| **S4 挤压突破** | R3 | σ 收窄后流突破方向 → 顺突破进 | TP / SL / 回抽 | 中 | ≤120s |
| **S5 避险** | R4/R5 | 不进场(仅持平已有仓) | 已有仓速平 | 0 | — |

**注:以上是**初版策略骨架** —— 每一格(阈值/TP/SL/时限/腿速)都是该策略的
独立参数,由第 5 节的进化循环持续改进,而不是一次性定死。**

## 4. 腿速政策(每种形态的节奏)

| 形态 | 腿速目标 | 理由 |
|---|---|---|
| R1 趋势流 | **高**(≥20 往返/时/币) | edge 在 5~30s(h690),流脉冲密集 |
| R2 平静 | 低(≤3/时/币) | 无 edge,只在极端偏离时出手 |
| R3 挤压 | 中 | 突破事件驱动 |
| R4/R5 | 0 | 危险/无流动性 |

## 5. 进化循环(策略如何"不断进步和完善")

**每策略独立五件套:**
1. **独立记账**:每个策略自己的往返 KPI(h803 扩展为按 strategy_id 分组:
   胜率 / 平均往返净 / 各离场路径分布 / 平均持仓);
2. **独立裁决**:每个策略的参数(阈值/TP/SL/时限)用 verdict 机制单独试跑
   (单变量 + rollback + 30min 快判,判据 = 该策略自己的往返净,不是全局每腿净);
3. **形态判据反哺**:形态分类器的阈值(θ_f/θ_t/σ_hi…)也用"该形态下策略的
   表现"来调 —— 某个形态长期亏钱 ⇒ 要么收紧它的入场判据,要么把它降为避险;
4. **Playbook 分页**:定律按策略分页(R1/S1 页、R2/S3 页…),不再全局混记;
5. **新策略孵化**:新形态/新入场方式先在**影子模式**并行跑(只记账不交易),
   往返 KPI 连续 N 小时为正 ⇒ 晋级正式策略(L4 微试跑的通用化)。
