# 腿速自适应(Q 速控)设计(2026-09-30,用户提案,已验证可行性)

> 用户命题:盘口质量好就提速,质量差就减速/先停下,等质量转好或该币被宇宙轮换淘汰。
> 状态:可行性已证(实证 + 既有零件清单),设计待排期;减速侧可先行,提速侧须影子验证先行。

---

## 0. 结论:可行,而且 80% 零件已经在线上

"质量闸"早已散落在系统里,只是**二进制、各自为政**:
跳价暂停 / 波动暂停 / 方向卡(逐币×逐边) / 趋势闸 / OFI 毒性 / 库存闸 = 都是"质量差→停";
宇宙 v5 的 L1 滚动价差+衰减检测 = "质量差→换币"。
缺的只有两件事:
1. 把这些二进制闸统一成**一个连续的 Q 分数**(逐币,滚动 15 分钟);
2. 给它**滞后再武装**(质量转好不立刻提速,防打脸——book_slot 180s dwell 已有此先例)。

## 1. 为什么可行(证据)

| 证据 | 内容 |
|---|---|
| E1 收益决定项 = 逆选择 | 24h 小时桶:捕获 cap 恒在 +0.01~+0.20bp,净 bp ≈ −adv(逆选择 −0.4~−3.4bp 摆动)。**"质量差"=adv 深负的时段**,正是该停/该慢的时段 |
| E2 选择性停已被验证 | 方向卡+D1 把逐腿 bp 从 −1.71 抬到 −0.77(p=0.0097)——"停掉差的那部分"是已验证的正收益操作 |
| E3 动作参数全部存在 | 腿量:per_symbol_size_mult / compound_ratio;停:各加仓闸;宽度:spread_mult;换币:v5 L1 衰减。**零新参数,只加一个分数层** |
| E4 减速侧天然安全 | 减速=少做=少亏(费用/逆选择同时降);提速侧每腿 edge 薄(+0.4bp),多做的边际风险 > 0 ⇒ **提速侧必须影子验证先行** |

## 2. Q 分数(逐币,滚动 15 分钟,全部用现有数据)

```
Q = 0.35×spread_ok_share     # 价差可行性(book ticker,已有 L1 口径)
  + 0.25×fill_rate_norm      # 成交活跃度(该币近 60 分钟腿数/基线)
  + 0.25×capture_norm        # 贴盘口质量(账本 spread_bp 滚动,quote-time 归因)
  + 0.15×(1 − |m30|_norm)    # 逆选择(markout 探针,h624 已有)
  − toxic_penalty            # VPIN/OFI 持续性毒性(已有数据;初版可置 0)
```
权重为初版建议值,**影子期用 Q 分桶收益标定后冻结**(见 §4)。

## 3. 动作表(滞后再武装,dwell 5 分钟)

| Q 区间 | 动作 | 参数路径 |
|---|---|---|
| Q ≥ 0.7 | 全速;提速档(×1.25 腿量)留待影子验证后启用 | per_symbol_size_mult |
| 0.4 ≤ Q < 0.7 | 半速(腿量 ×0.5) | per_symbol_size_mult |
| Q < 0.4 | 停加仓(减仓豁免),dwell 5min;再武装条件 Q ≥ 0.5(滞后带 0.1) | 与现有加仓闸并行,不重复封 side |
| Q < 0.4 持续 ≥ 3h | **写宇宙 v5 衰减标记** → 下轮选币轮换该币(淘汰换新币) | v5 L1 联动 |

**正交性**:方向卡/趋势闸管 **side**(哪边),Q 速控管 **speed**(做多快)——两个轴互不覆盖。

## 4. 验证先行(影子 12h,启用前必做)

1. Q 分数只算不动(影子),12h 后按 Q 分桶的逐腿净 bp(quote-time 归因):
   低 Q 桶 vs 高 Q 桶 Welch α=0.10——**若低 Q 桶显著更差(E1 已预示方向),减速侧启用试跑**;
2. 提速侧(×1.25):单独反事实——高 Q 桶里"若当时加码"的净贡献,正才启用。

## 5. 预注册试跑(减速侧先行)

| 项 | 值 |
|---|---|
| 变更 | Q<0.4 停加仓 + 0.4~0.7 半速(per_symbol_size_mult 由 Q 表驱动),dwell 5min,滞后带 0.1 |
| 判决(12h) | 主指标:低 Q 桶腿数占比下降 + 总体逐腿净 bp 上升(Welch);副指标:腿数 ≥60/h、日亏闸不触发 |
| 回滚 | Q 速控总开关置 0(参数 `q_speed_gate=0`,默认关) |
| 排期 | 出口修复包判决(次日 06:15)之后;与 min_n 自适应、pattern_matrix 同队列 |

## 6. 与出口修复包的关系

出口修复包解决的是"腿开了之后怎么收场";Q 速控解决的是"该不该开、开多快"。
两者同向不冲突,但按单变量纪律**顺序执行**:包判决 → Q 速控影子验证 → 减速侧试跑。
