## 一、风控官（有否决权）—— 修掉"宪法三项空转"

### 1.1 实测缺陷（本轮修的就是它）
`risk_constitution.constitutional_veto` 设计上是"最后红线"（env 不可覆盖），
但调用点 `mlto/brain.py:1864` **只传了 `account_id/symbol/side/sl_pct`**，
`equity_usd`/`margin_usd` 从未传过 ⇒ 三项检查**从未生效**：

| 检查 | 守卫条件 | 结果 |
|---|---|---|
| 单笔保证金占净值硬顶（>20%） | `if equity > 0 and margin > 0` | 恒假 ⇒ **空转** |
| 日亏损硬停（≥6%） | `if account_id is not None and equity > 0` | 恒假 ⇒ **空转** |
| 单币 30% / 总 60% 敞口上限 | 同上 | 恒假 ⇒ **空转** |

即"宪法级风控"过去只兑现了 1/4（只剩止损幅度校验）。

### 1.2 实现
- 新增 `backend/services/risk_officer.py`：显式角色，判定 = ①宪法红线（**传全参**）
  ②名义暴露硬顶（计划名义/净值，不依赖杠杆口径）③辩论风险姿态（主周期 reject 且风险共识 < 阈值 ⇒ 否决）；
  **每次判定落库** `alpha_analytics.risk_officer_decisions`（输入实参 + 逐项检查 + 结论 + 辩论姿态）。
- 接到**下单前唯一同时拿得到 权益/计划名义/杠杆** 的位置：
  `full_auto/midlong_helpers.try_execute_independent_agent_open`（`_extra_kwargs` 之前）；
  否决 → `risk_officer_veto` 事件 + `_audit_skip` + `return False`。
- 模式差异**显式**：paper 默认豁免"日亏损硬停"（`RISK_OFFICER_PAPER_DAILY_LOSS=false`，
  与 `PB_PAPER_SKIP` 同立场、遵从用户 09-11「允许小仓位」），豁免写进 `checks.skipped_paper`。
- `brain_debate` 补齐分周期字段 + 新增 `debate_context()` 读口（跨进程不丢姿态：
  子进程写辩论、主进程执行开仓）。

## 二、六域信号进混合打分（**先影子**）

- `analysts/service.blend_for_symbol()`：六域按权重合成 [-1,1] `analyst_score`
  （technical .30 / flow .25 / sentiment .20 / fundamental .10 / macro .10 / kline_deep .05，可 env 覆盖）；
  · **只在有信号的域之间归一化** —— 缺产域不摊薄、也不当 0（否则等于假装"中性"）；
  · 低信心域按 `max(0.2, conf)` 减权；· macro 为全局信号，所有标的都吃；
  · 有界混合：`blended = conviction × (1 + gain × analyst_score)`，gain 默认 0.15。
- 影子落库 `analyst_blend_shadow` + `blend_shadow_report()` 对照报告；
  brain 每轮记录并打日志 `[MidLongBrain] 混合打分(影子) …`，**默认不改任何行为**
  （`ANALYST_BLEND_APPLY=false`；改 conviction 属策略变更，先看差异分布）。
- 实测影子样本 6 条：会改变 3 条，Δ 区间 [-0.99, -0.27]（都在"略微降权"方向）。

| 观测 | 事实 |
|---|---|
| 辩论对 conviction 的调整（近 2h） | 5 次：BNB 43→25、AVAX 43→36、ETH 40→24、AAVE 40→24、SEI 40→24（日内 reject/reduce） |
| 11:25 之后新开仓 | **0 笔** |

| **风控官是否拦了 AAVE** | **没有**（`risk_officer_decisions` 无 AAVE 行；仅单测的 TESTCOIN 2 行） |
| 定位线索 | 11:53 起 AAVE 已进入**长线** AI 宇宙（`ai_long=['AAVE']`）；11:55 扫单只跳过 BTC（`probe_entry:waiting_pullback`）⇒ 疑似"推荐后未在它仍属中线宇宙的窗口内被扫到" |

**结论（如实）**：不是新模块误拦；但"推荐→成交"之间确实存在缺口（推荐时效 vs 宇宙重排 vs 尺寸地板），
已列为下一步定位项。同时辩论乘数已做成 env 可调，便于按实测软化：

```
MIDLONG_DEBATE_REJECT_MULT=0.6        # 主周期 reject 的乘数（实测 40→24）
MIDLONG_DEBATE_REDUCE_MULT=0.85       # 主周期 reduce 的乘数
MIDLONG_DEBATE_CONVICTION_FLOOR=10    # 生效下限（防"事实静默"）
```
