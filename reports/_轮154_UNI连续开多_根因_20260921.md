## 一、结论（一句话）

**分析没有说开多 —— 分析说的是"不追高、观望、等 4h 企稳"，是代码把这句话改成了"开"。**
`brain.py::promote_open_if_in_zone`（797-868 行）在"现价落入模型自己给的入场区"时**无条件**把
`recommend_open` 从 `false` 改写成 `true`（无置信门槛、无开关、无日志、无落库标记），
于是下游 `open_gate` 的"底线 4：尊重 LLM recommend_open=False"**永远看不到那个 false**。
再加上唯一能减小损失的缩仓结果被 paper 路径丢弃 ⇒ 同一形态被"看出来"多次，却每次都以满档规模开进去。

## 四、四个具体缺陷（都能定位到行）

### 缺陷 1（根因）：`promote_open_if_in_zone` 把模型的"不开"改写成"开"

`backend/services/mlto/brain.py:797-868`：

```python
def promote_open_if_in_zone(final, *, last_price, has_position=False, atr_pct=None):
    """无仓 + 方向明确 + 现价已在 entry_zone → 强制 recommend_open=true。
    模型常写「等回踩」却把 recommend_open 留 false；入场区是它自己给的数字契约，
    现价已落入则视为条件达成，避免永远观望。"""
    ...
    in_zone = lo <= px <= hi
    chase_long = direction == "long" and hi < px <= hi * (1 + _tol)     # 追高容忍 ≤1×ATR
    if in_zone or chase_long or chase_short:
        out["recommend_open"] = True                                     # ← 无置信门槛
        out["_promoted_open"] = "entry_zone_touched" if in_zone else "entry_zone_chase_tol"
```

- **全库只有这一处把 `recommend_open` 置 True**（`grep` 实测：`brain.py:843/864`，其余是读取）。
- 它**没有置信门槛**（对比进取档要 conf≥0.5）、**没有开关**（`MIDLONG_AGGRESSIVE_ENTRY` 只管下面那段）、
  **不写日志、不落库**（`_promoted_open` 标记全库无人消费 ⇒ 日志里 0 命中，审计完全看不到）。
- 它跑在 `open_gate` 之前，所以 `open_gate.py:167` 那条
  「底线 4：尊重 LLM 的 `recommend_open=False`（AI 自己说不建议开仓）」**在结构上不可能命中**。

**现场证据**：论题 `982fc260`（UNI mid，驱动这三笔，`review_count=223`）的字段与模型原始输出**互相矛盾**：

```
thesis 落库字段：direction=long   recommend_open=1   accepted=1   llm_conviction=47
reasoning_snapshot（模型 MiniMax-M3 原始 JSON）：
    {"direction":"neutral","strength":3,"confidence":0.35,"recommend_open":false,"should_close":false,…}
thesis_summary（同一行）：
    "…且 UNI 近 14d 同向多头连续三笔 -1.77%~-1.96% 止损、相似情景 5 例中 1 例止损，故**不追高**。
      现价 8.649 相对入场区 8.55-8.75 基本贴沿，但短周期动能未止跌、追入风险回报不佳，
      **选择观望等 4h 企稳信号**。"
```

**用户的观察（"近三笔连续止损"）就写在论题摘要里**，模型也把 `recommend_open` 设成了 `false`，
`direction` 甚至是 `neutral` —— 落库却成了 `long / recommend_open=1`。唯一能做到这个改写的函数
就是 `promote_open_if_in_zone`（现价 8.649 落在它自己给的 8.55-8.75 区间内 → `entry_zone_touched`）。

### 缺陷 2：`MIDLONG_AGGRESSIVE_ENTRY` 默认 true —— 价格离场区很远也照追

`brain.py:850-867`：方向明确 + `conf ≥ MIDLONG_AGGRESSIVE_MIN_CONF`（默认 0.5）时，
即使模型把入场区设在远处等回踩，**也按市价直接开**（`aggressive_market_entry`）。
`.env` 未设该键 ⇒ 走默认 **true**。注释写明这是"[2026-09-08 进取模式] 用户拍板"。

### 缺陷 3：辩论裁决没有任何消费方（承诺的消费方不存在）

- `brain.py:1642-1659`：`apply_conviction_effect()` 结果只用于一条日志；注释自陈
  「待"**规模链消费 debate_size_mult**"落地后再启用数值生效」。
- 实测 `grep debate_size_mult` 全库**只命中这条注释本身** ⇒ 该消费方**从未实现**。
- 后果：`MIDLONG_DEBATE_APPLY=false` ⇒ 三周期 `reject` + risk=0.25 对开仓**零影响**。

### 缺陷 4：`RISK_OFFICER_VETO_ON_DEBATE_REJECT` 名不符实

`risk_officer.py:192-211`：开关名是"按辩论 reject 否决"，但代码只在**方向相反**时否决：

```python
pv = str(debate.get("primary_verdict") or "")          # ← 取出来只写进 checks，从不判断
opposes = bool(dd in ("long","short") and side_l in ("long","short") and dd != side_l)
```

熊方辩论行的 `proposal.direction` 是 `long`/`neutral`（不是 `short`），`net_sentiment` ≈ 0
⇒ `opposes=False` ⇒ **allow**。实测近 1h UNI 的 23 条风控官判定全部 allow。
（`_probe163`：UNI 熊方 4+ 轮的论证正是用户的话——"30d +109~113%、距 EMA200 +111~115%、
1d RSI 75~76 超买、ls 1.8~1.9 多头拥挤、**此时做多本质上是接一把已经在空中的刀，期望值显著为负**"。）

### 缺陷 5：六层缩仓的结果在 paper 路径被丢弃（钱的问题）

- `proposal_execution.py` 把链条结果写进 `dec["size_multiplier"]`（本例 `0.0008 → 0.0714`，目标 $60 名义）。
- 但 **`paper_execution.py` 全文 0 次读取 `size_multiplier`**（`grep` 实测）；
  实际下单规模来自 `position_memory_manager.evaluate_trade` 的 tier 目标：
  `notional = equity × MIDLONG_TIER_MARGIN_PCT_MID(0.10) × leverage(3)` = **$1387**
  （`.env` 实测这两项：`MIDLONG_TIER_MARGIN_PCT_MID=0.10`、`PC_MAX_WEIGHT_PER_SYMBOL_MID=0.15`），
  再被单币帽压到 `$4621×0.15 = $693` 名义 / **$231 保证金**。
- 对照：**实盘路径读了它**（`live_trading.py:451-463`「下游缩仓乘子必须计入敞口估算」）。
  ⇒ 模拟盘（训练数据）按 11.5× 于风险链意图的规模成交。
- 全日志实测：`[SizeFloor] PROBE-CLAMP` **289 次**、`BLOCK` 72 次
  —— 这只说明风险链**频繁**想缩到 $60，而每次都没生效。

**钱的口径**：本例每次止损 −$12.5 ≈ `693 × 1.7%`；若按链条意图的 $60 名义 ≈ **−$1.05/次**。
7 次止损的差额 ≈ **−$80**（占这三天 UNI mid 净亏 −$47.5 的全部来源）。

## 七、为什么"不是冻结的问题"

- 每一次开仓都发生在**止损后 30~120 分钟**（再入场冷却已生效），冻结只会把同一笔强制开仓推后；
  02:39 止损 → 03:10 再开、05:02 止损 → 07:04 再开，节奏正是被冷却闸塑形的。
- 分析层**已经识别**该形态（论题摘要直接引用"连续三笔止损"、熊方给出"接飞刀"论证），
  缺的是**让分析的话算数**：现在的链路上，唯一被消费的是 `direction`（恒为 long 的偏置）与
  `conviction`（47~52 的一维数字），散文结论与辩论裁决都被当成描述性文字。
