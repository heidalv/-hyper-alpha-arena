## 〇、一句话结论

**系统不是"坏了"，而是被历史亏损一步步改造成"防御优先"形态：每发现一条亏损路径就加一道闸，30+ 层闸叠加后，信号→成交的通过率只剩 2~3%（多头）、<0.5%（空头）、0%（短线已整体关闭）；而唯一能产生"新样本→校准→学习"的数据流正是交易本身——闸把数据源掐死，校准器（p_win=0.393）就永远停留在旧的负期望估计上，形成"EV 负→硬拦→零成交→无新样本→EV 恒负"的死亡螺旋。**同时实盘侧根本没有接通（唯一 live 会话 8/31 手动暂停、交易所凭证缺失、套利实盘路径硬编码关闭），系统实质是"纸盘研究档满负荷空转"。** 三条链（AI 决策 / 因子挖掘 / 学习进化）各自真实运行、通过"证据注入提示词 + 软约束 + 硬闸"松耦合关联，但没有一条能驱动交易发生。**盈利 = 正期望车道 × 交易次数 × 仓位，三个因子现在全是 0 或负——这就是"垃圾"的根因，不是某一行的 bug。**

## 二、问题一："完全没有交易意愿"的直接原因（按证据强度排序）

1. **EV 闸死亡螺旋（当前最重）**：`midlong_ev_gate.py:88` 用校准器 p_win=0.393（trend_follow 历史 32 笔、胜率 0.375 的旧样本）算 EV = 0.393×13.4%×0.60 − 0.607×6.7%×1.0 − 0.42% ≈ **−1.3%** < 门槛 +0.08% → 硬拦。mid(swing) 车道 9/11 拿到了 paper 影子放行（`MIDLONG_EV_ENFORCE_MID_PAPER_ALLOW=true`），**但 long(trend_follow) 车道没有这个豁免**——所以"8 个候选 0 成交"是长期稳态而非偶发。拦→无新样本→校准器不更新→永远拦。**日志实证：每轮 `[MidLongEvGate] BLOCK ... EV=-1.3357%`，audit funnel 每 30s 全 skip。**

2. **learned 熔断窄带**：`midlong_circuit_gate.py:495` 多头只放行"up 且 chg24∈[3,6)"或"chop 且 pos≥60 且 chg≥2"，放行集实测仅 ~15%；空头需 down-regime + 三条件（pos≥60/RSI55-80/chg24≤−1%）→ 通过率再 ×0.05~0.1。**这道闸本身来自 9/9 根因报告的实证**（高位追多 24h 胜率 0.15-0.23），但它是"整方向窄带"，本质等于"大多数时候不交易"。

3. **位置闸**：`midlong_location_gate.py:237`——ranging 下 24h 区间分位 ≥60% 禁多。当前 BTC/UNI/ASTER 全在 60-93% 分位 → 天天拦。

4. **短线车道整体关闭**：`SCALP_OPEN_DISABLED=true` + `SCALP_MASTER_HARD_BLOCK=true` + 引擎层 `scalp_open_gate.py:11` 硬闸。短线在 9/9 被证明结构性负期望（144 组 walk-forward 无一存活）——关闭是对的，但**它同时把短线因子挖掘的消费者清零、把短线学习样本源清零**，属于"止血式报废"。

5. **实盘侧根本没接通**：唯一 live 会话 8/31 手动暂停；asterdex/hyperliquid 无凭证（`exchange_credentials` 仅 1 条 binance 8/28）；`arb_switches.py:104` 硬编码 live_trading_enabled=False（"Phase 5 未启用"）；TREND_E1_ENABLED / FUNDING_TAIL_LIVE / BASIS_LIVE / ARBITRAGE_ENABLED / EXEC_ALGO_ENABLED / FUSION_PROBE_DAILY_QUOTA_LIVE=0 全部关闭。**"不交易就不亏损"在实盘侧字面成立：没有任何一条路能到达真实交易所。**

6. **唯一有正期望证据的策略被搁置**：E1 趋势引擎（ema_stack 入场 + Chandelier 3×ATR20 出场，日线级，8 年回测 up 状态 20 日 +8.54% t=14）9/3 实现后 **TREND_E1_ENABLED=false 只跑观察模式**；其 F4 实盘门显示 trend_drift=2、leverage_violations=4、模拟 7/28 天——问题没被修复，只是被关着。

7. **叠加概率**：单信号→成交 ≈ 0.4(LLM 意愿)×0.15(learned 窄带)×0.6(位置/共识)×0.9(V5)×0.9(组合)×0.9(收口) ≈ **2.6%**（多头）。这不是单点 bug，是纵深防御的结构性结果。

**一句话：系统当前"完全防御"不是被某个人拉闸，而是 8/17~9/9 之间每一轮亏损整改都往链上加一道"不满足就跳过"的闸，闸叠加后把唯一能产生学习数据的交易行为自己杀死了。**

## 三、问题二：AI 自动交易 / 因子挖掘 / 学习进化——到底有没有真正的关联？

**结论：三者各自真实运行，但关联是"松耦合的证据链"，不是"一体化生产流水线"；且学习链的反馈方向当前是"越学越不交易"。**

### 3.2 三者之间的真实连接图（代码实证）

```
因子引擎(FactorEvo/GP/MCTS/LLM) ──TRADABLE 活跃集──┐
        │                                          ▼
        └──factor_route 投票(已降格,不开仓)──quant_brief 证据──→ LLM 主脑论题 ──hub 融合──→ 门禁 ──→ 订单
                                                                      ▲
学习闭环(outcome→memory/regime/Kelly/校准/教训/RAG) ────────────────┘
        (以 prompt 软约束 + 熔断硬闸 + EV 校准三种方式介入上面的决策)
```

- AI 决策链与因子链的关联 = **提示词证据**（quant_brief、活跃因子摘要、regime 矩阵、教训）——真实但权重低（LLM 权重 0.10、因子"证据非指令"）。
- 学习链与 AI 决策链的关联 = **软约束（prompt）+ 硬闸（熔断/EV/配额）**——真实，但当前净效果是减少交易。
- 学习链与因子链的关联 = **因子 IC/权重日更新 + 回测晋升**——真实，但晋升后的因子没有直接仓位映射权。
- **没有任何一条边是把"研究产出"变成"交易流量"的。** 这就是用户直觉上"没有真正关联"的代码级真相。

## 四、根因链（因果，非并列）

```
历史亏损（LLM 时代账户14 500→411 / 因子时代 5天-20.8%）
   └→ 每轮整改：发现负期望路径 → 加一道 fail-closed 闸（8/17~9/9，30+ 层）
        ├→ 信号→成交通过率 2.6%/0.3%/0%
        ├→ 新样本枯竭 → 校准器(p_win=0.393)/成熟度(8/16冻结)/学习矩阵全部停在旧负期望
        └→ EV 闸按旧数据硬拦 → 零成交 → ……（死亡螺旋闭环）
   └→ 正期望引擎被闲置：E1 趋势引擎(唯一回测 t=14 的策略)关着；MM 做市直到 9/13 才转进攻
   └→ 实盘侧从未打通：live 会话暂停 + 凭证缺失 + 套利实盘硬编码 False
   └→ 结果：盈利 = 正期望车道×次数×仓位 = 0×0×0 = 0；"不亏"成了唯一可能的结果
```

**最深的根因是一句认知错误**：把"止损优先"误解为"不做就不亏"。量化系统的亏损治理应该靠**正期望车道 + 仓位纪律**，而不是靠"少交易"——少交易不仅不产生收益，还饿死校准器和学习系统，让系统永久停留在旧数据的错误结论里。

## 五、分模块整改设计（为每个断/缺模块单独出设计；本轮只设计不实施）

### M1. 打破 EV 死亡螺旋（当前最优先，1 天可完成）

- **目标**：让 paper 模式下 long(trend_follow) 车道与 mid 车道同等待遇——影子放行、积累新样本，live 保护完全不变。
- **方案**：新增 `MIDLONG_EV_ENFORCE_LONG_PAPER_ALLOW=true`（镜像既有 `MIDLONG_EV_ENFORCE_MID_PAPER_ALLOW` 的成熟模式：`midlong_ev_gate.py:192-195` 同款逻辑，paper 下记录判定不拦截）；live 硬拦不变（`shadow_lane` 语义完全复用）。
- **配套**：校准器样本窗口加**修复切点**（2026-09-11 F38 上线）——9/11 前 32 笔 trend_follow 是"修复前口径"（含去 LLM 时代的负期望结构），9/11 后 after 侧 6 笔全赢单笔 +6.01；校准应可选"仅取修复后窗口"或至少按时间衰减。不然即使放行，p_win=0.393 会把新样本也污染。
- **验收**：paper 下 long 车道每日开仓从 0 → ≥2 笔；EV 影子日志可见；live 路径行为逐字节不变（契约测试锁定）。

### M2. 恢复 E1 趋势引擎 = 唯一有回测正期望的策略（2-3 天）

- **现状**：`trend_e1_engine.py` 完整实现（8 币日线、ema_stack 入场、Chandelier 3×ATR20 出场、目标权重 60/30/10、日任务 cron 00:20），但 `TREND_E1_ENABLED=false` 只跑观察；F4 门显示 trend_drift=2、leverage_violations=4。
- **方案**：①先修 drift=2 与 leverage_violations=4 的成因（E1 目标与账户 14 存量仓不一致——`TREND_E1_ADOPT_LEGACY_LONGS=true` 已设计接管，需核查接管为什么没清零漂移）；②`TREND_E1_ENABLED=true` + `TREND_E1_DRY_RUN=false` 在 paper 账户 14 实跑；③保持 F4 门禁为实盘前置（4 周模拟 → 费用/漂移/停机测试全过才允许 live），**但把 F4 的"模拟 28 天"倒计时从现在开始认真跑起来**。
- **理由**：这是系统里唯一通过 8 年回测（up 20 日 +8.54% t=14.08）+ walk-forward 的规则策略；日线级、低手续费占比、持仓月级——与"45s LLM 噪声"天然隔离。它不依赖 LLM 意愿、不依赖因子晋升，是当前最干净的盈利候选。
- **验收**：paper E1 日任务开始真实下单；4 周后 F4 各项读数正常演进；trend_drift→0。

### M3. 中长线车道收敛：LLM 做研究，规则做执行（3-5 天）

- **问题**：日线级策略被 45s 频率的 LLM 论题 + 30 层门禁反复折腾（长线设计 V2 早已论证：频率错配/数据错配/机制错配）。
- **方案**（对齐《长线趋势策略重构设计 V2》+ E1 现状）：
  - long 车道执行权**完全交给 E1**（`TREND_E1_LONG_LANE_EXCLUSIVE=true`），LLM 主脑不再对 long 车道出开仓指令，只做每日复盘（`LONG_REVIEW_CADENCE_HOURS=24` 已设计）。
  - mid(swing) 车道保留 LLM 主脑 + 因子证据，但**门禁从"全拦"改为"缩仓"**：learned 窄带之外一律影子记录 + probe 缩仓（margin×0.25），而不是 hold——mid 车道是因子/学习链唯一的活样本源，必须先保证样本流量。
  - 空头：维持关闭（9/9 报告实证任意持有期全负），但保留"down-regime + learned 三条件"的窄带在 paper 影子收集样本。
- **验收**：paper 日开仓量稳定 ≥5 笔/天（样本流速）；每笔拦截都有证据编码（已有）；long 车道不再出现 LLM 与 E1 双重管理冲突。

### M4. 门禁体系重新标定："paper = 数据工厂，live = 纪律堡垒"

- **原则**：paper 模式唯一的使命是产生**带成本真实性的样本**；一切"学习型拦截"在 paper 下改为"影子记录+缩仓"，live 下保持全量硬拦（已有 PB_PAPER_SKIP、EV mid paper allow、loss_lock paper 禁用的先例，扩展即可）。
- **清单**（按当前拦截频次排序）：
  1. EV 闸 long 车道 paper 影子放行（M1）；
  2. learned 熔断窄带：paper 下窄带外从 hold 改为 probe（缩仓 0.25）——与 9/11 F38c mid 车道同款政策；
  3. 位置闸：paper 下从 veto 改为缩仓+记录（保留 live veto）；
  4. maturity_state：恢复定时调用（`run_maturity_tick` 挂 scheduler），消除 8/16 冻结；
  5. QAA rating 断点：`qaa_backend.py:33` 传真实 decision_quality（或后端从 outcome 计算），让 5min 优化周期从"恒 0 计划"变成真实反馈；灰度发布对 paper 不再降级短路（`strategy_health_service.py:284-304` 把 REDUCE_RISK 改为 queue_optimization 双轨）。
- **验收**：paper 下单信号→成交通过率从 2.6% 回升到 ≥15%（不靠放宽硬风控，只靠"影子化学习型闸"）；live 路径契约测试零变化。

### M5. 因子链：把"研究部门"变成"A/B 生产线"

- **方案**：
  1. `MIDLONG_MID_VIA_FACTOR_ROUTE=true`（paper），因子路由开仓以独立 entry_source 标记，与 LLM 主脑仓**A/B 对账**——两种信号源各记各的 PnL，月末谁赢谁拿配额（这是回答"因子到底有没有用"的唯一科学方式）；
