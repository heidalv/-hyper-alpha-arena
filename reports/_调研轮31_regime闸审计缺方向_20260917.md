## 1. 本轮目标：量化 long 车道的方向闸（long 空仓 0/8 是"拦得对"还是"被误伤"）

```
python backend/scripts/audit_block_counterfactual.py --reason-prefix midlong_long_regime_block

```

## 2. 根因：这批拦截行**缺方向字段**（工具按纪律拒绝猜）

96h 的 276 行 `midlong_long_regime_block` 字段实况：

| 字段 | 值 |
|---|---|
| `action` | `hold`（276/276） |
| **`dir`** | **空（276/276）** |
| `stage` / `source` | `writer` / `factor_route` |
| symbol | VIRTUAL 118 / APT 78 / TIA 54 / XPL 21 / FET 5 |
| reason | `日线 regime=down（下行趋势），mid/long 多头在…` |

对照**能**算反事实的那类拦截行：

| 拦截 | n | action | dir |
|---|---|---|---|
| `location_gate_veto` | 1286 | `hold` | **long 868 / short 418** ✓ |
| `midlong_cooldown_block` | 630 | `buy` | long 547 / 空 83 |
| **`midlong_long_regime_block`** | **276** | `hold` | **空** ✗ |
| `midlong_short_regime_block` | 537 | `hold` | **空** ✗ |

⇒ 这两个 `*_regime_block` 是**方向性闸**（一个只拦多头、一个只拦空头），
reason 文本已写明方向，但审计行**没有把方向写进去** ⇒ 事后无法做反事实，
等于每次"这道闸对不对"的问题都要重新靠猜。
