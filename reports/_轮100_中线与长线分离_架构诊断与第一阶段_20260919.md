## 一、把"合并"量化（实测）

| 事实 | 数字 |
|---|---|
| 名字带 `midlong` / `mid_long` / `mlto` 的服务模块 | **24 个**（约 1.2 万行） |
| 这些模块里的 `tier` 引用 | **324 处** |
| 其中"长线例外"式补丁（`tier=='long'` / `_LONG`） | **22 处** |
| `MIDLONG_*` 配置键 | **195 个** |
| ├ 带车道后缀（`_MID`/`_LONG`/`_SHORT`） | **31 个** |
| └ **两条车道共用同一个键** | **164 个** |

**一套"中长线"策略栈 + 22 处临时补丁** —— 这个结构决定了"每轮修复都会再发现一处漏补丁"：

| 轮次 | 漏掉的补丁 | 后果 |
|---|---|---|
| 轮96 | `midlong_position_manager` 的 `tighten_trailing` 对两车道都生效 | 4 笔长线趋势仓被 **1% 回撤**在 9.4–13.6h 内收割（+1.14%~+4.33%） |
| 轮99 | `_run_v2_protection` 的 ATR 阶梯**全车道共用**（按 regime 选参，无车道维度） | 长线在 **+3.83%** 就被 `staged_tp1` 分批止盈 |
| 轮99 | 车道声明的 `exit_policy.tp_stages`（中线 0.8/1.6/3.0、长线 8/15/25）**没有消费者** | 声明与执行两套口径，声明被架空 |

周期上两者本来就不是一回事：

    中线 mid    设计 12–48h    主看 1h/4h     出场：分档TP + 保本 + 回撤 + 追踪
    长线 long   设计 3–7 天    主看 4h/1d/1w   出场：规则失效 + Chandelier（+ 滚仓）

最荒唐的共用是**复查节奏**：`MIDLONG_POSITION_MGMT_LLM_INTERVAL_SEC=14400`（4h）——
对中线是"每 1/3 生命复查一次"，对长线是"**每 1/40 生命复查一次**"。
一个节奏不可能同时服务两个时间尺度；它必然同时是"中线复查太慢、长线复查太快"。

## 三、第一步交付：车道策略真源 + 机械化"合并检测"

新增 `backend/config/lane_policy.py`：

- `LanePolicy`：一条车道的完整策略身份 —— 归属（谁管持仓/出场栈）、节奏（复查/AI tick）、
  持仓窗口、出场参数（分档/结构止损/追踪）、止损口径（ATR 倍数/上限/最小带宽/最小锁利）、
  组合与准入（并发/簇帽/置信）、加仓规则；
- `lane_of()` / `is_long_lane()` / `resolve()` / `policy_for()`：**唯一**的车道归属与取值入口；
- `RECOMMENDED`：两车道的**设计意图值**（例如长线复查 24h、入场止损 3×ATR、允许滚仓；
  中线复查 4h、上限 48h、不做金字塔）；
- `MUST_BE_INDEPENDENT` + `SHARED_FALLBACK_ALLOWLIST`：**合并检测清单与棘轮**；
- `python -m backend.config.lane_policy` 可直接打印两车道逐字段对照。

实测输出（14 个必须独立字段）：

```
review_interval_sec   mid=14400  long=14400  [独立键] ← 两车道同值（已拆键，值待调）
tp_stages             mid=[0.8,1.6,3.0] long=[8.0,15.0,25.0]  [独立键]
structural_stop       mid=price        long=chandelier         [独立键]
trailing_*            mid=2.5/1.2      long=None/None          [独立键]
entry_sl_atr_mult     mid=1.5          long=1.5                [独立键] ← 两车道同值（已拆键）
min_hold_sec          mid=43200(12h)   long=259200(72h)        [独立键]
max_hold_sec          mid=604800(7天)  long=604800(7天)        [独立键] ← 同值（中线被拉成 7 天）
exit_stack            mid=分档TP栈      long=规则失效+Chandelier [独立键]
仍共用键的字段: 无       仍回退共用键: review_interval_sec / entry_sl_atr_mult（白名单，只减不增）
```

**已拆开的两处共用键**（默认值 = 原共用值 ⇒ **行为不变**，可独立调）：

```
MIDLONG_POSITION_MGMT_LLM_INTERVAL_SEC_MID   / _LONG      ← 复查节奏（设计意图 4h / 24h）
MIDLONG_ATR_SL_MULT_MID                      / _LONG      ← 入场止损 ATR 倍数（1.5 / 3.0）
```
两者均已登记 `KNOWN_FLAGS`。

**消费方接线**（行为等价，仅去掉重复的车道词汇）：
- `paper_trading_engine._is_trend_lane_member` → `lane_policy.is_long_lane`；
- `midlong_position_manager` 的车道判定 → 同上；
- 复查节奏 → `LanePolicy.review_interval_sec`（按仓位车道取）。

**回归**：`test_lane_separation_20260918.py` **15/15**，其中三条是机械护栏：

1. 每个 `MUST_BE_INDEPENDENT` 字段的**来源键必须按车道不同**（同键 ⇒ 红）；
2. 设计意图表里两车道在周期类字段上**必须不同**（抹平 ⇒ 红）；
3. 仍回退共用键的字段**只许减不许增**（新加共用键 ⇒ 红）。
