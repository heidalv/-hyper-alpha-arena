## 一、修「明早失败没人发现」的洞（轮50）

### 1.1 根因（实测）

| 事实 | 证据 |
|---|---|
| 进化跑在**分离子进程** | `backend/services/evolution/evo_subprocess.py` |
| 该文件是否写 `job_registry` | **`job_run` / `JobRun` / `record` 零命中** |
| 后果 | 成功/失败/超时在 `ops_jobs`（`stale_warn`/`stale_critical`，`api/ops_jobs_routes.py:31-32`）、`_alert_failure`、`watchdog_job` 里**全部隐形** |

`register_job()` / `job_run()`（异常 → 记 `error` + `_alert_failure` + 重新抛出）/

### 1.2 改动

| 文件 | 改动 |

## 二、学习进化层的第三套词表（轮51，目标④收尾）

### 2.1 冲突现场

`backend/services/evolution/evolution_memory_v7.py:89` 有一份**独立的**周期映射：

```python
if p in ("4h","8h","1d"):        return "L"
if p in ("15m","30m","1h","2h"): return "M"
return "S"
```

**同一个"中"字，在四层指四个不同周期**：

| 层 | 15m/1h 被称作 | 4h 被称作 |
|---|---|---|
| 因子发现 `factor_discovery` | `scalp` | **`midlong`（中期）** |
| 调度 V7 `main.py` | **中周期** | 大周期 |
| **学习层** `evolution_memory_v7` | **`M`（中期）** | `L`（长期） |
| 策略层 | `mid` 车道（实测中位持仓 3.2h = **日内**） | `long` 车道 |

### 2.2 改动

1. `_period_to_cycle` 改为**从唯一真源 `backend/config/cycle_semantics.py` 派生**，
   字母含义重定：`S`=短线（1m/3m/5m）、**`M`=日内**（15m/30m/1h/2h）、**`L`=长期趋势**（4h 及以上）。
   - **唯一行为差异**：`1w`/`1M` 此前落进 `"S"`（月线不是短线，明显错误），现归 `"L"`。
   - 真源不可用时 fail-safe 退回历史词表。
   - 存量 `v7_lessons.cycle` 值**不改写**（检索按原值继续可用）。
2. `evolution_v7_runner.DEFAULT_PERIODS` `["4h","15m","5m"]` → **补入 `"1h"`**
   —— 1h 此前没有进化调度，所以 V7 记忆**从不记录 1h 教训**。

契约测试 9 项：`test_learning_layer_cycle_semantics_20260917.py`
（含"三层必须对日内/趋势给出一致答案"的跨层一致性断言、fail-safe、行为差异锁定）。
