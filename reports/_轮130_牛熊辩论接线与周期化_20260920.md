### 2.1 周期化（本次指令的核心）
| 周期 | 中文 | 证据范围 |
|---|---|---|
| `intraday` | 日内 | 1h/4h 结构、24h 区间位置(pos24)、资金费/OI/清算、舆情信号 |
| `swing` | 中期 | 4h/1d 均线结构、7d/30d 收益、因子路线、基本面信号 |
| `trend` | 长期趋势 | 1d/1w 结构（距 EMA200 / above_ema200）、30d 收益、宏观战略报告 |

- LLM prompt 追加**周期契约**：牛/熊都必须逐周期给 `stance/confidence/argument`，缺周期视为无效回答；
- **分周期裁决**：每周期 net = 牛信心 − 熊信心，按 `_horizon_verdict`（含风险共识门槛）出
  `proceed/reduce/reject`；并记录 `horizon_conflict`（例：日内 reject vs 中期 reduce）；
- **车道 → 主周期**：`mid→日内`、`long→长期趋势`；conviction 生效**只看主周期**
  （否则「日内看空、长期看多」会被平均成"什么都没说"）；
- **单侧缺答不算裁决**：某侧没按周期作答、且文本也抽不出立场 ⇒ 该周期 `insufficient`，
  不产生裁决、不生效（首版会退化成"牛方信心 − 0.5"的半盲比较，已修）；
- **容错解析**：模型 JSON 嵌未转义引号（实测熊方如此）时，按 `"horizons"` 局部正则抢救，
  否则整段解析失败会把"分周期"降级成文本启发式（方向都可能反过来）；
- **证据按周期配额**（每周期 ≤4 条）：修掉全局 `[:12]` 截断把长期趋势证据整段挤掉的问题
  （实测牛方因此抱怨"缺乏距EMA200/宏观证据"——证据其实采到了）。

### 2.2 成本闸（LLM 是花钱的）
| 开关 | 默认 | 说明 |
|---|---|---|
| `MIDLONG_DEBATE_ENABLED` | true | 总闸（回滚） |
| `MIDLONG_DEBATE_LLM` | true | false=规则降级（0 LLM 成本） |
| `MIDLONG_DEBATE_LLM_RISK` | **false** | 风控角色走规则裁决 ⇒ 每轮 **2 次** LLM（牛+熊）而非 5 次 |
| `MIDLONG_DEBATE_APPLY` | true | false=只记录裁决、不改 conviction |
| `MIDLONG_DEBATE_MAX_ROUNDS` | 1 | 轮数 |
| `MIDLONG_DEBATE_COOLDOWN_S` | 1800 | 同标的冷却 |
| `MIDLONG_DEBATE_HOURLY_CAP` | 6 | 全局小时上限（防灰区 40~70 刷爆） |
| `MIDLONG_DEBATE_TRANSPORT` | 空 | 空=取 `ANALYSIS_PRIMARY_TRANSPORTS` 第一项（实测 minimax） |

生效幅度**有界**：`reject→×0.6` / `reduce→×0.85`，下限 10。
**否决权不在这层**——它是"风控官"（下一块）的职责；辩论只产出裁决与证据，避免两处都能改方向。
