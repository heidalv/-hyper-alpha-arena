
## 1. 目标架构（以《中线因子化与长线纯AI架构评估》为主）

### 1.1 为什么这么分

- **中频决策 = 数值模式识别**：因子能编码、可离线验证（K 线 IC 回测，样本量远大于 315 笔交易样本）、确定性执行（不受 LLM JSON 失败/幻觉影响，失败率 ~10-15% 是行业基线）。
- **长线决策 = 叙事/宏观/regime 判断**：LLM 长板；trend_follow 是唯一净盈利 tier（+4.37、55.3% 胜率、证据链可用率 71-75%）；决策频率低、单次价值高。
- **中线 LLM 的负 EV 实证**：swing -53.39、RR≈0.66、JSON 解析失败回退虚高开仓、每 tick 60-120s 串行（单轮 390s+）。「把大模型当计算器用」是既有提示词审查结论。

### 1.2 中线 LLM 去留（待用户拍板，推荐 B 起步）

| 选项 | 内容 | 备注 |
|---|---|---|
| **A 纯因子**（用户原提案） | LLM 完全不参与中线 | 目标态；需因子先有强边缘 |
| **B 因子为主 + LLM 边缘裁决**（推荐起步） | 因子得分明确 → 直接执行/否决；落在模糊带（45-55）才问 LLM；LLM 失败 fail-closed 回因子结论 | 复用 scalp_factor_router 已验证范式 |

### 1.3 目标态形态

```
中线：因子池(IC达标+WFO通过) → regime/ADX 过滤 → IC 加权合成 score
      → score 明确：直接开/拒；score 边缘：LLM 裁决(fail-closed)
      → 砍仓硬门(enforce) → 分层熔断(三周期隔离) → 执行
长线：TrendAgent 唯一通道（禁模板双轨）+ 因子/概率引擎作证据输入
      → 提示词重构（角色+CoT+多情景推演）→ 同上执行层
```

## 3. 外部调研与多角色论证（要点）

- **数学硬约束**：盈亏平衡胜率=1/(1+RR)；swing RR 0.66 → 需 60% 胜率，当前 39.9% → 必负。
- **行业惯例**：ADX>20-25 过滤、止损 ≥1.5×ATR、止盈 ≥3×ATR、波动率定仓、持仓以天计（Man AHL/AlphaQuest/Freqtrade/Hummingbot 一致）。
- **LLM 代理**：JSON 失败 ~10-15%；缓解=结构化输出+重试+规则回退阈值；LLM 只作决策辅助，执行由规则层校验（TradeTrap 审计）。
- **TSMOM**：趋势利润集中在少数长持有大赢单；提前止盈=保留小亏砍掉大赢。
- **短周期加密**：动量优于均值回归；微市值 5m 均值回归成本后负 EV。
- **多角色裁决**：① pair_research 立即关停；② 砍仓权方案 A（hard-fact shadow→enforce）+ trend_review 撤白名单；③ 风险 5 原则 + 行为 5 原则（见风控诊断）；④ 透明化设计（冷却快照 API/拦截原因流/通道盈亏透视）；⑤ 冻结铁律：**单币/单周期亏损不得冻结其他周期**（用户指正）。
