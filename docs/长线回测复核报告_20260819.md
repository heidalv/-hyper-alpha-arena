## 四、诚实记录（复核中的已知局限）

1. L1 阈值网格（2 vs 3）在本次复核中未生效：classify_series 的 state 已按 ±3 阈值固化，翻多事件由 state 翻转定义，故 L1=2 与 L1=3 两行结果相同。阈值敏感性的正确做法是改 classify_series 的阈值参数重跑——留待 FIX-5 修订版验证报告产出后一并对齐（两者共用 trend_layer）。
2. 回测未模拟「首仓 50% + 24h 补足」（A4 实盘新增），当前为满仓口径；首仓减半会等比缩小单笔 R 但保留收益形态，趋势级结论不变。
3. 样本为 5 币 8 年 244 次翻多事件，多周期/多币合并统计；单币逐年的稳健性检验留待后续。
4. Sharpe 为按平均持有天数折算的近似年化；真实交易含滑点/资金费（回测 cost 未含 funding），实盘期望略低于回测。
