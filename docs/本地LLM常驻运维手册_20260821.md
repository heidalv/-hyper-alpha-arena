## 1. 分工（写进运维契约）

- **白天档**：14B 常驻（约 10–12GB）供批评/解释/提案/打标；挖矿不跑或仅轻量复检。
- **夜间进化窗（03:00/04:00/06:00 定时）**：全卡挖矿（14–16GB 预算）；LLM 卸下，Codegen 走云端降级。
- 桌面占约 6GB 已从预算中扣除；能换核显输出再省 2GB。
- 单卡一把「GPU 忙」锁：挖矿/冷池重打分/训练互斥；LLM 为显存预留方。

## 3. GPU 因子求值（已完成，2026-08-21）

- 等价性验收：**PASS**（`backend/scripts/validate_gpu_equivalence.py`，
  min_pearson=1.000000、IC 偏移 0、批量对照全对）。
- 墙钟对照：**PASS**（`backend/scripts/bench_gpu_wallclock.py`，
  pop=120/gens=5：GPU 21.4s vs CPU 48.1s = **2.24× 加速**，晋升名单同批 5=5）。
- 本次修掉的两个跨设备求值分歧（都会在真实数据上触发验收回退）：
  1. `ts_argmin/ts_argmax` 并列极值位置被求和顺序 ~1e-15 差异翻转 →
     两侧改「容差内取首个」（formula_ops + gpu_batch_eval 镜像）；
  2. `_roll_wma` 掩码乘法 `0×NaN=NaN` → GPU wma 实际只支持满窗，与 CPU
     部分窗口（尾部权重）语义分歧 → 无效槽先置 0 + 尾部权重对齐。
- 种群扩容：`.env FACTOR_EVO_GPU_POP_BOOST=1`（300→1200）保持开启；
  等价验收绿后按设计可以保留，观察首周晋升质量再评估。

## 4. 故障与回退

- 挖掘挂：自动回 CPU loky（GpuEvalContext 等价/显存失败 fail-closed）。
- LLM 挂：Codegen 回云端；批评停；**交易热路径不依赖本地 LLM**（设计 §8）。
- 显存不足：夜间窗预算降到 12000；白天 14B 换 `qwen2.5:7b` 档。
