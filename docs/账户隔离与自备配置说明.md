# 账户隔离与自备配置（产品规则）

> 更新：2026-08-03  
> 目标：多用户互不串数据、互不串密钥、互不串挖掘因子。

## 一句话

**每个登录账户是独立租户。** LLM 密钥、交易所 API、持仓/订单、自己挖掘的因子，全部只属于自己；平台只共享**基础因子**（代码内置），不要和「我挖出来的因子」搞混。

## 必须自己配（不共享）

| 项目 | 说明 |
|------|------|
| **LLM（严禁公用）** | 每个登录用户在设置里填**自己的** API Key。系统**没有**全站公用默认 LLM；未配置则该账户 AI 功能直接不可用，**不会**借用别人的 Key。开关：`FORBID_SHARED_PLATFORM_LLM=true`（默认开）。 |
| 交易所 API | 凭证只挂在当前用户。下单/查余额走自己的 Key。 |
| 挖掘/训练因子 | 存在本账户目录；列表接口只返回本账户的。别人挖的你看不到，你挖的别人也看不到。 |
| 交易数据 | 持仓、订单、模拟盘、策略会话按 `tenant_id`（=用户 ID）隔离。 |

## 平台共享（只读基础能力）

| 项目 | 说明 |
|------|------|
| 基础因子 | 引擎内置技术/量价等基础因子（如 RSI、波动率一类），所有账户共用同一套**代码定义**。 |
| 行情数据 | 公开市场价格本身可共享；不包含任何账户密钥。 |

**后期**：在基础因子之上，由各账户自己去挖掘、回测、训练、晋升；晋升后的私有因子仍只服务本账户。

## 管理员

- `role=admin` 可看管理后台、跨租户审计，**仍应使用自己的 LLM/交易所配置**做交易。
- 给别人开权限：改 `tier`（free/pro/vip）或 `role`（user/admin），不等于把你的 Key 分给他。

## 登录后请先做

1. 设置 → **配置自己的 LLM**
2. 设置 → **配置自己的交易所 API**
3. 因子页：先用**基础因子**；需要增强时再跑本账户的挖掘/训练

## 技术对应（给开发）

- 交易所：`/api/exchange/credentials*`、`/api/users/exchange-config` 绑定 JWT `user_id`
- LLM：`llm_configurations.tenant_id`；账户取配置不跨租户回退
- 发现因子：`data/discovered_factors.json` 按 `tenant_id` 分条；`GET /api/factors/discovered` 只返回本租户
- 旁路：`AUTH_LOCAL_TENANT` 已关闭，避免未登录当作用户 1
