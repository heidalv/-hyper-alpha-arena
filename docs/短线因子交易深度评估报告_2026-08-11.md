# 短线因子交易深度评估报告（2026-08-11）

> 范围：`scalp_factor_router` / `factor_engine` / `scalp_loop` / `paper_engine` 全链路 + AI选币联动
> 数据基准：alpha_arena / alpha_market / alpha_analytics（PG，D盘），近 30 天实跑数据
> 外部对标：幻方量化（High-Flyer）、开源量化框架、2024–2026 最新论文
> 原则：**实话实说，能成交 ≠ 有边缘**

---

## 1. 执行摘要（先说结论）

**工程上这是一套比绝大多数开源项目完整得多的系统；研究上，它目前没有任何被验证的正期望信号。**

证据链：

1. 近 30 天信号日志 **236,596 条信号**，已结算 236,135 条，胜率 **35.5%**，平均净收益 **−0.218%/笔**（成本口径）。
2. 分数分桶分析：**分数越高并不代表越赚钱**（<30：34.8% / 30-40：34.4% / 40-50：37.8% / 50-60：37.9% / ≥60：35.1%），所有分桶净收益均为负。即当前“因子分”不是有效排序变量。
3. 纸盘 30 天已平仓 scalp 单 **1,428 笔**，胜率 43.5%，利润因子 **0.908（<1）**，净亏 −16.86 美元；平均持仓 **2.16 小时**（与“5m/15m 短线”标签错配）。
4. Meta 元模型 OOS AUC = **0.503（LGBM）/ 0.508（线性）**，`usable=false`，过滤后净收益仍为负；说明当前特征集里没有可被机器学习稳定提取的边缘。
5. 运行时权重 974 个因子中 **884 个权重落在 0.5–1.0**，几乎等权——所谓“自适应加权”目前没有产生实际分化，也没有证据证明它在工作。

一句话：**系统在“流程完整性、风控、执行、可观测性”上是优秀生，在“信号有效性、验证纪律、数据积累”上是差生。** 下一步必须把资源从“加更多因子/更多门控”转向“先证明一个信号真的有效”。

## 2. 链路与交易概念（先讲清楚它是什么）

### 2.1 完整数据流

```
5m/15m K线（数据中心落库） + 订单流（CVD/OI/Taker/资金费率/盘口）
  → factor_engine.compute_all_factors（150+ 因子：WorldQuant/Alpha158/订单流/币圈原生）
  → factor_pipeline.compute_weighted_signals（IC/regime/衰减加权 → top-15 聚合）
  → scalp_factor_router.evaluate（score=|direction|×100；5m/15m 共振 ×1.3 / 矛盾 ×0.5）
  → scalp_structure_scanner（结构止损 advisory）
  → scalp_execution_gate（direct≥45 / veto 35-44 / hold<35）
  → FlashVeto（35-44 分边缘信号走 5s LLM；Paper fail-open / Live fail-closed）
  → scalp_ev_gate（p_win×TP 实现率 − (1-p_win)×SL 实现率 − 往返成本）
  → portfolio_budget + dynamic sizing（波动率×置信度 → 杠杆/名义）
  → paper_engine.place_order（滑点由 fee_guard.calc_slippage_rate 统一计算）
  → 持仓期：ATR/结构 SL、TP、保本、trailing、max_hold_timeout
  → scalp_signal_logger 落信号 → 结算 → calibrator / meta 训练（影子）
```

### 2.2 交易概念（本质）

当前策略本质上是一个**规则化因子打分 + 分层门控 + 期望值过滤**的短线交易系统：

- 因子合成：**IC/衰减/regime 加权的线性聚合**（与 Gu-Kelly-Xiu 的 ML 资产定价、López de Prado 的元标签方法不同，它没有端到端训练）。
- 多周期：5m 主信号 + 15m 共振确认。
- 门控：置信度分档（direct/veto/hold）+ LLM 边缘裁决 + V5 统一门禁 + EV 闸门 + 组合预算。
- 执行：动态杠杆、结构止损、保本/分批止盈、频率与冷却。
- 学习：因子 IC 每 80 tick 回写权重；信号结算喂校准器；Meta 模型日训但**只做影子**。

### 2.3 真实运行画像（近 30 天）

| 指标 | 数值 | 说明 |
|---|---|---|
| 信号总数 | 236,596 | 平均每天 ~7,900 条 |
| 已结算信号胜率 | 35.46% | 固定前瞻窗口口径 |

## 3. 数据证据（为什么说“没有边缘”）

### 3.1 因子分不是有效排序变量

按 `factor_score` 分桶（近 30 天，已结算信号）：

| 分数桶 | 信号数 | 胜率 | 平均净收益 |
|---|---|---|---|
| <30 | 16,713 | 34.8% | −0.099% |
| 30–40 | 21,676 | 34.4% | −0.079% |
| 40–50 | 15,444 | 37.8% | **−0.046%** |
| 50–60 | 20,708 | 37.9% | −0.123% |
| ≥60 | 162,055 | 35.1% | −0.279% |

**162,055 条信号集中在 ≥60 分**（68%），但胜率反而比 40–60 分更低、净收益更差。结论：当前打分把大量噪声样本送进“高置信”区，分数没有单调预测力。

### 3.2 亏损来源（30 天纸盘 close_reason）

| 平仓原因 | 笔数 | 净盈亏 | 平均/笔 |
|---|---|---|---|
| sl | 166 | −71.32 | −0.430 |
| master_running_reduce | 164 | −22.39 | −0.137 |
| master_running_close | 71 | −9.65 | −0.136 |
| symbol_removed | 111 | −4.83 | −0.044 |
| max_hold_timeout | 221 | −2.68 | −0.012 |
| tp | 155 | +49.42 | +0.319 |
| breakeven_tp | 103 | +50.75 | +0.493 |

最大出血点是 **SL 166 笔 −71.32 美元**（占比绝对亏损的 60%+），其次是 **Master 减/平仓共 235 笔 −32 美元**——说明“主控干预”本身成了第二亏损源，需要审计 Master 干预规则。

### 3.3 符号维度（30 天，前 20）

胜率普遍 16%–36%，仅 XMR/LDO/HYPE/LIT 等少数符号平均盈利。**AI 选币选进来的 AAVE（95 笔 −7.90）、KAITO（101 笔 −6.40）、ZEC（125 笔 −8.58）都是重灾户**——选币与短线因子命中率没有联动。

### 3.4 Meta 模型：诚实的“不可用”

`data/scalp_meta_report.json`（2026-08-11）：

| 字段 | 值 |
|---|---|
| usable | false |
| OOS AUC（LGBM / 线性） | 0.5031 / 0.5077 |
| 基线胜率 / 净收益 | 36.0% / −0.228% |
| top30% 过滤后 | 37.5% / −0.214% |
| top15% 过滤后 | 34.7% / −0.240% |
| gate_reasons | AUC<0.53；过滤后净收益仍为负 |

这说明：**特征集（含因子分、订单流、周期概率）无法区分赢单和输单**。这不是“训练不够”，而是信号本身没有可学习边缘。

### 3.5 运行时权重：近乎等权

`data/factor_runtime_weights.json`：974 个权重，884 个落在 0.5–1.0，只有 13 个 >1.0。所谓“IC 自适应加权”目前没有把任何因子显著压掉或显著提升，等于一个 974 维的等权噪声池。

## 4. 外部对标（实话实说）

### 4.1 幻方量化（High-Flyer）—— 不是一个“算法”，是三座壁垒

幻方官方口径（high-flyer.cn）：2008 年开始全自动量化；2016 年首个深度学习交易，2017 年深度学习全面用于交易；自研 Fire-Flyer 算力平台；**数据量 10PB+、数千数据源**；团队以数学/物理/计算机竞赛与博士为主。

公开报道（**未经官方证实的媒体信息，仅作参考**）：5000+ 动态因子库、微观结构预测模块、高频统计套利、订单簿/订单流挖掘、另类数据占比约 20%、FPGA 极速决策（~5μs）、自研时序数据库。

**对比结论（必须诚实）**：

| 维度 | 幻方 | 本项目 |
|---|---|---|
| 数据 | 10PB+，2008 年至今 tick/另类数据 | ~60M 根 K 线，5m 历史仅 ~7–30 天可用 |
| 算力/基础设施 | 自建超算 + 低延迟硬件 | 单机 Python 进程 |
| 研究纪律 | 数理博士团队，严格多阶段验证（公开资料暗示） | 已有 walk-forward/DSR/PBO 工具箱，但尚未成为硬门禁 |
| 因子体系 | 动态大库 + 微观结构预测 | 150+ 静态注册因子，974 权重近乎等权 |
| 可复制的差距 | 数据和算力是护城河，算法不是 | 应先复制“研究纪律”，而不是复制“因子数量” |

**关键认知**：幻方的成功不可通过“多写因子/多上模型”复制；本项目最该学的是它的**研究工程化**——把“想法 → 数据 → 严格验证 → 上线门禁”做成流水线。

### 4.2 优秀开源量化/交易软件

| 项目 | 定位 | 本项目可借鉴 |
|---|---|---|
| Freqtrade（~25–30k stars） | 通用策略 + 回测 + Hyperopt + FreqAI | 独立回测/超参/组合优化是标配；本项目缺 |
| Hummingbot（~44k stars） | 做市/套利 | 库存/逆向选择风控成熟；本项目套利侧可参考 |
| Jesse / OctoBot / Superalgos | 策略框架/可视化 | 数据与策略分离、插件化 |
| vn.py / Qlib（微软） | 国内量化平台 / AI 量化研究 | Qlib 的 factor/model/portfolio 分层与 point-in-time 数据是现成范本 |
| vectorbt / backtrader / Lean | 向量化回测 / 事件驱动 / 生产级 | 成本模型、滑点、多资产组合回测的成熟实现 |
| CCXT | 交易所适配 | 本项目已大量使用 |

**对比结论**：在“风控、执行、多智能体、LLM 集成”上本项目**明显强于大多数开源项目**；但在“独立回测 + 诚实成本建模 + 超参/组合验证 + 防过拟合门禁”上，**连 Freqtrade 这种社区项目都有而我们没有**——这是最刺眼、也最该补的差距。

### 4.3 最新论文方向（2024–2026）

| 方向 | 代表 | 对本项目的含义 |
|---|---|---|
| 反过拟合方法学 | López de Prado：triple-barrier、meta-labeling、CPCV、DSR、PBO；《10 Reasons ML Funds Fail》 | 本项目已实现部分（meta/triple-barrier 默认关），但**未作为上线门禁** |
| 回测即检查而非预言 | TradingStrategy.ai 综述；Backtest Overfitting in the ML Era（2024, Knowledge-Based Systems） | walk-forward 单独用也不够，需 PBO/DSR/随机基准组合 |
| 加密因子动物园 | Crypto factor zoo（2025, FRL） | 大因子池多数冗余，显式选择协议后显著因子极少——本项目 974 权重等权正是反面教材 |
| 加密量化系统性综述 | Quantitative Alpha in Crypto Markets（2025, SSRN） | 因子/套利/ML 的边界条件：成本、流动性、regime |
| LLM 交易智能体 | QuantHarness（arXiv:2509.09995）、ATLAS（2025）、ALERA（2025） | LLM 适合做“结构化信号之上的裁决/审计/研究助手”，**不适合做高频主信号**；本项目 FlashVeto 的定位符合前沿共识 |
| 深度学习混合因子 | Deep learning-augmented hybrid factor model for crypto（2025） | 在点时间数据 + 严格验证齐备后才值得尝试端到端模型 |

## 5. 综合评估矩阵（诚实版）

| 维度 | 评级 | 证据 |
|---|---|---|
| 信号有效性 | 🔴 未证明 | 分数无单调性；meta AUC≈0.50；纸盘 PF=0.908 |
| 数据积累 | 🔴 严重不足 | 5m 历史 ~7–30 天；信号 23.6 万但高度同质（≥60 分占 68%） |
| 验证基础设施 | 🔴 明显落后 | 无独立回测/成本模型；walk-forward 仅脚本级、样本不足 |
| 执行/成本建模 | 🟡 中等 | 滑点/手续费已统一，但订单模拟真实性未审计 |
| 风控 | 🟢 优秀 | V5 门禁/预算/熔断/动态杠杆/冷却体系完整 |
| 工程与可观测性 | 🟢 优秀 | 日志/心跳/审计/门禁开关齐全 |
| 因子纪律 | 🟡 有工具未闭环 | DSR/PBO/相关性去重存在，但权重近等权、晋升少 |
| 学习闭环 | 🟡 训而不用 | Meta 已训练但 usable=false 且未接入；因子归因刚起步 |
| LLM 集成边界 | 🟢 设计正确 | 只做边缘裁决 + 审计，Paper/Live 降级分离 |
| AI 选币 × 短线联动 | 🔴 断裂 | 选币高分币（AAVE/KAITO/ZEC）恰是短线亏损重灾户 |

## 6. 结论

1. **当前短线策略在统计意义上没有可验证的正期望**：23.6 万信号、1,428 笔已平仓单、meta 模型三个独立证据都指向“无边缘或边缘为负”。
2. **不是“调参/加因子/加门控”能救的**：分数分桶显示当前打分体系本身不排序；在信号无效的前提下，所有下游门控只是“更精致地亏钱”。
3. **最优先的整改不是算法，而是三件事**：
   - 建立**独立回测 + 诚实成本 + 防过拟合门禁**（walk-forward + CPCV + DSR/PBO + 随机基准）；
   - 积累并清洗**点时间 5m 历史数据**（目标是 ≥3–6 个月、覆盖多种 regime）；
   - 在信号被证明有效之前，**降低无谓交易频率与成本暴露**（例如收紧 EV、降低高量低质分桶的放行），而不是扩大因子池。
4. **AI 选币与短线执行必须联动**：当前选币只看“题材/热度/波动”，不校验“该币在短线因子上的历史命中率”，导致高分币成为亏损主力。

详细整改设计见《短线因子交易整改设计_2026-08-11.md》，落地节奏见《执行计划》，验收见《评估计划》。
