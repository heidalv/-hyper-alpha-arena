## 逐页详细缺失

### 1. AI策略 (strategy)
缺失: 策略创建向导(5步) / 策略CRUD(激活/暂停/删除) / 自动选币面板 / AI风控模式切换 / 回测进化引擎 / 门禁配置 / 快速试单 / MLTO论点 / 情报中心 / 动态加币移币 / 清理僵尸

### 2. 模拟交易 (paper-trading)
缺失: 手动下单(POST /paper/order) / 部分平仓(按百分比) / 手动设余额 / 完整重置 / MLTO论点面板 / 挂单识别 / AI复审状态

### 3. 设置 (settings)
缺失: LLM配置库CRUD / API密钥配置 / 交易对管理(增删/刷新) / 锁仓强度 / 通知(飞书/钉钉) / 新增账户功能

### 4. 风控 (risk)
缺失: 爆仓预警表 / 多级风控指标 / 熔断状态 / 风险事件历史 / 分级处置

### 5. K线图表 (charts)
缺失: 技术指标(MA/EMA/MACD/RSI/BOLL) / AI分析面板 / 多周期共振 / K线回填 / 自定义币种

### 6. 仪表盘 (dashboard)
缺失: 多账户对比 / 拖拽布局 / 布局保存 / widget系统 / 真实三周期状态

### 7. 交易所 (exchange)
缺失: 跨所价差 / 统一持仓 / Rebate引擎 / 添加账户功能

### 8. 套利 (arbitrage)
缺失: 全部(11Tab/60API)

### 9. Hyperliquid
缺失: 全部(钱包/下单/授权/持仓/余额)

### 10. 市场中台 (intel)
缺失: Tab切换 / 数据源配置 / 套利高亮 / 刷新
