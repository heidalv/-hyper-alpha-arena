# 短线因子交易评估计划（2026-08-11）

> 配套：《短线因子交易深度评估报告》《短线因子交易整改设计》《短线因子交易执行计划》
> 目的：给「信号是否有效」「改动是否有效」一个可复现、可审计、不可事后改口径的判定标准。

---

## 0. 评估原则

1. **先定义口径，再出结论**：所有指标必须写清数据源、时间窗、成本假设、结算口径。
2. **不能只报胜率**：胜率只是赔付结构的一部分，必须与每笔期望、PF、成本占比、统计显著性一起看。
3. **回测不是证据终点**：回测必须通过随机基准、防过拟合门禁，并与纸盘 parity 对齐。
4. **单变量评估**：一次只评估一个改动，禁止把多个改动打包算功劳/背锅。
5. **写进报告才算数**：任何评估结论必须可复现（同 commit + 同数据 = 同结果）。

## 3. 回测-纸盘 Parity 定义（v1）

parity_score 在**同一时间窗、同一信号定义**下计算：

```
parity = 0.5 × sign(回测净收益) == sign(纸盘净收益)
       + 0.3 × (1 − |回测净收益% − 纸盘净收益%| / max(|纸盘净收益%|, 0.1%))
       + 0.2 × (PF 方向一致 ? 1 : 0)
```

- parity ≥ 0.70：可进入晋升讨论；
- parity 0.40–0.70：先查成本/滑点/结算差异，不晋升；
- parity < 0.40：回测基础设施有问题，冻结所有新信号上线。

v2（数据充足后）：按周滚动计算 IC 方向一致率与分层组合的相关性，parity 定义可升级，但需先写进评估计划修订记录。

## 4. 晋升 / 否决 / 下线标准

### 4.1 新因子 / 权重变更晋升（硬门，全部满足）

1. OOS 净收益 > 0，且覆盖悲观成本；
2. 随机基准 permutation p < 0.05（≥200 次）；
3. PBO < 0.1（robust）或 DSR > 0.95；
4. 分数分桶单调显著（Spearman p < 0.05）或分层组合净收益转正；
5. parity ≥ 0.70；
6. 样本量：已结算信号 ≥ 3,000（或按数据可用性明确标注置信度不足）。

### 4.2 Meta usable（候选门槛，M4 前复核）

- OOS AUC ≥ 0.55；
- top30% 过滤净收益 > 基线净收益且 > 0；
- 覆盖率 ≥ 15%；
- 连续 2 周影子对照不劣化纸盘成交质量。

### 4.3 单变量实验判定（A/B）

- 对照期：改动前 14 天 vs 改动后 14 天（同账户、同参数基线）；
- 判定指标优先级：每笔净收益（含成本）> PF > 胜率；
- 统计方法：bootstrap 或 t 检验，p<0.05 才算有效；
- 若样本 <100 笔：标记「证据不足」，继续收集，不判成功。

### 4.4 否决 / 下线信号

- 连续 14 天每笔净收益 < 0 且随机基准不显著 → 下线/收缩；
- 符号级：30 天 PPE < −0.1% 且样本 ≥50 笔 → 进入观察名单，短线降频；
- 权重 >1.0 的因子无可复现证据 → 回落到 1.0；
- 数据完整率 <99% 且未恢复 → 暂停依赖该数据的评估结论。
