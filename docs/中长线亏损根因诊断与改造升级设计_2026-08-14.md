同时（对照）：短线 scalp 正常跑（V5Gate PASS/BLOCK、SizingAgent 下单、持仓更新）→ 证明**调度与执行链路活着，只有中长线这条链路被多层阻断**。

### 1.2 冷却机制详解（代码级）

`backend/services/reentry_cooldown.py`：
- 基准亏损冷却：short=4h、mid=4h、long=12h（`REENTRY_LOSS_COOLDOWN_SEC_*`，long 另设 SL 冷却 `REENTRY_SL_COOLDOWN_SEC_LONG` 默认 48h）。
- **连续亏损惩罚乘数** `_get_loss_multiplier`：连亏时 ×2 → long 最长 24h 同向禁开。
- 反转冷却（反向翻转）另有 24h 级冷却。
- 状态 DB 持久化（`_durable_reopen_blocked` 查最近平仓记录）→ 重启不清零。
- 设计意图（注释自述）："避免信号未变时重复付手续费"——**但把它同时用在了亏损惩罚上，等于在趋势策略最需要重新入场时把它锁死**。

### 1.3 意图→执行转化 0% 断点

周报（`backend/data/midlong_reports/latest.md`，08-11 生成）自证：
- NIBBLE/BUILD 事件 253 次（NIBBLE=247）→ **24h 开仓转化率 0.0%（0/253）**
- 决策漏斗（审计 JSONL 336h）：skip=0 / open_attempt=0 / opened=1
- 即：**MLTO Hub 每 2 分钟在产出 NIBBLE 意图，但执行层一个都没放行**。断点位于 open_gate→Writer/执行之间（`mlto/open_gate.py` 已精简为 5-6 条底线，说明历史上"多闸把 AI 卡死"发生过一轮，现在疑似再次出现在执行层，待量化审查员定位确切位置）。

### 1.4 前端为什么「完全不知道怎么回事」

- `/dashboard` 三周期卡只显示 active_strategies/budget/drawdown/win_rate——**不显示冷却剩余时间、不显示 hold 原因、不显示意图转化漏斗**。
- 冷却/LLM 回退/门禁拦截全部只在日志与内部审计 JSONL 中。
- 周报生成器还有**隐藏 bug**：因租户 RLS 读不到 `paper_*` 表（无租户上下文），回退 `event_log.jsonl`——周报抬头写着「paper_* 表无样本」是**假的**，绩效口径长期失真。

### 2.2 六大根因逐条（证据链）

**① master 总控砍仓 + trend_review 白名单漏网（P0，损失最大来源）**
- 数据（orders 权威口径）：swing `master_running_close` 30 笔 **-33.89**、胜率 10%（其中 23 笔持仓 1-6h）；`trend_review_close`（trend）**12 笔 -44.90、胜率 0%**。

### 2.5 深层根因：中长线跑错了策略类型（模板级证据，2026-08-14 深度复查）

> 前几轮止于「执行层砍仓」，本轮深挖到**策略库本体**——这才是「设计不合格」指出的缺口。

**（一）mid 层的策略模板库几乎被「均值回归」占据，而均值回归在中长线周期上负 EV。**

- 成交数据按策略模板聚合（paper_positions，swing/trend 已平仓）：
  - `tpl_mid_reversion_*`（均值回归模板家族）：**28+ 笔、几乎全负**（-8.45/-4.14/-1.94/-0.58/-0.55/-0.50/-0.25/-0.13/-0.08……），胜率 0-40%；
  - `tpl_long_mean_reversion_*`（长线均值回归，挂在 trend_follow 层）：**8 笔、全负**（-3.20/-2.33/-1.44/-0.63/-0.47/-0.29…）；
  - `gen_*_reversion/ranging_*`（AI 生成器持续产出同型模板）：几乎全负。
- **对照赢家**：`tpl_long_swing_*`（长线摆动/趋势模板）4+6 笔 **+16.59/+10.23，胜率 50%，平均持仓 49-58h**——与「让利润奔跑」哲学一致，是全库唯一稳定盈利的家族。
- 外部证据链（调研报告 §一/§四）：短周期加密「动量优于均值回归」，成本后均值回归负 EV；本项目自身 Walk-Forward 也显示趋势类 OOS 弱而均值回归更差。

**（二）模板晋升管道没有真实回测门禁，占位指标直接入实盘。**

- `strategy_templates` 表中大量 `[实战验证] [mean_reversion] *` 模板的 backtest 指标为 **win_rate=1.0 / sharpe=0.5 / rating=4.65**——胜率 100% 不可能，是**占位符**；
- 内置「均值回归波段」（mid）与「长线均值回归」（long）模板 **backtest 三零（0 胜率/0 Sharpe/0 样本）却 is_active=true**；
- 真正带高质量回测的「中周期动量追踪」（win 86.9%、Sharpe 3.6、n=61、rating 5）与 `[实战验证][swing] SOL/BNB mid`（58-78% 胜率、Sharpe 3.5-5.6）反而没有成为 mid 层主力。
- **后果**：mid/long 层持续实例化「从未被证明」的均值回归模板，每个 symbol 一个实例（`tpl_mid_reversion_<hash>`），样本永远分散（单实例 n=1~7），既攒不出证据、也触发不了任何「家族级」淘汰。

**（三）方向不对称（模板方向选择近似随机，不随 regime）。**

- swing：多单 56 笔 **+10.11**（胜率 23.2%）/ 空单 26 笔 **-5.02**（19.2%）——**该层应只做多或对空单加 regime 条件**；
- trend_follow：空单 24 笔 **+33.98**（33.3%）/ 多单 6 笔 **-5.04**（0% 胜率）——与 swing 恰好镜像；
- 说明模板在方向上是「两个方向都无差别地试」，而不是「顺着 regime 选边」。

**（四）止损装饰化：亏损单从未真正行使过止损。**

- swing 亏损单 32 笔中 **0 笔打 SL**、4 笔 trend_broken、**16 笔 master_running_close**；trend 亏损单 11 笔中仅 1 笔打 SL。
- SL/TP 名义距离：swing 平均 SL 4.79% / TP 9.53%（RR 2:1），trend 6.78%/16.55%——止损远到噪音打不到，实际亏损全部来自**人工/半人工通道提前离场**（master、trend_broken 在 -1%~-7% 处割肉），RR 结构从未被行使。

**（五）小结——中长线亏损的完整因果链（修正版）：**

```
策略库选型错误（mid/long 跑均值回归模板，无回测门禁）
   → 入场信号本身负 EV（胜率 0-40%，方向随机）
   → 亏损单频繁出现 → 主控/复审在噪音窗口提前砍仓（0% 胜率通道）
   → 盈利单也被同样通道砍掉（RR 结构被破坏为 0.66）
   → 亏损后冷却叠加 → 中长线「事实性停摆」且用户不可见
```

执行层的 P0 修复（砍仓硬门）是**止血**；策略库治理（下 §5 P0-策略库）才是**治本**。

## 3. 外部调研要点（完整报告：`docs/外部调研报告_中长线_2026-08-14.md`，18 次检索）

与本项目根因直接对应的四条硬结论：

1. **数学硬约束**：盈亏平衡胜率 = 1/(1+RR)。风控员 orders 口径实测 swing RR≈**0.66**（均赢 0.465/均亏 0.703）、trend RR≈0.88——**盈亏结构被系统性破坏**（砍赢单留小亏），期望必负，与净亏完全一致。
2. **行业惯例**：趋势策略教科书参数是「ADX>20-25 过滤震荡、止损 ≥1.5×ATR、止盈 ≥3×ATR、波动率反比定仓、持仓以天计」（Freqtrade/Hummingbot/Man AHL/AlphaQuest 一致）——本项目「几小时内砍仓 + 支撑阻力位附近止损」与全部主流惯例相反。
3. **LLM 代理失败模式**：JSON 失败率 ~10-15% 是常态；标准缓解 = 结构化输出 + 重试 + 规则回退**阈值**；LLM 只做决策辅助、执行由规则层校验（TradeTrap 审计证实幻觉直接变现为错误交易）。
4. **趋势策略生命线**：TSMOM/ATR trailing 研究一致——趋势系统利润集中在少数长持有大赢单；提前止盈/保本=「保留高频小亏、砍掉补偿性大赢」。本项目 63.6% 回吐正是反面教材。
5. **微市值短周期均值回归 = 负 EV**（第二轮定向调研）：短周期加密市场「动量优于均值回归」，微市值币滑点/点差可轻易吞噬 5m 均值回归的几个基点毛利（IRFA 2024 实证纳入成本后异象消失）——pair_research 通道的 -319.62 完全符合「成本吞噬微利」画像；研究性通道生产惯例是「先样本外验证 + 资金上限 + 连亏熔断」后才准实盘。
