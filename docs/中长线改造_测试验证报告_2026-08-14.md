## 3. 实施中发现并修复的额外根因（超出原设计清单）

### 3.1 `symbol_risk.py` 的 `sa_text` 未导入 —— 币种级日亏冻结从未真正运行
`update_symbol_daily_pnl` 使用 `sa_text(...)` 但模块从未导入它，运行时抛 `NameError`，
被外层 `except` 静默吞掉 → **per-symbol 日亏损追踪与冻结 Layer1 一直是死代码**。
本批已补导入（`e9a8f78`），修复后该层首次真正生效。

### 3.2 tier 归因优先级反转 —— 会把短线亏损误记到中线
`AIStrategy.timeframe_tier` 有 `server_default='mid'`，原 SQL 优先用它归因，
实测近 14 天 1756 笔订单里 1735 笔被记成 mid（短线仅 3 笔）。
改为 `trade_nature → NATURE_TO_TIER` 优先后：short=1666、mid=72、long=18，符合真实结构。
若不修复，P0-E 中线日亏预算会被短线亏损错误触发（违反三周期隔离铁律的反方向）。

### 3.3 旧进程持续重新注入污染（重启前反复）
见 §4。
