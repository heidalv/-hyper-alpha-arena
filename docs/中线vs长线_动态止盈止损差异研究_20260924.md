## 1. 两条车道的结构性差异（决定了"动态止盈"必须两套设计）

| 维度 | 中线（mid） | 长线（long / E1） |
|---|---|---|
| 车道身份判定 | `tier=mid` | `tier=long`；现有 7 仓**全部 is_e1=True** |
| 管理路径 | ExitPolicy 层（每 tick 评估）+ 保护管理器 | E1 日任务（**cron 08:20，日线 bar 滞后 1 天+**）；非 E1 走 `decide_long` |
| 出场参数来源 | `EXIT_POLICY_MID_*`（.env，逐笔快照） | `exit_policy.long`（结构性：无 TP / 无 trailing）+ 车道声明 `tp_stages=[8,15,25]` |
| 止损 | 声明 sl_pct 3~6% + **实际 1.5~1.8% 快照**（偏紧） | 结构止损 Chandelier（周线 ATR×2.0 / E1 3×ATR20），实测 −5.8%~−19.6% |
| 止盈（改动前） | 分档 2.5/4/6% + trailing 2.5/1.2（会跑） | **完全没有**（声明档不执行；轮99/主动扫描/E1 三层各自跳过） |
| 平均持仓 | 6.3 小时 | 29.2 小时（设计 24–168h） |

## 5. 逐笔验收中发现并修掉的两个缺陷

1. **peak 口径放大**：`peak_pnl_pct` 在 `get_positions` dict 里是百分数（×100），
   且分批减仓后用 `peak_usd/名义` 反推会把峰值放大（BTC 11.5%→23.1%、XRP 14.2%→29.4%）
   ⇒ 锁利线被推到市价上方。修法：**以 DB 列为准**，仅在列为空时用反推值。
2. **触发只看日线收盘**：E1 的 `as_of_bar` 有 1 天以上滞后，实测 AVAX 日线收 +9.8%
   而实时价 −0.4% ⇒ 在**亏损价**上减仓（oid 24196 成交 −$0.48）。
   修法：分档触发必须**同时**满足「日线收盘 ≥ 档位」**且**「市价 ≥ 档位」。
