# AI 选币全面升级设计（2026-08）

> 版本：V1.0｜状态：落地中  
> 前置：[AutoCoin选币改造落地设计稿_2026-08-02.md](./AutoCoin选币改造落地设计稿_2026-08-02.md)、[VIP共用AI选币说明.md](./VIP共用AI选币说明.md)

## 一句话目标

把「平台研报墙 + 会话短线猎手」从两套半成品流水线，升级为 **共用 `CoinRankEngine` + 闭环反馈 + 政权/陷阱门控**；双轨只保留「谁审、谁注入」的差异。

## 双轨契约（不变）

| 轨道 | 定位 | LLM | 注入 |
|------|------|-----|------|
| 平台 `coin-select` | VIP 共用研究看板 | 管理员租户 `coin_select` | 默认手动；短线可 auto_follow |
| 会话 `auto-coin` | 账户短线猎手 | 各账户交易 LLM | 自动写入 `auto_coin_symbols` → 仅 scalp |

交易决策仍各用自己的 Key；平台只做共用研究。

## 目标架构

```
数据中心(ticker/catalog/universe/kline)
        ↓
  CoinRankEngine（features → score → gates → feedback 衰减）
        ↓
   ┌────┴────┐
平台 Board   会话 Hunter
Admin LLM    Account LLM LAYER
看板+Screener  Inject/Replace
        ↑──────── FeedbackWriter(24h/72h)
```

## 模块

| 路径 | 职责 |
|------|------|
| `backend/services/coin_rank/features.py` | 只读数据中心拉快特征 |
| `backend/services/coin_rank/score.py` | CS/TS 动量、流动性、composite、explain |
| `backend/services/coin_rank/gates.py` | TrapSoft、MTF confluence → pass/soft_reject/hard_reject |
| `backend/services/coin_rank/feedback.py` | 24h/72h 回写 + 衰减乘数 |
| `backend/services/coin_rank/engine.py` | 统一入口 `rank_universe` / `rank_symbols` |
| `backend/services/coin_rank/metrics.py` | 周期观测指标 |

## 阶段

| 阶段 | 内容 | 回滚 |
|------|------|------|
| P0 | 周期指标、degraded/replace 日志 | 关日志即可 |
| P1 | RankEngine + 会话 DC 统一 | `COIN_RANK_ENGINE_ENABLED=false` |
| P2 | 换币门槛下调；Paper 开 V3/三车道 | 恢复旧 margin / flag |
| P3 | TrapSoft + MTF 门 | `COIN_RANK_GATES_ENABLED=false` |
| P4 | FeedbackWriter + 看板绩效 | 停调度任务 |
| P5 | Screener UX、权限收口、降质显性 | 前端回退 |

**不做本轮：** DEX 土狗、AutoCoin 进长线、LLM 全市场打分、生产 DRL 组合器。

## 验收

1. 平台与会话粗分 Top20 重叠 ≥70%  
2. 僵死池消失，有 replace 日志  
3. 量价陷阱 / 多周期打架不得进强烈推荐  
4. VIP 可见 24h 样本绩效（不足则诚实标注）  
5. AI 降质显性化  
6. Auto 仅 scalp；midlong 不自动跟投；VIP 门控保持  

## 关键开关

见 `backend/config/settings.py`：`COIN_RANK_*`、`AUTO_COIN_REPLACEMENT_MARGIN`、`PAPER_AUTO_COIN_*`、`AUTO_COIN_SCORE_V3_ENABLED`、`AUTO_COIN_MULTI_LANE_ENABLED`。
