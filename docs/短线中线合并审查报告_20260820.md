## 2. 现行架构（只画现码）

### 2.1 短线（现码，未改道）

```
midlong 无关。入口：FullAutoTradingService → run_scalp_independent
  → 5m K 线（跟随活跃交易所，默认 asterdex）
  → compute_all_factors（可精选白名单）
  → scalp_factor_router.evaluate  或  regime=ranging 时 scalp_ranging_mr
  → scalp_execution_gate
  → evaluate_scalp_proposal（TCP/V5）
  → 可选 FlashVeto（约 35–44 分）
  → MTF / short_tier / 动态仓位 / EV 闸（代码默认开）
  → paper_engine.place_order(trade_nature=scalp)
```

Master 对短线：**只禁新开**（`SCALP_MASTER_HARD_BLOCK` 拦 buy/sell/pyramid/dca）。  
注释写「短线也跳过」，**后面没有 `continue`**，`close` / `reduce` 会继续往下走。减仓对 short 另有「浮亏 < 20% 不准减」；浮亏够大仍会出现 `master_running_reduce`。

### 2.2 中线（现码，8 月 15 日后）

```
midlong_loop.run_midlong_independent
  → 宇宙 = 固定 mid ∪ AI 中线候选(≤3) ∪ 已有 swing 续管
  → _run_mid = ("mid" in due) and 宇宙非空
  → _maintain_mlto_theses_for_session(run_mid=...)
       若 MIDLONG_MID_VIA_FACTOR_ROUTE：
         factor_route_decide → factor_route_open
           → execute_midlong_open(source=factor_route, nature=swing, tier=mid)
       若仅 MIDLONG_MID_VIA_MLTO：前端标「中线AI(过渡)」
         （注意：mlto_cycle 对 mid thesis 仍可能 continue 跳过，标签可能假阳性）
       两开关都 false：前端 mid_mode=mid_paused，循环只占位 mid key
  → 出场：_run_midlong_active_exit + 模式 B manage_position
       （规则止盈止损 + 方向复查：默认 _rule_direction，
        MIDLONG_REVIEW_LLM=true 时才走 trend_agent LLM）
       → close_reason 前缀 trend_broken / trend_weaken
```

**已废弃（测试仍在、主路径不再调）：** `swing_agent.analyze` 独立开仓。  
**不要再说：**「中线是 MLTO NIBBLE、转化率 0%」。2026-08-17 周报写的是 NIBBLE→24h 开仓转化率 **67.3%**，且入场主路径已是因子路由（开关打开时）。

代码默认：

| 开关 | 代码默认 | 含义 |
|------|----------|------|
| `MIDLONG_MID_VIA_MLTO` | **false** | 旧 AI 中线 thesis 开仓关（仍读 env，非硬锁死） |
| `MIDLONG_MID_VIA_FACTOR_ROUTE` | **false** | 因子路由也关 → 默认「中线暂停」 |
| `MIDLONG_REVIEW_LLM` | **false** | 模式 B 方向复查默认**规则**，不是 LLM |
| `MIDLONG_EXEC_AUTHORITY` | **mlto** | paper 下 `factor_route` 被当成合法 writer |
| `FACTOR_ROUTE_MIN_ACTIVE_FACTORS` | **2** | 活跃因子 <2 则 hold |
| `FACTOR_ROUTE_SL_PCT` / `TP` | **5% / 10%** | 固定比例，不是结构位 |
| `FACTOR_ROUTE_TRANCHE_MARGIN_PCT` | **0.12** | 小资金能过敞口闸 |

M4 实施记录（2026-08-16）写过：当时环境已用 5 个活跃因子投票、`factor_route` 在跑。那是当时机器实况，不是代码默认。

### 2.3 测试与现码打架（中线）

`tests/integration/test_swing_deprecated.py` 要求 `midlong_loop` 里 `_run_mid = False`。  
现码是 `_run_mid = ("mid" in due) and bool(_mid_universe)`，并在 `mlto_cycle` 里接了因子路由。  
**测试描述的是「中线并进长线 mid_view、不再调度中线」的中间态；现码已经把中线调度接回因子路由。** 这不是「中线又变回 SwingAgent」，是测试没跟上 8 月 15 日接线。
