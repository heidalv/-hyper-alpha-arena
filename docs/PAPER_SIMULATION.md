# 纸面仿真保真度说明 (Paper Simulation Fidelity)

## 仿真模式分级

通过环境变量 `PAPER_SIMULATION_TIER` 控制：

| 特性 | `demo` (默认) | `research` | `off` |
|------|:---:|:---:|:---:|
| 基础开平仓 | ✅ | ✅ | ❌ |
| 滑点模拟 (固定) | ✅ | ✅ | — |
| 手续费 (Taker) | ✅ | ✅ | — |
| 杠杆 | ✅ | ✅ | — |
| 标记价 vs 成交价 | ❌ 使用成交价 | ✅ 分离 | — |
| 资金费率 (Funding) | ❌ | ✅ 每8h结算 | — |
| 维持保证金 + 强平 | ❌ 简化 | ✅ MM阶梯 | — |
| 滑点模型 (按名义) | ❌ | ✅ `slippage_bps` | — |

## 已模拟项
- 滑点：固定 `SLIPPAGE_RATE = 0.001`（0.1%）
- 手续费：固定 `TAKER_FEE_RATE = 0.0005`（0.05%）
- 杠杆：保证金 = 名义 / 杠杆
- 止盈/止损限价单检查
- 部分平仓

## 未模拟项（即便 research 模式）
- 真实订单簿深度与排队
- 自适应保证金阶梯（按品种不同档位）
- ADL（自动减仓）
- 交割合约到期结算
- 跨品种保证金抵扣

## 配置方式

```bash
# 启用研究模式
PAPER_SIMULATION_TIER=research

# 资金费率结算周期（秒，默认 8 小时）
FUNDING_SETTLE_INTERVAL_SEC=28800

# 维持保证金率（简化固定值）
MAINT_MARGIN_RATIO=0.005
```

## 重要声明

**本纸面仿真不等同于任何交易所真实环境**。`research` 模式提高保真度但仍有显著简化。
实盘交易需要独立的风控审查和法律合规评估。
