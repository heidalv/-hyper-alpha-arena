## 0. 结论（TL;DR）

1. **引文查证**：外部 v0.5.1 引用的模型全部真实存在，但有三处需要修正——
   "日频约5000样本横截面"是 **A 股语境**；本仓库宇宙为**四层结构**（数据中心 `symbol_catalog`
   在册 **2,577 个在市交易对** / K线采集宇宙 **200+ 币** / 核心观察 **18 币** / 动态注入 **3-5 币**，
   详见 §2.1）；ADD 是 **2020 年微软 CIKM 期论文**
   （解缠超额收益/市场信息 + 蒸馏），不是 2024 新模型；TabPFN v2 **没有 listwise 排序目标**（只有回归/分类），
   "LTR 目标函数"只能由 LightGBM `lambdarank` 承担，TabPFN 走"回归出分、按 RankIC 评估"的分工。
2. **架构方向认可**：双通道（数值模型 + LLM 本身当打分器）在论文层面有直接依据——
   Lopez-Lira & Tang (2023) 证明 LLM 直接输出数值收益预测具有显著 IC；FinMem 证明分层记忆跟踪
   agent 历史表现能提升交易决策。通道 B 不是花架子。
3. **本仓库的分层宇宙适配**（数据中心既有现实，无需"扩展"）：通道 A 直接用 K线采集宇宙
   **200+ 币**做横截面训练（MASTER/StockMamba 的横截面注意力广度天然满足，目录在册 2,577 对
   为后续扩容上限）；通道 B（证据包按 token 计费）只覆盖**核心观察 18 币 + 动态注入 3-5 币**。
4. **影子打分通道有直接仓库先例且必须吸收其教训**：`learned_weighting.py` 的 shadow→hybrid→learned 三段式
   就是融合层的采用路径模板；`paper_factor_policy.py` 的 09-03 审查结论（paper 因子半权重混入实盘违反隔离）
   明确了影子通道红线——**只打分、只统计 IC、权重恒为零**，不进组合。

## 1. 论文依据（逐篇查证）

### 1.1 TabPFN v2 —— 通道 A 零样本表格基线

Hollmann et al., *"Accurate predictions on small data with a tabular foundation model"*, **Nature** (2025-01)，
已引 1800+。要点：
- 预训练表格基础模型（先验数据拟合网络），**≤10,000 样本 / ≤500 特征 / ≤10 类**区间内主导性优于调参 GBDT；
- 免预处理（缺失值/离群点/不规则特征直接进），推理秒级；
- 超限走训练集子采样（官方 README 明示）。

**对本设计的含义**：K线采集宇宙 200+ 币 × 1d × 3 年 ≈ 20 万行面板，**远超 1 万样本限**——
TabPFN 的正确用法是滚动短窗/子采样（训练块按时间切块），或直接在核心观察 18 币子宇宙上跑零样本对照；
主力排序模型是 LightGBM-lambdarank，TabPFN 是"免调参对照组"而非主力。
特征侧 = 活跃因子池暴露（当前 12 active + alpha101 库 102 候选筛选），远低于 500 特征上限。
**注意**：TabPFN 是 iid 行假设的先验——面板数据有时间相依性，必须按时间切块（训练块严格早于评估块），
禁止随机行分割（否则横截面同期相关性泄题）。

### 1.2 MASTER —— 横截面注意力深度模型（Qlib 基准榜首线）

Li et al., *"MASTER: Market-Guided Stock Transformer for Stock Price Forecasting"*, **AAAI 2024**（已引 181+）。
要点：momentary attention（时序内）+ cross-sectional attention（横截面股票间）+ market guide
（用一致性分数选 top-k 股票构造市场指数引导）。**设计初衷是几千只股票的横截面**。

### 1.3 ADD —— Qlib 生态的老牌基线（修正年代）

*"ADD: Augmented Disentanglement Distillation Framework for Improving Stock Trend Forecasting"*,
Microsoft Research（CIKM 期，约 2020）。要点：解缠"超额收益 vs 市场信息"两因子 + 蒸馏提鲁棒。
**修正**：外部文档若把它列为 2024 线新模型，应更正为 2020 基线；保留价值 = 解缠思想（分离 β 与 α）
对加密市场同样适用（币种间市场共性极强，BTC β 占比高）。

### 1.4 StockMamba / MambaStock —— 状态空间模型线

- MambaStock：Shi, arXiv:2402.18959（2024，已引 54+）——选择性状态空间模型免特征工程预测股价；
- **StockMamba**：MDPI Mathematics 14(11):1859（2026）——**双通路：状态空间动态因子选择 + rank-aware 机制**，
  是"SSM + 排序感知"的代表，与 LTR 目标同向。

### 1.5 LambdaMART / lambdarank —— 通道 A 的目标函数

Burges, *"From RankNet to LambdaRank to LambdaMART: An Overview"*（2010）。LightGBM **原生支持
`objective='lambdarank'`**——通道 A 基线不用换框架，改一行目标函数 + 按日期构造 group（每日横截面为一个
query group）即可从收益回归切到 listwise 排序，直接优化 RankIC 同族目标。

### 1.6 Lopez-Lira & Tang —— 通道 B"LLM 当打分器"的直接依据

*"Can ChatGPT Forecast Stock Price Movements? Return Predictability and Large Language Models"*
（arXiv:2304.07619, 2023）。要点：LLM 读新闻标题直接输出数值化收益预测/情绪分，样本外 IC 显著且
**强于传统情绪分析器**——证明 LLM 的数值输出本身就是有效 alpha 源（正是通道 B 的合法性论证）。
配套：**FinMem**（arXiv:2311.13743）分层记忆 + **历史表现跟踪**支撑"记忆库里该类 thesis 的历史准确率"
这一证据包组件；**TradingAgents**（AAAI 2025，仓库已在 `trading_analysts.py` 落地）支撑辩论记录入证据包。

### 1.7 James-Stein 收缩 —— 融合层的防过拟合权重

经典收缩理论（James-Stein 1961 / Efron-Morris 1975）：当各通道近期 IC 估计噪声大时，通道权重应向
均匀先验收缩，收缩强度随 IC 估计方差增大。落地形式：
`w_channel = (1-λ)·w_ic + λ·w_prior`，λ 由该通道 IC 的滚动标准差驱动（IC 越不稳，越信先验）。

## 2. 对外部 v0.5.1 设计的核对与修正清单

| 外部设计原文 | 核对结果 | 修正 |
|---|---|---|
| "日频全市场横截面约5000样本，正中 TabPFN 甜区" | ❌ 语境错误：5000 是 A 股股票数 | 本仓库宇宙四层（§2.1）；TabPFN 用采集宇宙滚动子采样或核心 18 币子宇宙做零样本对照，主力是 LightGBM-lambdarank |
| "ADD（Qlib 基准生态）" | ⚠️ 年代错误 | ADD 为 2020 微软论文；作为基线保留，标注年代 |
| "目标函数改为 LTR 优化 RankIC" | ⚠️ 分工不清 | LightGBM=`lambdarank`（原生）；TabPFN=回归出分+RankIC 评估；StockMamba=rank-aware 结构自带 |
| "MASTER/ADD/StockMamba 数据格式与因子库兼容" | ✅ 且前提已满足 | 横截面注意力需币种广度：采集宇宙 200+ 币训练（数据中心既有）、核心观察层部署；扩容上限 = 目录在册 2,577 对 |
| "隔离纪律（P10）" | ⚠️ 命名冲突（本仓库 P10 是补丁号） | 沿用 **REV-P10**（与 ADR-21 评审文档一致），只读生产命名空间不变 |
| "已晋级 LLM alpha 因子作特征" | ⚠️ 现实约束 | 实测 **llm-source 活跃因子 = 0 条**（12 个 active 全部 source=registry）；+LLM alpha 消融臂初期为空，靠影子通道逐步填充 |
| "影子通道让 lab 信号积累实盘证据" | ✅ 且有仓库教训背书 | 吸收 `paper_factor_policy.py` 09-03 审查结论：**只打分不进组合、权重恒零**，避免"半权重混入实盘"重演 |

### 2.1 宇宙四层结构（数据中心权威口径，2026-09-17 实测）

| 层 | 规模 | 来源与证据 |
|---|---|---|
| L0 目录宇宙 | **2,577 个在市交易对**（binance 773 / bybit 663 / asterdex 507 / okx 404 / hyperliquid 230，全部 status=trading） | `alpha_market.symbol_catalog`（数据中心全市场目录） |
| L1 K线采集宇宙 | **200+ 币** × 5 所 × 14 周期，6200 万根 K线，2017-08-17 → 当日 | `alpha_market.crypto_klines`；通道 A 的训练横截面 |
| L2 核心观察宇宙 | **18 币**（BTC ETH SOL BNB ASTER XPL VIRTUAL AAVE AEON APT AR BTW HOME HUMA ZEC JTO UNI XRP） | `data_center_routes._DEFAULT_UNIVERSE`（与 KLINE_FRESHNESS_SYMBOLS 同源，短线扫描宇宙）；深度回填热点池 ≤60（hot 模式） |
| L3 动态注入宇宙 | 每轮 **3-5 币** 注入交易会话，历史去重 28 币，冷却/黑名单 83 币 | `auto_coin_selector.py` 五阶段流水线（Scan→Enrich→AI Review→Inject→Evaluate）+ `backend/data/auto_coin_injected/` |

**打分中心宇宙决策**：通道 A 训练 = L1（200+ 币横截面）；部署评估 = L2+L3；通道 B 证据包 = L2+L3（成本红线）。
**幸存者偏差校正**：L0 目录含全部在市对，回测宇宙若只取 L1 会漏"采集前已下市"样本——消融报告须声明口径。

## 3. 架构设计与仓库锚点

```
                    ┌─ 通道A（数值）：L1采集宇宙200+币（训练） → L2核心18+L3注入（部署）
  生产因子池(只读) ──┤    LightGBM-lambdarank(稳态) / TabPFN v2(零样本对照) / MASTER·StockMamba(进阶)
  + 已晋级LLM alpha ─┤
  + thesis数值特征  ─┤
                    └─ 通道B（证据）：L2核心观察18币 + L3动态注入3-5币
                         证据包 = 因子暴露摘要 + thesis/辩论记录 + 舆情事件精评
                                  + 记忆库该类thesis历史准确率（全部 evidence_refs 锚定，仅当日可得）
                         LLM 综合器 → 评分 + 文字理由（Lopez-Lira & Tang 范式）
  融合层：James-Stein 收缩的自适应 IC 加权 + 宏观 regime gate（趋势/震荡/高波）
  影子层：lab 区信号每日只打分只统计 IC → 喂 REV-P10/P12 评审门（权重恒零）
  消融层：四档矩阵（纯因子 / +thesis / +LLM综合器 / 全开）× 市场状态，强制出报告
```

### 3.1 通道 A（数值通道）

| 组件 | 论文 | 仓库锚点 | 落地要点 |
|---|---|---|---|
| LTR 稳态基线 | LambdaMART | `learned_weighting.py`（Qlib 式学习加权层，`get_model/SupervisedModel` 统一接口，**shadow→hybrid→learned 三段式现成**） | LightGBM `objective='lambdarank'`，group=每日横截面；标签=日内前瞻收益的横截面秩 |
| 零样本基线 | TabPFN v2 | 新增后端挂进 `get_model` 接口 | 滚动短窗/子采样 ≤1 万行（或 L2 核心宇宙直接跑）；**时间切块 CV**，禁随机行分割 |
| 进阶深度 | MASTER / StockMamba / ADD | `dataset_builder.py` 产 Qlib 风格面板 | L1 采集宇宙 200+ 币训练（横截面广度天然满足）；ADD 的解缠思想用于分离 BTC β |
| thesis 数值特征 | —（TradingAgents 配套） | `agent_decision_envelope.py` / `decision_fusion_arbiter.py` | 观点分/置信度/多空方向从决策信封数值化，**point-in-time 取快照** |

### 3.2 通道 B（证据通道）

- **证据包 schema**（每币每日一份，token 预算 ≤4k）：`{symbol, date, factor_exposure_summary(通道A特征摘要),
  thesis_records[](带 debate_log_id), news_event_digest, thesis_type_accuracy(记忆库检索),
  evidence_refs[](全锚定)}`；
- **LLM 综合器**：输出 `{score∈[0,10], direction, confidence, rationale≤120字}`——数值化直接对标
  Lopez-Lira & Tang 范式；
- **记忆检索**：`rag_knowledge_service`（bge+Chroma，2203 向量在库）查"该类 thesis 历史表现"，
  `decision_feedback_service.py` 供历史准确率统计；
- **成本**：L2+L3 ≈ 23 币 × ≤4k token ≈ 9 万 token/日，DeepSeek 价格 <¥1/日——通道 B 只覆盖
  核心观察+动态注入层是成本红线（若扩到 L1 采集宇宙 200+ 币则日耗 80 万 token+，需另行评审）。

### 3.3 融合层

- 通道分先转横截面秩再融合（尺度统一）；
- 权重 = James-Stein 收缩滚动 IC 加权（§1.7），先验=等权；先例锚点：`combo_weights.py` / `online_weights.py`；
- regime gate：宏观分析师市场状态 → 分状态查四档矩阵，决定融合开关与收缩强度；锚点：`_daily_regime` /
  `midlong_regime_weights.py`。

### 3.4 影子打分通道

- lab 区（factors_lab / 未晋级 LLM 信号）每日参与打分，**权重恒为零，不进任何组合与实盘口径**；
- 只落 IC/RankIC 时序日报 → 作为 REV-P10/P12 评审门的证据输入；
- 纪律依据：`paper_factor_policy.py` 09-03 审查（半权重混入实盘=违反隔离，本通道不得重演）；
  周期驱动复用 `shadow_judge.py` 调度模式。

### 3.5 消融纪律（四档 × 状态矩阵，强制报告）

| 档 | 特征集 | 初期现实 |
|---|---|---|
| A0 纯传统因子 | 生产因子池 | ✅ 立即可跑（12 active + 102 alpha101 候选） |
| A1 +thesis | + 观点分/置信度/方向 | ✅ 决策信封已有数据，需回填历史 |
| A2 +LLM综合器 | A1 + 通道B 评分作为特征 | ✅ 可跑 |
| A3 全开 | 双通道融合输出 | ✅ 可跑 |
| （横向）+LLM alpha | + 已晋级 LLM 因子 | ⚠️ 当前 0 条，靠影子通道与五 agent 闭环逐步供数 |

每档 × {趋势, 震荡, 高波} 出 IC/RankIC/超额/换手对比——报告模板挂 `evaluation.py` 既有指标。

### 3.6 防泄漏三原则 → 仓库机制映射

1. **point-in-time**：因子值与 thesis 特征都取决策时点快照（`dataset_builder` 防前视处理器 +
   决策信封时间戳）；
2. **LLM 不见原始行情/时间切分**：证据包只含当日可得摘要（RD-Agent schema 纪律，同 ADR-21 闭环）；
3. **标签无未来污染**：前瞻收益标签经 `expr/audit` 同源纪律，评估走 `evaluation.py`（CPCV）。

## 4. 里程碑（建议 3 周 → 4 段）

- **HC-1（第1周）**：通道 A LTR 基线 + 消融矩阵骨架（L1 宇宙面板）。验收：lambdarank vs 回归的
  RankIC 对比报告落地；A0/A1 档出数。
- **HC-2**：TabPFN 后端 + 通道 B 证据包管线。验收：L2+L3（≈23 币）证据包日更；LLM 综合器评分入落盘；
  A2 档出数；token 用量纳管（`llm_quota_usage` 计量）。
- **HC-3**：融合层 + regime gate + 影子通道。验收：James-Stein 权重日报；影子通道 IC 日报；
  全链防泄漏审计（point-in-time 抽查）通过。
- **HC-4**：深度模型进阶。验收：MASTER/StockMamba 在 L1 宇宙训练、L2 部署集上的
  RankIC vs LightGBM/TabPFN 对照；四档 × 状态归因矩阵完整出报告。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| L2 部署层（18+3-5 币）横截面窄，RankIC 噪声大 | 训练用 L1（200+ 币）、评估分 L1/L2 双口径出报告；评估窗拉长 + 分 regime 切片；CPCV/DSR 纪律复用 |
| 宇宙幸存者偏差（L1 只含被采集过的币） | 消融报告声明口径；用 L0 目录（2,577 对，含新上市/下市流转）做宇宙审计 |
| 动态注入宇宙（L3）样本外轮换 | 选币注入带时间戳入面板；评估时 L3 币按注入时点起算，防前视 |
| TabPFN iid 先验遇面板时间相依 | 强制时间切块 CV；训练窗 ≤1 万行 |
| 深度模型在采集宇宙过拟合 | 部署层（L2+L3）严格 OOS；PBO/DSR 门禁不放宽 |
| 通道 B 证据包被注入过期信息 | evidence_refs 全锚定 + 生成侧"仅当日可得"硬过滤 + 抽查审计 |
| 影子通道变相影响实盘 | 权重恒零写死在代码常量 + 月度审计（复用 09-03 审查模式） |
| LLM 评分漂移（prompt/模型升级前后不可比） | 评分版本号入落盘；升级前后并行影子两周 |
