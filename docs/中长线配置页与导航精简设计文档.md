## 3. 长线(Trend)配置页设计

### 3.1 长线特殊点

- **TP=0（无固定止盈）**：交给 D14 分批战略 TP（8%/15%/25% 减仓）
- **趋势复查**：90 分钟一次 LLM 复查（hold/reduce/close/tighten_trailing）
- **金字塔补仓**：趋势确认后可加仓
- **更长持仓**：2h-7天

## 4. 提示词结构化管理

### 4.1 核心问题

当前提示词存在 3 个位置：
1. 磁盘文件 `docs/opencode/prompts/tasks/*.md`
2. DB 表 `prompt_versions`（L2 优化版本）
3. Agent 代码内 `inline fallback`（硬编码）

**风险**: 用户在配置页改了提示词，如果改动破坏了 JSON 输出格式 → Agent 解析失败 → 策略停止工作。

### 4.2 结构化保护方案

#### 4.2.1 提示词分区

每个提示词分为两个区域：

```
┌─ ✏️ 可编辑区域（用户可自由修改）──────────────
│
│  ## 分析要求
│  1. 评估 1h/4h 趋势强度
│  2. 寻找回调入场点（支撑位+趋势顺势）
│  3. 关注 RSI 超卖区
│  ...
│
├─ 🔒 输出契约（只读，禁止修改）────────────────
│
│  ## 输出格式（仅 JSON）
│  {
│    "action": "buy|sell|hold",        // 必填
│    "confidence": 0-95,                // 必填
│    "direction": "long|short|neutral", // 必填
│    ...
│  }
│
└────────────────────────────────────────────
```

#### 4.2.2 字段锁定

每个 JSON 字段标记为：
- 🔒 **locked**: 字段名和类型不可修改，灰色只读显示
- ✏️ **editable**: 字段的描述/注释可修改

```json
{
  "🔒action": "buy|sell|hold",        // locked: enum
  "🔒confidence": 0-95,                // locked: range
  "🔒direction": "long|short|neutral", // locked: enum
  "🔒sl_pct": 0.02-0.05,               // locked: range
  "🔒tp_pct": 0.04-0.09,               // locked: range
  "🔒risk_reward": "float",            // locked: type
  "🔒cited_fact_ids": "[]",            // locked: array
  "✏️reasoning": "你的分析推理过程"     // editable: 自由文本
}
```

#### 4.2.3 保存时校验

保存提示词时，后端执行结构校验：
1. 提取提示词中的 JSON 模板部分
2. 验证所有必填字段（`locked` 字段）仍存在
3. 验证字段名未被修改（`action` 不能改成 `decision`）
4. 如果校验失败 → 拒绝保存 + 高亮被破坏的字段

```python
def validate_prompt_structure(prompt_text: str, required_fields: list[str]) -> tuple[bool, str]:
    """校验提示词的 JSON 输出契约未被破坏。"""
    # 提取 JSON 模板
    json_match = re.search(r'\{[^{}]*\}', prompt_text)
    if not json_match:
        return False, "未找到 JSON 输出模板"
    
    for field in required_fields:
        if field not in prompt_text:
            return False, f"必填字段 '{field}' 被删除"
    
    return True, "OK"
```

#### 4.2.4 测试功能

"测试提示词"按钮：
1. 用当前提示词 + 模拟数据调一次 LLM
2. 检查返回的 JSON 是否包含所有必填字段
3. 显示 LLM 的完整返回 + 解析结果
4. 如果解析失败 → 红色警告 + 定位问题

### 4.3 提示词配置页 API

```
GET  /api/strategy-prompt/{tier}          # 读取中线/长线的提示词
PUT  /api/strategy-prompt/{tier}          # 保存（含结构校验）
POST /api/strategy-prompt/{tier}/test     # 测试提示词
GET  /api/strategy-prompt/{tier}/schema   # 获取JSON契约（只读）
POST /api/strategy-prompt/{tier}/reset    # 恢复默认
```

### 4.4 提示词存储

改后的提示词写入 DB 表 `strategy_prompt_overrides`:
```sql
CREATE TABLE strategy_prompt_overrides (
    id SERIAL PRIMARY KEY,
    tier VARCHAR(10) NOT NULL,          -- 'mid' / 'long'
    task_id VARCHAR(50) NOT NULL,       -- 'task_swing_agent' 等
    system_prompt TEXT,                 -- 系统角色
    task_prompt TEXT,                   -- 任务指令（含JSON模板）
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

渲染时优先级：
1. DB `strategy_prompt_overrides`（配置页保存的版本）
2. DB `prompt_versions`（L2 自进化版本）
3. 磁盘文件 `docs/opencode/prompts/tasks/*.md`
4. Agent 代码内 `inline fallback`
