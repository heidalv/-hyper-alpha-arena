# 中线因子化 + 长线纯 AI 架构评估

>

> 结论先行：**方向成立、与全部证据一致，但有一个硬前提（中线因子弹药库当前为空）和一个设计选择（中线 LLM 去留）需要拍板。**

## 1. 提案理解与目标架构

```
┌─────────┬──────────────────┬─────────────────────────┐
│ 周期    │ 现状              │ 提案目标                │
├─────────┼──────────────────┼─────────────────────────┤
│ 短线    │ 因子路由（已有）  │ 不变                    │
│ 中线    │ LLM 主导（MLTO） │ → 因子化（规则决策）    │
│ 长线    │ LLM TrendAgent   │ → 纯 AI（保持不变）     │
└─────────┴──────────────────┴─────────────────────────┘
```

核心思想：**中频决策是「数值模式识别」问题（因子能编码），长线决策是「叙事/宏观/regime 判断」问题（LLM 长板）**——把 LLM 从中线摘掉，只保留在它能创造价值的长线。

## 2. 现状盘点（两边家底，全部实测）

### 2.1 因子侧：基础设施齐全，但弹药库为空

| 组件 | 状态 |
|---|---|
| 中线因子评分器 `factor_engine/midlong_active_factor_set.py` | ✅ 存在：IC 回测（回看 900、前瞻 4h=6 根 / 1d=3 根）、min_sharpe=0.4、晋升/候选/拒绝三态 |
| Alpha101 因子注入 `alpha101_factors.py`（标 horizon=midlong） | ✅ 已灌 22 个 ai_generated + 20 个 legacy 因子 |
| 演化调度接因子研究 `evolution_scheduler.py` | ✅ 已接线 |
| 因子在 MLTO 中的角色 `mlto/qual_layer.py` | ⚠️ 仅作「LLM 证据摘要」（v6 M4 明确「禁止进 Hub 投票」） |
| **中线活跃因子数（实测 `get_health_snapshot()`）** | ❌ **active=0 / candidate=0 / rejected=0** —— 42 个因子**无一通过 IC 回测达标** |
| 短线范式模板 `scalp_factor_router`（IC 加权 + 类别去重 + 边缘 LLM 裁决 + walk-forward 验证） | ✅ 中频因子化的现成可复用范式 |

**含义**：中线因子化不能「切个开关就上线」——当前没有任何一个有统计边缘的因子可用，必须先跑因子研究把弹药生产出来。

### 2.2 AI 中线现状（为什么要摘掉它，数据实证）

- 决策负 EV：swing 315 笔 -53.39、RR≈0.66（砍赢单留小亏）；
- LLM JSON 解析失败反复发生（`Expecting value: line N column M`），失败回退置信度虚高仍开仓（量化员 P0-1）；
- 成本：每 tick 每币 60-120s 串行 LLM，单轮循环 390s+，持仓管理被拖累；
- 「把大模型当计算器用」（`docs/中长线提示词深度审查与重构方案.md` §1.1）：EMA/RSI/vol_ratio 代码已算好，LLM 重算一遍毫无增量；
- 外部证据：TradeTrap 审计——LLM 交易代理幻觉/不忠实是常态；JSON 失败率 ~10-15% 是行业基线。

### 2.3 AI 长线现状（为什么保留它，数据实证）

- `trend_follow` 是**唯一净盈利的 tier**（+4.37，胜率 55.3%）；
- TrendAgent 证据链已建：cited_fact_ids 覆盖率 100%、evidence_checklist 可用率 71-75%、cycle_prob 概率先验可用率 100%；
- 长线决策频率低（4h/1d）、单次决策价值高，LLM 的叙事/宏观判断正好匹配；
- 缺陷在「执行层被砍」与「模板双轨混入均值回归」，不在 LLM 本身。

## 3. 证据评估（支持 / 反对）

### 3.1 支持「中线因子化」的证据

1. **周期可测性**：项目自研 `CYCLE_DIRECTION_RESEARCH` 结论——短周期（1m/15m）均值回归、**长周期（4h/1d）趋势可测**；中线（1h-4h）处于可测区，适合因子建模。
2. **学术**：TSMOM 与加密动量实证（外部调研 §一）——中频动量因子在加密有证据；行业惯例（ADX 过滤 + ATR 定仓）全部是**规则可编码**的，不需要 LLM。
3. **样本效率**：因子用 K 线 IC 回测验证（数百万根 K 线），样本量远超交易样本（315 笔）——因子化能把「验证」从实盘试错搬到离线。
4. **可靠性**：规则执行确定性 100%，不受 JSON 解析失败/幻觉影响；失败模式可控（fail-closed）。
5. **成本**：摘掉中线 LLM 后，单轮循环 390s → 秒级，持仓管理/冷却时间戳失真问题一并解决（量化员 P2-8）。
6. **短线已走通**：scalp_factor_router 是同构范式，中线可以照搬（路由→类别去重→IC 加权→门控→执行）。

### 3.2 反对 / 风险的证据

1. **弹药库为空（最大障碍）**：42 个因子 0 达标——「因子化」的第一周没有任何信号可用；因子研究有失败风险（加密中频因子的 IC 衰减快）。
2. **过拟合风险**：IC 回测达标 ≠ 样本外有效；必须复用 walk-forward 门禁（`AI_WALK_FORWARD_VALIDATION_ENABLED=true` 已存在），否则重蹈「占位指标晋升」覆辙（§2.5-二）。
3. **叙事突变盲区**：纯因子对突发新闻（ETF 消息、监管、插针）没有感知；中线虽快于长线，但仍可能持有数小时跨过新闻——需要 regime/宏观过滤兜底（现有 regime_agent + 资金费 gate 可复用）。
4. **低频因子结论不稳**：外部调研指出加密短周期「动量 vs 均值回归」结论对参数敏感；中线因子选型需要 4h/1d 两档前瞻分别验证。

### 3.3 支持「长线纯 AI」的证据

1. trend_follow 是唯一正 tier（+4.37）；长线 LLM 没有负 EV 实证（负 EV 在 mid）。
2. 长线价值在叙事/regime/宏观（LLM 长板），因子在周线级样本太少（噪声大）。
3. 行业对照：Man AHL/AlphaQuest 的趋势跟踪同样「规则定仓 + 人/模型做 regime 判断」——长线保留 AI 判断符合主流。

## 4. 可行性结论

**可行，方向正确，推荐采纳。** 但顺序必须对：

- ❌ 不能直接「关掉中线 LLM、切因子」——因子 active=0，切了就是停摆。
- ✅ 正确路径：先产因子（研究管道）→ 因子与 LLM 双轨 shadow 对照 → 达标切换 → 再决定是否摘除 LLM。
- 长线纯 AI 无需改造前提，可直接按「模板收敛 + 提示词重构」推进（P0-G + P2）。

## 5. 中线 LLM 去留：两个选项（请拍板）

| 选项 | 内容 | 优点 | 缺点 |
|---|---|---|---|
| **A. 纯因子（用户提案）** | 因子路由直接决策，LLM 完全不参与中线 | 最彻底：零 LLM 成本/零解析风险/确定性强 | 叙事盲区；因子必须有强边缘；切换前无对照 |
| **B. 因子为主 + LLM 边缘裁决（推荐起步）** | 因子得分高/低直接执行/否决；只有落在阈值带（如 45-55 分）的模糊信号才问 LLM；LLM 失败 fail-closed 回因子结论 | 复用 scalp 已验证范式；叙事盲区有兜底；双轨可对照 | 保留少量 LLM 成本（仅边缘） |

推荐：**B 起步 → 观察 4-8 周 → 数据支持则演进到 A**。A 作为目标态写入设计。

## 6. 目标架构（写入设计文档的形态）

```
中线：因子池(IC达标+WFO通过) → regime/ADX 过滤 → IC 加权合成 score
      → score 高/低：直接开/拒；score 边缘：LLM 裁决(fail-closed)
      → P0-B 砍仓硬门 → P0-E 分层熔断 → 执行
长线：TrendAgent 唯一通道（禁模板双轨）+ 因子/概率引擎作证据
      → 提示词重构（角色+CoT+多情景）→ 同上执行层
```

## 7. 迁移路径（衔接现有 P0 计划）

| 步 | 内容 | 时长 | 验收 |
|---|---|---|---|
| 0 | （不变）P0-H 关 AI 中线 lane + P0-G 模板白名单 + P0-B 硬门 | 0.5-1 天 | 中线宇宙=表单；无 reversion 模板 |
| 1 | **因子研究**：跑 midlong 因子管道（22 ai_generated + 20 legacy → IC 回测 + WFO），达标晋升 active | 1-2 周 | active ≥ 5 个、各 IC>阈值、WFO DSR≥0.5 |
| 2 | **双轨 shadow**：因子信号与 MLTO 并行记录，逐笔对照胜率/盈亏比/回吐率 | 2 周 | 因子信号 ≥ MLTO（对照报告） |
| 3 | **切换**：中线改因子路由（选项 B），LLM 只裁决边缘 | 1 天 + 4 周观察 | 切换后 30 笔滚动胜率 ≥40%、RR≥1.2 |
| 4 | 视数据演进到纯因子（选项 A） | 待定 | LLM 摘除后指标不回退 |
| 5 | 长线：模板收敛 TrendAgent 唯一通道 + 提示词重构 | 2-4 周 | 长线无 reversion 模板；证据链可用率 ≥80% |

## 8. 风险与前提汇总

1. **前提**：因子研究必须产出真实达标因子（IC + WFO 双门禁，禁止占位指标）——否则本方案整体延后，中线暂以「P0-G 白名单模板 + 修好的 MLTO」过渡。
2. **风险**：因子过拟合 → WFO 门禁 + 每 3 天衰减监控（现有演化调度可接）；叙事盲区 → 选项 B 边缘裁决 + regime/资金费 gate；切换期波动 → 双轨 shadow 对照 + 灰度开关。
3. **与既有整改的关系**：本方案不替代 P0-A~P0-H（止血优先），是 P0 之后的「中线重建」路线；P0-G 白名单正好为因子化提供了模板治理底座。

## 9. 需要你拍板的三个点
