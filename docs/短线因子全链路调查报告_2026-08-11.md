## 0. 一句话结论

短线**热路径完整、纸盘能成交**；但**能成交 ≠ 有边缘**。

- Meta 报告：`usable=false`，OOS AUC≈**0.517**，基线胜率≈**35.0%**，基线净收益≈**−0.22%**；过滤 top30% 胜率略升，净收益仍更差。
- 调 `SCALP_SIZE_PCT` / 保证金只能改赔付规模，救不了 alpha。
- 优先修顺序：**Router/Loop 算子口径对齐 → sizing 单源 → meta 影子日志 → 三重障碍接 5m 进化 → usable 后 meta 软进 EV → 因子归因喂权重**。

## 3. 断点深挖 → 解法

### P0-1 因子边缘不足（胜率 ~35%）

| 项 | 内容 |
|----|------|
| **症状** | 开仓能成，期望为负；抬/降仓位只改赔付 |
| **根因链** | ① 挖矿目标≠实盘结算 ② 噪声因子可进 Router 主路径 ③ meta 未过滤且自身未过 usable |
| **解法** | 组合拳：先 P0-2/P0-3；收紧 `SCALP_ACTIVE_FACTOR_MAX` + prune；usable 前用更严 EV/置信度**止血**；达标后走 P0-4B |
| **验收** | 14 日纸盘胜率与净收益 vs 改前；活跃因子 IC 分布 |
| **回滚** | 恢复门槛与 ActiveSet 上限 |

---

### P0-2 Router vs Loop 算子口径分裂（优先修）

| 项 | 内容 |
|----|------|
| **症状** | 分数依赖「缓存是否命中」：命中走 exclude，未命中 Router 重算则含 PATTERN/BEHAVIORAL |
| **证据** | [`scalp_loop.py`](../backend/services/full_auto/loops/scalp_loop.py) ≈L369–370：`exclude_categories={PATTERN, BEHAVIORAL}`；[`scalp_factor_router.py`](../backend/services/scalp_factor_router.py) L310、L328：`compute_all_factors(...)` **无** exclude |
| **解法** | ① 抽出常量/env `SCALP_FACTOR_EXCLUDE_CATEGORIES`（或 `SCALP_EXCLUDE_PATTERN=1`）② Router 两处与 Loop 共用 ③ 单测：同 K 线两路径 `direction` 一致 |
| **改动面** | `scalp_factor_router.py`、`scalp_loop.py`、新增/扩展 unit test |
| **风险** | 分数分布变化 → 成交变少/变多 |
| **回滚** | 关 exclude 开关 |
| **工时** | ~0.5 天 |

---

### P0-3 挖掘标签与实盘错配

| 项 | 内容 |
|----|------|
| **症状** | IC/晋升优化「未来 5 根简单收益」；实盘按 SL/TP/超时结算 |
| **证据** | [`factor_evolution_loop._forward_returns(horizon=5)`](../backend/services/evolution/factor_evolution_loop.py) 多处；[`factor_labels.build_triple_barrier_labels`](../backend/services/evolution/factor_labels.py) 已实现，但 `FEATURE_FACTOR_LABELS_ENABLED` 默认 **false** 且**未接挖矿**；`meta_label_samples` 仍空壳 |
| **解法** | 仅短线 `run_scalp_factor_evolution_loop` / 评估路径：开关为 true 时用三重障碍标签 + `net_ic`；**不**一次改 4h 中长线 |
| **默认** | 开关仍关 → 纸盘先开对比晋升质量 |
| **验收** | 新 `s5m_*` 在纸盘 SL/TP 方向命中率 ≥ 旧标签晋升集 |
| **回滚** | `FEATURE_FACTOR_LABELS_ENABLED=false` |
| **工时** | 1–2 天 |

---

### P0-4 Meta「训而不用」+ usable=false

| 项 | 内容 |
|----|------|
| **症状** | 日训有报告，对开仓零影响；现模型也不该硬拦 |
| **证据** | [`predict_win_prob`](../backend/services/scalp_meta_trainer.py) 标明影子；实现**未强制**读 `bundle.meta.usable`；`scalp_loop` 不调用；[`scalp_ev_gate`](../backend/services/scalp/scalp_ev_gate.py) 用 `scalp_confidence_calibrator.estimate_p_win` |
| **解法 A（影子，先做）** | 开仓前调 `predict_win_prob`，只写 `meta_p_win` 到 signal_log/审计；日更事后对比「若按 top30% 过滤」净收益是否转正 |
| **解法 B（软进 EV）** | `SCALP_META_IN_EV=0\|1`（默认 0）；仅 `usable=true` 时 `p_win = blend(calibrator, meta)` 或 `min(...)`；同时让 `predict_win_prob` **强制**查 usable |
| **硬拒条件** | 连续 2 周影子对照：过滤后净收益转正且覆盖率 ≥15%，再开 `SCALP_META_HARD_FILTER` |
| **验收** | 关开关行为不变；开时仅 usable 模型改 p_win |
| **回滚** | `SCALP_META_IN_EV=0` |
| **工时** | A 0.5 天；B 1 天 |
