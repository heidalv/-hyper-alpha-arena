## 0. 一句话结论

现系统的问题是**"链条太长、每一环都打折、最后一环静默丢弃"**：
一个信号要过六层缩仓（乘子乘积 ≈0.0014）→ 名义被抬到 $60 地板 → 再被策略装配/会话可见性/
出场闸逐个消耗，最后**开不出来或开出来是个 $60 的噪音单**。
所以本设计的主轴不是"再找一个更强的因子"，而是：

1. **把乘子链换成一次风险预算**（§7）；
2. **把两条车道彻底分治**：日内(中线)与趋势(长线)各自建模、各自出场、各自验收（§6、§16）；
3. **把"每笔决策 → 每个结果"变成可 join 的数据契约**，学习才有输入（§10）；
4. **把模拟盘当数据工厂**：用统计功效反推"该开多大、该开多少笔"（§13）；
5. **每个改动预登记判据**，用反事实与 walk-forward 验收，而不是凭感觉调参（§12、§18）；
6. **方向跟随 regime，不设单边**（v2）：up 做多 / down 做空 / chop 条件单，
   空头与多头共用风险预算、共入学习闭环、各自验收（§1.2、§3.3、§6.2b、§11）。

## 1. 目标、口径与验收

### 1.1 目标（用户的最终口径）
在**不改杠杆**（币种档位固定：BTC/ETH 5x，其余 4x）的前提下，让
**日内(中线)车道与趋势(长线)车道各自实现正期望**，并在摸底窗口内合计为正收益。
两条车道的方向**都不预设**：跟随 regime 对称治理（§1.2 第 1 条），
上行趋势做多、下行趋势做空，震荡按实测最优档做条件单。

### 1.2 三条不可谈判的约束（来自用户，v2 修订）
1. **方向跟随 regime，禁止任何单边焊死**——up 做多 / down 做空 / chop 按实测最优档；
   任何形式的"永久禁空"或"只做多"都违反本约束。依据：N3_regime 大样本
   down 空头 +0.618%/14d（t=+4.09）与 up 空头 −1.038%（t=−4.11）并存——
   "能不能做空"由 regime 决定，不是由禁令决定（§3.3）；
2. **不因"怕亏"而压制开仓**——模拟盘的任务是攒数据，空头样本同样必须持续采集、
   结算、学习（空头亏过的教训是改入场条件，不是关车道）；
3. **杠杆不动，仓位靠保证金/名义调节**。

### 1.3 摸底口径（事先写死，避免事后解释）
| 项 | 定义 |
|---|---|
| 窗口 | 连续 30 个自然日，窗口内**不改任何参数**（只允许修 bug，且 bug 修复需记录并单独标注） |
| 主指标 | 净收益 = Σ(平仓毛盈亏) − 全部手续费 − 资金费（当前口径缺少资金费，见 §10.4） |
| 车道指标 | 每条车道单独报：笔数 / 胜率 / 盈亏比(PF) / 期望(每笔) / 最大回撤 / 中位持仓时长 |
| 样本门槛 | **每条车道 ≥ 200 笔**且**每个 regime 桶 ≥ 40 笔**且**每个 (方向×regime) 桶 ≥ 40 笔**（否则结论只写"样本不足"，不算通过）——方向对称后，空头线同样必须攒够样本才能验收 |
| 通过线 | 合计净收益 > 0 **且** 两条车道都不为负 **且** 回撤 ≤ 权益 15% |
| 反作弊 | 报告中必须包含"去掉最好 5 笔后是否仍为正"（防单笔幸运） |

## 3. 数学模型层

三条模型并存，各管一段，**不混用**：

### 3.1 状态模型（regime）
- **输入**：1d/4h 的 EMA 斜率、真实波幅(ATR)、已实现波动率 σ_ewma（λ=0.94）。
- **模型**：3 状态阈值模型（现有 `classify_market_environment`：strong_trend / weak_trend / volatile / ranging）
  → 建议升级为 **2 维高斯 HMM**（维：日频收益、波动率），输出状态后验概率 `P(state|t)`，
  **用概率而不是硬标签**驱动仓位（避免"行情变了还在确认"的迟滞）。
- **验收**：状态后验的**切换延迟**（真实转折到识别）≤ 6 小时；误切换率 ≤ 20%。

### 3.2 日内（中线）模型：**均值回复 + 微观结构**
- **核心假设**：日内价格围绕"公允价"（VWAP / EMA21 / 资金费调整后价）做 OU 过程：
  `dX = θ(μ − X)dt + σ dW`，半衰期 `τ = ln2 / θ`。
- **可交易判据**：`|z| = |X − μ| / σ_1h ≥ z*` **且** `τ ≤ 8h`（回复得快才做）。
- **进场**：**回踩/限价**而不是追价（见 §6.1：现在的痛点就是"信号即市价 → 1h 内被打"）。
- **止损**：`k × σ_1h`（k=2.0~2.5）**或**结构位（前低/前高）取更近者，**由波动决定，不用固定 3%**。
- **目标**：回到 μ（第一目标）+ 上轨(μ+1σ)（第二目标）；到 μ 后止损上移到成本（breakeven）。
- **为什么这样改**：实测 `sl` 51 笔 −390.70、中位持仓 1.7h，说明"固定 3% 止损 + 市价追入"
  把赢家（最大逆行 MAE 中位 0.69%、p90 1.04%）和输家（2.56~4.85%）用同一条线切开——
  赢家几乎从不深水，止损却按输家的尺度设。

### 3.3 趋势（长线）模型：**状态空间趋势 + 让利润奔跑（方向对称）**
- **模型**：局部线性趋势（Kalman）：`level_{t+1} = level_t + slope_t + η`，`slope_{t+1} = slope_t + ζ`；
  当 `slope` 显著 > 0（t 统计量 > 2）且价格 > Chandelier(3×ATR) 时持多仓；
  **对称地**：`slope` 显著 < 0（t < −2）且价格 < Chandelier(3×ATR) 时持空仓。
- **进场（多）**：不追高；在趋势内**回踩 EMA20/前高**分批（现有 staged/tranche 机制可复用）。
- **进场（空）**：不追跌；在下降趋势内**反弹 EMA20/前低**分批；拒绝 spike 追空
  （历史追涨空头 72h −13.6%，见 `MIDLONG_SHORT_CHG24_MAX_PCT`）。
- **止损**：Chandelier 3×ATR（当前实测 6.04~8.00% 的宽止损**是对的**，R8 已把上限放到 8%）；空头同距。
- **出场（多）**：只做三件事——① 斜率翻负 ② 收盘跌破 Chandelier ③ 极端回撤闸；
  **出场（空）**：对称三件事——① 斜率翻正 ② 收盘升破 Chandelier ③ 极端反弹闸；
  **不做** ROI 衰减类软出场。
- **实测依据**：long 车道 20 笔 +34.56、PF 2.29 是全系统唯一稳定正贡献；**设计原则是"少干预"**。
  空头侧的正边际在 regime 层已证：down-short 14d +0.618%（t=+4.09，n=8899），
  down-regime 46 笔真实空头合计 +2.33（§3.3 附）。空头同用"少干预"原则，区别只在方向与入场拒绝条件。

### 3.4 波动与成本模型（两条车道共用）
- 波动：`σ_t = max(ATR14/price, σ_ewma)`；止损距离 = `kσ`。
- 成本：taker 0.035%/边 ⇒ 往返 **7bp**；加**资金费**（8h 一次，按持仓时长计提）与**滑点**（限价 0~2bp / 市价 3~8bp）。
- **资金费的方向纪律（v2 新增）**：funding 由**市场结构**决定、不由持仓方向决定——
  上行拥挤时多头付（空头收）、下行拥挤时**空头付**（多头收）。因此 down regime 做空
  很可能持续付出资金费，回测与实盘对账都必须如实计提（§10.4），
  空头线不得按"做空白收资金费"的想象建模。
- **回测必须扣**：7bp + 资金费 + 滑点；否则又会出现"回测很美、实盘为负"。

## 4. 因子层

### 4.1 因子分类（限定可解释、可回测的 6 族）
| 族 | 代表因子 | 适用车道 | 现有资产 |
|---|---|---|---|
| 动量 | 多周期收益(1h/4h/1d/7d)、斜率 t 值 | 趋势 | 已有（factor_engine） |
| 回复 | z-score(VWAP/EMA)、OU 半衰期、布林位置 | 日内 | 部分有 |
| 波动 | ATR%、σ_ewma、波动率变化率 | 两者（定尺寸/止损） | 有 |
| 资金/基差 | funding rate、8h 计提、基差 | 两者（持仓成本） | 有采集（`crypto_klines` + funding 表），需并入决策 |
| 横截面 | 相对强弱（同宇宙排序）、相关性聚类 | 选币 | 币种表有 |
| 微观结构 | 深度/买卖价差/主动成交占比 | 日内 | 采集已有（P1 depth），**尚未进决策** |

### 4.2 因子验收（比"IC 好看"更硬）
1. **样本外 IC/ICIR**：walk-forward 每折独立算（代码已有 WFO_* 工具链）；
2. **正交性**：与已入库因子的 \|corr\| < 0.6，否则合并；
3. **衰减**：半衰期 ≥ 持有周期的 2 倍，否则只配日内；
4. **换手成本**：因子的理论收益必须 > 该周期往返成本 × 换手次数（**这条现在没有硬门禁**）；
5. **落地判据**：因子只有在"把它的权重置零后组合期望下降 > 2σ"时才保留（消融检验）。

### 4.3 因子管道（工程约束）
- 预算：`V3_FACTOR_MAX_SECONDS=120`，实测每轮只能覆盖 **12~19 个 symbol**（远小于候选池）
  ⇒ **设计上必须承认"因子覆盖是稀缺资源"**：按"当前持仓 + 候选池 top-N + 轮转"分配，
  并**把覆盖度写进决策**（覆盖不到的币不允许开新仓，只允许管理已有仓）。
- 缓存：注入 TTL 已做（14400s + 轮转游标持久化）；本设计要求**加一条指标**：
  "当日被因子覆盖过的 symbol 比例"，低于 60% 就告警（否则又在盲开）。

## 5. 分析层（决策前 + 事后）

### 5.1 决策前分析（每次评估产出）
| 输出 | 内容 | 门禁作用 |
|---|---|---|
| regime + 后验 | 状态概率 | 决定用哪条车道的模型 |
| 因子面板 | 各族最新值 + 覆盖标记 | 覆盖不足 ⇒ 不开 |
| 微观结构 | 价差/深度/预计滑点 | 滑点 > 预期收益 20% ⇒ 不开 |
| 成本预算 | 往返费 + 资金费 + 滑点 | 目标收益 < 成本 × 3 ⇒ 不开 |
| 论题 | 方向/失效条件/预期持有 | 写入 `mlto_thesis`，作为归因主键 |

### 5.2 事后分析（每笔平仓自动产出，落库而非只写日志）
- **入场质量**：`MAE_1h / σ_1h`（>2 说明入场时机差）、入场滑点、信号后延迟；
- **持仓质量**：MFE 实现率 = 实现收益 / MFE（<0.4 ⇒ 出场太早；>1 ⇒ 数据错）；
- **出场质量**：出场后 1h/4h 的价格走向（"卖飞"或"躲过"）；
- **归因**：按 regime / setup / 币种 / 时段 四维分组，**每组必须给样本数**（不足 30 笔不下结论）。

> 这一层是"摸底为正"的**仪表盘**：没有它，任何调参都是盲调。

## 6. 策略层（两条车道分治）

### 6.1 日内（中线）策略 —— 目标：把 <1h 秒亏与同币重入消灭掉
| 环节 | 设计 | 依据 |
|---|---|---|
| 选币 | 因子覆盖 ∩ AI 候选 ∩ 价差合格；**同一 setup 5 分钟内最多 2 个 symbol** | 已有同模板限流 |
| 进场 | **回踩挂单**（限价 = μ ± 0.3σ），15 分钟内未成交则放弃 | <1h 桶 −96.29 的主因是追价 |
| 止损 | `max(结构位, 2.2σ_1h)`，但**不超过** 3%（现 cap） | 赢家 p90 MAE 1.04%，2.2σ 通常 1~2% |
| 止盈 | 到 μ 平 50% + 止损抬到成本；到 μ+1σ 平 30%；余 20% 用 1×ATR 跟踪 | `breakeven_tp` 已是最大盈利来源(+327.85)，说明"保本+小目标"适配 |

## 7. 执行层（本设计的核心手术）

### 7.1 问题定性（实测）
```
位置闸 0.25 × regime探针 0.25 × swing共识 0.50 × V5 0.25 × MTF 0.60 × brain 上界 0.30
= 0.0014  ⇒  名义 = base × 0.0014 ≈ $2  ⇒  被 SizeFloor 抬到 $60 地板
```
每一层都以为自己在"轻微打折"，乘起来是 **0.14%**。这是**系统性设计错误**，不是参数问题。

### 7.2 目标结构：**一次定价 + 单一上限**
```
① 风险预算：risk_usd   = equity × risk_pct(lane)            # 日内 0.6%，趋势 1.0%
② 止损距离：stop_pct   = max(structure, k×σ)                # 由市场决定，不固定
③ 目标名义：notional   = risk_usd / stop_pct
④ 单一上限：notional   = min(notional, equity × max_weight(symbol, lane))
⑤ 组合上限：Σ margin ≤ equity × 0.60；Σ 同族相关仓 ≤ 3
⑥ 结果：一个数，不再有"乘子链"
```
> 需要的**唯一**新机制：把"多重缩仓"改成"**否决 or 定价**"——
> 任何一层要么否决这笔（写明原因），要么不再改动大小。**禁止乘法链**。

### 7.3 执行质量
| 项 | 设计 |
|---|---|
| 下单方式 | 日内：限价（回踩）；趋势：限价分批 + 市价兜底 |
| 滑点预算 | 下单前估算价差/深度，超预算则改价或放弃 |
| 幂等 | 每笔下单带 `decision_id`，重复下单必须被拒（现在靠策略可见性，脆弱） |
| 可见性 | 新建策略/会话/元数据**必须落库后再执行**（本轮已修一个同类 bug：按需建的策略只 flush 不 commit → 执行侧 fresh session 查不到 → 开仓全丢） |
| 失败可观测 | 每次拒单必须写 `open_blocked` + 具体原因码，且**原因码要有分母**（"为什么没开仓"可查） |

## 11. 学习层（从"记事件"改成"改行为"）

### 11.1 学习目标（按可行动性排序）
| 学什么 | 影响什么 | 现状 |
|---|---|---|
| 币种 × regime × **方向** 的期望 | 选币、开不开、开哪边 | 部分（AI 候选；空头线此前被封锁，后验为 0 样本） |
| setup 类型的胜率/期望 | 进场时机 | 无 |
| 出场参数的边际效果 | 止损/止盈距离 | 无（靠人调） |
| 规模与风险的映射 | 仓位大小 | 无 |

### 11.2 学习方法（可落地、可回滚）
1. **贝叶斯后验**：每个 (lane, **direction**, symbol, regime, setup) 维护 `Beta(α, β)` 胜率后验与盈亏比后验；
   分层先验（全局 → 车道 → 方向 → 币种），样本 < 30 时自动回退到上层先验（防过拟合）；
   **方向对称（v2）**：空头后验与多头后验同构同权——空头样本不足时的正确动作是
   "回退到上层先验 + 继续攒样本"，而不是"关掉空头"；
2. **后验 → 行为**（唯一允许的三条通路）：
   - 选币排序加权（后验期望 × 因子分数）；
   - 仓位乘子 `m ∈ [0.5, 1.5]`（单调、有界，禁止乘子链）；
   - 否决（后验期望 < −成本 × 3 且样本 ≥ 30）；
3. **反事实评估**：任何参数改动前，先在历史成交上做"只改这一项"的重放（已有工具链）；
4. **预登记**：改动必须写下假设、指标、阈值、最小样本，事后按此裁决。

### 11.3 必须拆掉的陷阱：**冻结 ≠ 停止学习**
现状：策略毕业（`golden_frozen`）会把 `learning_enabled=False`，**连"这笔交易的结果"都不再回灌**。
实测：mid 车道 138 笔里 24 笔被该闸挡住（有日志证据），而现役 mid 策略几乎全部处于冻结态。
**设计**：把"参数冻结"与"结果回灌"解耦——
冻结只锁**该策略自身的参数更新**，其平仓结果仍必须进入**因子层/源归因层/全局后验**。

### 11.4 学习闭环的度量
- 覆盖率 = 进入学习的平仓 / 全部平仓 → 目标 **≥ 0.9**（现在 0.41）；
- 影响度 = 因学习而改变的行为次数（选币/仓位/否决）→ 目标 ≥ 每周 20 次；
- 效果 = 学习前后同组交易的期望差（需要 A/B 或反事实），**不允许**用"事件数增加"当效果。

## 12. 回测层（决定"能不能上"的唯一裁判）

| 项 | 设计 |
|---|---|
| 切分 | Walk-forward：训练 60d / 验证 15d / 测试 15d，滚动前进 |
| 防泄漏 | Purge + Embargo（持有期 + 1 天）；因子计算与标签严格按时间点可用性 |
| 成本 | 手续费 7bp 往返 + 资金费 + 滑点（限价 0~2bp / 市价 3~8bp） |
| 过拟合控制 | CSCV/PBO、DSR、试验次数登记（每次参数搜索都记 trial 数） |
| 最低标准 | OOS 夏普 > 0.8、PF > 1.2、最大回撤 < 20%、**扣费后**为正 |
| 反事实 | 对每个"即将上线的改动"重放历史，给出 Δ期望与置信区间 |
| 对比基准 | ① 买入持有 BTC ② 随机入场同止损止盈 ③ 现行参数（基线） |

> 关键纪律：**回测通过 ≠ 上线**，还要过 §13 的模拟盘门槛。

## 13. 模拟交易层（把 paper 当数据工厂）

### 13.1 统计功效反推规模（这是"该开多大"的真正依据）
- 日内车道：假设真实边际期望 `μ = +2%/笔`、单笔标准差 `σ = 3%`，
  要在 95% 置信下判定 `μ > 0`，需要 `n ≈ (1.96σ/μ)² ≈ 8.6` —— 即**几十笔**即可粗判；
  但要把"每 pen 期望"精度压到 ±0.5%，需要 `n ≈ (1.96×3/0.5)² ≈ 138 笔`。
- ⇒ **目标：每条车道每 30 天 ≥ 200 笔**，或等价地把单笔名义调到"能产生可测量差异"的量级。
- **推论（与本轮用户判断一致）**：$60 的单子产生的盈亏（±$1.8）淹没在费用($0.4~0.7)与噪音里，
  **既学不到东西、也测不出改进**；$400 的单子（±$12）才有信噪比。

### 13.2 模拟盘的规模政策（建议值，待批准）
| 车道 | 单笔风险预算 | 单笔名义（权益 4643 时） | 并发上限 | 日新开上限 |
|---|---|---|---|---|
| 日内(mid) 多/空 | 0.6% 权益 ≈ $28 | **$700~900**（止损 3% 时；止损 1.5% 时 $1800） | 6 | 6 |
| 趋势(long) 多/空 | 1.0% 权益 ≈ $46 | **$1000~1500**（止损 6~8% 时） | 6 | 2 |

> 说明：名义由 `风险预算 / 止损距离` 推出，**杠杆不动**；方向**不设差异预算**——
> 空头与多头共用同一条风险预算公式（方向差异只在 regime 准入与入场拒绝条件，不在规模）。
> 空头初期仍受 `MIDLONG_SHORT_SIZE_MULT=0.5`（第2刀）约束，等 down-regime 空头样本
> ≥ 40 笔且后验期望为正再放开到 1.0（§11.2 后验→行为通路）。总保证金占用目标 **40~60%**
> （现在 8.5%），上限由组合闸把守（≤60% 权益）。

### 13.3 模拟盘必须与实盘同构
- 同一套下单/撮合/费用/资金费口径；

## 16. 日内 vs 趋势：一页对照（本设计的核心分歧点）

| 维度 | 日内（中线） | 趋势（长线） |
|---|---|---|
| 收益来源 | 均值回复（OU 回中） | 趋势延续（斜率） |
| 持有期 | 2~24h（中位应 < 6h） | 5~30 天 |
| 止损 | 2.2σ 或结构位（≈1~2%） | Chandelier 3×ATR（6~8%） |
| 止盈 | 到 μ 保本 + 分批（1σ） | 不设固定 TP，跟到斜率翻负 |
| **方向治理（v2）** | 多空对称：超买(μ 上方)做空 / 超卖(μ 下方)做多；regime down 优先空、up 优先多 | 多空对称：slope>0 持多 / slope<0 持空；方向跟趋势，不预设 |

| 规模 | 名义 = 0.6%权益 / 止损%（多空同式） | 名义 = 1.0%权益 / 止损%（多空同式） |
| 因子 | 回复/微观结构/资金费 | 动量/横截面/波动 |
| 学习重点 | 入场时机（MAE_1h）、出场（MFE 实现率） | 选币与持有纪律 |
| 现状 | **−121.53（PF 0.76）** | **+34.56（PF 2.29）** |

## 19. 风险与"绝不"

1. **绝不用乘法链做风控**（每一层都"轻微打折"= 系统性归零）；
2. **绝不让学习静默停止**（冻结策略的结果仍要回灌；空头样本同样必须回灌，不许"亏过就关车道"）；

4. **绝不跳过成本**（费+资金费+滑点）做回测；
5. **绝不在样本不足时下结论**（每组 < 30 笔只报"样本不足"——"做空全负"当年就是这样一次样本偏差结论）；
6. **绝不改参数后不预登记**（预登记 = 假设 + 指标 + 阈值 + 最小样本）；
7. **绝不长期依赖"日志里有"当证据**（日志会随进程消失——本轮已实测）；
8. **绝不单边焊死方向**（v2 新增）："永久禁空"或"只做多"违反用户指令——方向由 regime 决定，
   能在 up 做多就必须能在 down 做空；反过来 up regime 做空 / down regime 做多同样是
   负边际（t=−4.11 / −4.09），regime 纪律双向生效。
