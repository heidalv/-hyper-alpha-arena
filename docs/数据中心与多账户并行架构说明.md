# 数据中心 · 多账户 Agent 并行 · 日志治理

> 更新：2026-08-03  
> 与 [`账户隔离与自备配置说明.md`](账户隔离与自备配置说明.md) 配套。

## 总原则（三层，不要混）

| 层 | 归属 | 一句话 |
|----|------|--------|
| **A. 数据中心** | 全平台**共享** | 整个项目就是行情/K线采集中心；谁要用 K 线、交易所行情，**强制走数据中心** |
| **B. 多 Agent / AI 策略** | **按账户隔离** | 各账户自己的 LLM、策略、运行日、决策；并行时互不堵死 |
| **C. 日志** | 平台统一治理 | 必须轮转 + 定期清理，**禁止无限堆砌撑满硬盘** |

## A. 数据中心（共享 + 预留通道）

> **2026-08 起支持独立进程**：见 [`独立数据中心模块.md`](./独立数据中心模块.md)。  
> `.env` 设 `DATA_CENTER_MODE=standalone` 后，主 API 只读；采集用 `scripts/start-data-center.bat`。

### 唯一读入口
- 代码：`backend/services/data_center.py` → `UnifiedMarketDataCenter`
- 门禁：`data_center_gate.py`（启动检查）
- 采集写入：`kline_realtime_collector.py`（P0 热路径 / P1 全市场 / P2 回填）
- 独立进程：`backend/workers/market_data_center.py`

### 强制规则
1. 业务层（交易、选币、因子、Agent）**禁止**直接 `ccxt.fetch_ohlcv` / 直查 `crypto_klines` 绕过中心。
2. 正确写法：`from backend.services.data_center import data_center` → `get_klines` / `get_price`。
3. 采集与读取分离：只有采集器打交易所 HTTP；业务只读 DB/缓存。

### 预留通道（环境变量）

| 通道 | 变量 | 默认 | 用途 |
|------|------|------|------|
| P0 交易宇宙 | `KLINE_P0_CONCURRENCY` | **16**（原 12，已抬高预留） | 活跃交易品种优先，不被全市场抢走 |
| P1 全市场 | `KLINE_P1_CONCURRENCY` | 4 | catalog 轮转 |
| P1 HL 上限 | `KLINE_P1_HL_CONCURRENCY` | 3 | Hyperliquid 配额保护 |
| 采集线程池 | `KLINE_COLLECTOR_MAX_WORKERS` | 6（上限 16） | 同步写库 |

P0 忙时 P1 会降并发让路——保证「交易用数据」通道优先。

## B. 多账户 Agent（隔离 + 并行通道）

### 隔离内容（每账户自己的）
- LLM Key、交易所 API、挖掘因子、持仓/订单、AI 决策落库、`tenant_id` 运行上下文
- 全自动 session 按 `session_id` / `account_id` 独立调度

### 并行（默认放开）

多账户并行**不**再用人造 LLM 槽卡死（`LLM_BUDGET_ENABLED=false`，全局并发 `0=不限`）。  
各账户自备 Key；能开多少账户只看**本机 CPU/内存**与数据中心采集能力。

| 资源 | 变量 | 说明 |
|------|------|------|
| LLM 分桶限流 | `LLM_BUDGET_ENABLED` | **默认 false（关闭）** |
| 选币并行 | `AUTO_COIN_PARALLEL_SESSIONS=0` | 0=按 session 数全开 |
| 调度线程池 | `SCHEDULER_MAX_WORKERS` 默认 **64** | 多账户 tick |

### 运行日隔离
- 决策/审计写入带 `tenant_id` / `account_id`（DB 与 JSONL）
- 日志清理按天保留，不按「全站一份永远追加」

## C. 日志治理（防撑盘）

### 已有轮转
- `logs/backend.log`：20MB × 10  
- `logs/backend.error.log`：10MB × 10  

### 审计 JSONL（原无上限，已改为轮转）
- 写入走 `backend/utils/jsonl_rotating.py`
- 默认单文件 **20MB**，备份 **5** 份（`AUDIT_JSONL_MAX_BYTES` / `AUDIT_JSONL_BACKUP_COUNT`）
- 覆盖：`prompt_trace`、`training_audit`、`decision_arbiter` 等

### 定期清理任务
- 服务：`backend/services/log_retention_service.py`
- 启动时跑一轮 + 每天定时
- `LOG_RETENTION_DAYS=30`：过期 `*.jsonl.N` / 报告  
- `AI_DECISION_LOG_RETENTION_DAYS=90`：过旧决策表行
