# 主题 D：简一 Zen Mono —— 视觉设计方案

> 适用项目：Hyper-Alpha-Arena（AI 驱动的加密货币量化交易平台）
> 交付物：本文档 + `previews/04-zen-mono.html`（可打开预览）+ `previews/tokens-04.css`（可落地 token）
> 配套主题：本方案为多主题方案中的「D」，与现有 Bloomberg 深色主题共用同一套 shadcn/ui 组件层，token 角色名与现有 `globals.css` 完全一致，可直接替换。

---

## 1. 设计理念

**一句话概念：极简主义的「单色专注台」——把界面减到只剩信息本身。**

炭黑底色承载一切；所有结构靠「亮度分层 + 留白」而不是边框表达；唯一强调色翡翠绿只留给三件事：**关键数字、关键行动、关键状态**；其余全部退入中性灰阶。海量留白不是浪费，而是让交易者的眼睛只被「数字」吸引。

三条设计纪律，贯穿全局：

1. **无边框设计**：卡片不描边，靠背景分层（card `#141518` vs 页面 `#0E0F11`）与留白区分；只有 hover 时浮现 1px 极淡边 `#232529`，暗示"这是可交互的"。
2. **强调色纪律**：翡翠绿 `#10B981` 全界面只出现在 4 处——总盈亏数字（关键指标）、主按钮"前往配置"（唯一行动）、侧边栏激活指示点（当前位置）、ticker 末尾 LIVE 状态点。涨跌仍用绿/红，但降饱和（`#34D399` / `#F87171`），不与强调色争夺注意力。
3. **静**：150ms ease-out 是唯一的运动语言。没有弹跳、没有入场动画、没有骨架屏闪烁——交易终端的动效是噪音，数字才是内容。

气质：**冷静、干净、自信——像 Linear 做交易终端。**

## 2. 情绪板参照

| 参照产品 | 风格描述 | 本主题借鉴点 |
| --- | --- | --- |
| **Linear** | 精密留白、单色分层、几乎无边框、微动效、克制的强调色 | 无边框卡片 + 亮度分层；hover 极淡边；150ms 过渡 |
| **Vercel Dashboard** | 超大标题体系、无边框卡片、等宽数字、紧凑但透气的密度 | 28px 页面主标题 + 灰字副标题；数字 mono + tabular-nums |

**设计要点**：

- 所有灰阶色相统一在 ~264°（近蓝的炭灰），色度 ≤ 0.012——「单色」不是黑，而是有同一色相的炭灰分层；唯一有彩度的只有翡翠绿与降饱和涨跌色。
- `--primary` 在炭黑底上对比 **7.56:1**（AA/AAA 达标），因此翡翠绿可以放心做文字；白字压在翡翠按钮上为 **2.54:1**（详见 §8 无障碍的取舍与对策）。

## 4. 字体与排版

**字体栈**：Manrope（西文与数字标题）+ Noto Sans SC（中文正文）+ JetBrains Mono（**所有数字、价格、百分比、时间、代码**）。

**全局规则**：

- `font-variant-numeric: tabular-nums` 全局开启——数字永不跳动，这是交易终端的基本礼仪；
- 中文永远由 Noto Sans SC 渲染（Manrope 不覆盖 CJK）；西文与数字优先 Manrope / JetBrains Mono；
- 标题字重 650–700；辅助文字一律 12px；等宽数字 11–13px 常用。

**字号阶梯表**：

| 字号 | 字重 | 字体 | 用途 |
| --- | --- | --- | --- |
| 30px | 700 | JetBrains Mono | 统计卡关键数字（总资产 / 总盈亏 / 胜率 / 持仓） |
| 28px | 700 | Manrope | 页面主标题（如"仪表盘"） |
| 20px | 650 | Manrope | 区块大标题（预留） |
| 15px | 650 | Manrope | 卡片标题、表格主文字（币种、策略名） |
| 14px | 650 | Manrope | 空状态标题、按钮文字 |
| 13px | 400/500 | Manrope / Mono | 正文、表格数据、导航项、ticker 价格 |
| 12px | 400 | Manrope | 辅助文字、标签、表头、徽章、副标题 |
| 11px | 500 | JetBrains Mono | 分组小标、⌘K 键帽、状态码、版本号 |

行高：正文 1.6；表格行固定 40px；导航项 32px。

## 6. 组件规范

**侧边栏（Sidebar）**：200px 固定，底 `#0B0C0E`（比页面更暗，形成"炭黑台上浮着纸页"的层次）。5 个分组标题改为 11px 灰色小字（`--muted-foreground`，字距 0.08em）；导航项高 32px、圆角 6px、图标 18px 线性 stroke 1.5、文字 13px。激活项 = 左侧 2px 圆角翡翠条 + 白字 + 右侧 5px 翡翠指示点；hover 底色 `#18191D`。底部放版本号（11px 灰 mono）。

**顶栏（TopBar）**：56px 高、背景与页面同色（无底、无下边框——靠留白分隔）。只保留 5 个元素：搜索框（320×34，底 `#141518` 无边框，⌘K 键帽）、WS 状态（"实时" + 6px 翡翠点）、铃铛（灰色线性图标 + 红色报错角标 6px）、时钟（mono）、头像（28px 圆，底 `#1F2126` 白字首字母）。**移除**：桌面版本号、检查更新按钮、用户等级等噪音。

**ticker 行情条（PriceTicker）**：无背景条，直接铺在页头下方。每一项 = 白字币种（13px/600）+ 灰字价格（mono 13px）+ 涨跌色百分比（mono 12px），`justify-content: space-between` 均匀分布；末尾 `● LIVE` 翡翠点（2.4s 呼吸动画）。价格变化时闪烁 600ms 一次性淡出（涨=翡翠 14% 底、跌=红 14% 底）。

**统计卡**：无边框区块（底 `#141518`、radius 10px、padding 24px、卡间距 20px）。标签 12px 灰；数字 30px 白 700 mono；变化值 12px 带涨跌色。总盈亏数字用翡翠绿（关键指标，强调色纪律第 1 位）。hover 时浮现 1px 极淡边 `#232529`。

**表格**：无纵向网格线；仅表头下 1px 发丝线 + 行间极淡线（`#232529` @45%）；行高 40px；数字 mono 右对齐；hover 行底 `#17181B`、圆角 6px（行内元素局部圆角，不破表格结构）。异常值防御性显示：数值超合理域（如胜率 2518.0%）→ 琥珀色 `#FBBF24` + 「数据异常」小徽章。

**徽章（Badge）**：SELL = `--loss` 10% 底 + `--loss` 文字（11px/600 mono，字距 0.04em，radius 6px，padding 2px 8px）；BUY 同理绿。**无边框、无阴影、无渐变**——底色即背景，克制到极致。

**按钮（Button）**：主按钮 = 翡翠底 `#10B981` + 白字（14px/600），高 34px、radius 8px、padding 0 16px，hover 提亮 6%（`filter: brightness(1.06)`），无阴影。次按钮 = `#1F2126` 底 + 白字，hover 提亮。全站按钮不超过这两种。

**输入（Input）**：无边框，底 `#141518`（与卡片同色，靠内容区留白区分），radius 8px、高 34px；focus 时 2px 翡翠焦点环 `--ring`。placeholder 12px 灰。

**Tab**：下划线式——激活项白字 + 2px 翡翠下划线，未激活灰字；不用背景胶囊（背景胶囊留给 segmented 场景，底 `#1A1C1F`）。

**图表**：SVG 内联，1.5px 细线为主序列（翡翠 `--chart-1`），面积填充 ≤8% 透明度或干脆不填充；网格线用 50% 透明发丝线；坐标文字 11px 灰 mono。无图例边框、无 3D、无渐变堆叠。

**空状态**：居中于卡片内——32px 灰色线性图标 + 一行 14px/650 标题 + 一行 12px 灰说明 + **唯一翡翠按钮**（"前往配置"）。空状态是"行动的邀请"，因此是强调色最合理的落点之一。

## 7. 动效规范

**原则：少即是多。** 交易终端里，任何多余的动效都在消耗注意力——数字变化本身就是内容，动效只是让"变化"被看见。

| 动效 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| hover 背景 / 边框过渡 | 150ms | ease-out | 唯一被允许的持续过渡 |
| 价格闪烁（涨/跌） | 600ms | ease-out | 一次性淡出，不循环 |
| LIVE 点呼吸 | 2.4s | ease-in-out | 唯一允许的无限循环动画（状态信号） |
| 页面 / 卡片入场 | — | — | **禁用**（无入场动画、无骨架屏闪烁） |
| 弹跳 / 弹簧 / 视差 | — | — | **禁用** |

`prefers-reduced-motion: reduce` 时全部动画关闭（价格闪烁与呼吸点静态显示）。

## 8. 无障碍与对比度

实测对比度（WCAG 相对亮度法）：

| 配对 | 比值 | 判定 |
| --- | --- | --- |
| `--foreground` / `--background` | 17.27:1 | AAA ✓ |
| `--muted-foreground` / `--background` | 7.31:1 | AAA ✓ |
| `--muted-foreground` / `--card` | 6.96:1 | AA ✓ |
| `--sidebar-foreground` / `--sidebar` | 12.27:1 | AAA ✓ |
| `--sidebar-foreground` / `--sidebar-accent` | 11.01:1 | AAA ✓ |
| `--primary`（翡翠文字）/ 炭黑底 | 7.56:1 | AAA ✓ |
| `--profit` / 底 | 9.98:1 | AAA ✓ |
| `--loss` / 底 | 6.93:1 | AA ✓ |
| `--warning` / 底 | 11.49:1 | AAA ✓ |
| **白字 / 翡翠按钮底** | **2.54:1** | **✗ 低于 AA（4.5:1）** |

**已知取舍与对策**：`#10B981` 提亮后白字对比不足是翡翠族的通病。对策（按优先级）：

1. 按钮文字放大加粗（15px/700）并保持 34px 高度，作为大号 UI 元素按 3:1 的"大文本"标准接近达标；目前"前往配置"按钮即按此处理；
2. 若需严格 AA：按钮底用 `color-mix(in oklch, var(--primary) 78%, #000 22%)` 微降明度（视觉上仍是同一翡翠），或直接使用 `#047857`（5.46:1）；
3. 翡翠作为**文字/指示**使用（总盈亏、LIVE 点、焦点环）无任何问题，7.56:1 为 AAA。

其他保障：焦点可见性——`:focus-visible` 2px 翡翠环；可点击目标 ≥ 32px（导航 32 / 按钮 34 / 表格行 40）；辅助文字一律 ≥ 12px 且灰字对比 ≥ 6.9:1，小字号也安全；键盘可遍历全部导航（tab 顺序 = 视觉顺序）；红绿色盲可辨识——涨跌不只用颜色，价格方向保留 ▲/▼ 符号。

## 10. 风险与取舍

**核心取舍：信息密度下降约 30–40%。** 40px 行高、24px 卡片内边距、大留白，在"展示型"页面是气质，在"监控型"页面就是效率损失。

**适合本主题的页面**：`/dashboard`（仪表盘）、`/strategy`（AI 策略）、`/risk`（风控监控）、`/paper-trading`、`/live-trading`、`/settings`——这些页面以"读数字、做决策"为主，密度换清晰是净收益。

**不适合默认密度的页面**（需保留紧凑模式）：
- `/ops` 运维看板（`OpsHeartbeatMatrix`、`OpsFunnel` 等网格面板）——矩阵式健康状态需要 32px 行高 + 更小 padding，否则一屏装不下；
- `/compute` 算力中心（GPU 卡矩阵、任务进度流）——高密度时序面板同样不适配 40px 行高；
- `/agent-monitor` Agent 监控——实时日志流需要紧凑行距。

对策：为高密度页提供 `dense` 变体（行高 32、卡片 padding 16、表格 hover 保留），只套色板不套留白。

**其他风险**：

1. **强调色纪律需要产品共识**：新增任何"成功提示"一律用 `--profit` 而非 `--primary`，防止翡翠色贬值成"通用绿色"。这是最容易破的规矩。
2. **无边框分层依赖纯深色底**：若未来引入浅色模式，灰阶亮度差需要重新推导（本主题当前只做深色，与交易终端定位一致）。
3. **白字/翡翠按钮 2.54:1**：见 §8，已给出 color-mix 加深预案；若审计严格，直接落 `#047857`。
4. **数据异常只能减缓不能根治**：胜率 2518.0% 是数据质量问题，防御性显示（琥珀 + 徽章）只是让它"体面"，仍应反馈数据侧修复。
5. **行高 40px 在长列表中的滚动成本**：交易记录、决策历史等超长表建议提供 dense 开关，默认仍 40px。
