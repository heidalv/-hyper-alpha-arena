# 曙光研究院 Dawn Research — 浅色主题设计方案（主题 C）

> 项目：Hyper-Alpha-Arena（AI 驱动的加密货币量化交易平台）
> 配套文件：`previews/03-dawn-research.html`（可双击打开的自包含预览）、`previews/tokens-03.css`（可直接落地的 token 块）
> 适用范围：frontend-next（Next.js 16 + React 19 + Tailwind v4 + shadcn/ui），Electron 桌面端同一套 token 复用
> 状态：设计稿（新增文件，未改动任何现有代码）

## 1. 设计理念

**一句话概念：机构级量化研究台（浅色）——纸白的研究桌面上，靛蓝主色 + 语义色让数据一目了然。**

当前产品是纯深色 Bloomberg 终端风，信息密度高、沉浸感强，但长时间阅读与对外输出（研报、截图、PDF 导出）场景下存在明显短板。曙光研究院把「纸」作为第一隐喻：像金融分析师的白纸桌面一样，让**内容**（数字、表格、图表）自己说话，而不是被深色背景吞掉。

三个设计支柱：

- **纸白 × 靛蓝**：`#F5F6F8` 纸白底 + `#3456D9` 靛蓝主色。靛蓝在金融语境中是「信赖感」的标准色（彭博、Fidelity、Morningstar 均大量使用），与墨色文字 `#182230` 形成「纸上印刷」的对比，天然具备可打印、可导出研报的气质。
- **语义色即信息**：涨绿 `#059669` / 跌红 `#DC2626` / 警示琥珀 `#D97706` 只出现在「变动值」上，其余一律中性灰蓝。数据密集页面里，颜色永远是第二读层——先形状后颜色。
- **克制即机构感**：1px 细边框 + 极轻投影（`0 1px 2px rgba(16,24,40,0.05)`）+ 150ms 动效。没有渐变、没有玻璃拟态、没有装饰性插画，一切服务于「读得清、对得上、导得出」。

这套浅色主题不是替代深色，而是**第二种皮肤**：证明本项目完全能出浅色模式，也为风险、情报、研报导出等场景提供更优的阅读环境。

**使用纪律：**

- 涨跌色只出现在「变动值」（ticker、涨跌列、盈亏列、delta），静态数字一律墨色。
- 表格表头 `#F8F9FB`、斑马纹 `#FAFBFC`、hover 行 `#F5F7FB` 为扩展值（已注释在 tokens 文件内，可选）。
- 阴影极轻：卡片 `0 1px 2px rgba(16,24,40,0.05)`，hover `0 4px 12px rgba(16,24,40,0.08)`。

## 4. 字体与排版

**字体族：** 中文 `Noto Sans SC`（数字内嵌），西文 `Inter`，数字 `JetBrains Mono`（等宽）。价格、百分比、表格数字一律 `font-variant-numeric: tabular-nums` 并启用等宽族——数字不跳动是量化平台的底线体验。

**字号阶梯（12px 基准体系，浅色比深色略大一号）：**

| 阶梯 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| 微标 | 10px / 0.625rem | 1.4 | 600 | 英文副标（`STRATEGY PERFORMANCE`）、极小角标 |
| 小标 | 11px / 0.6875rem | 1.4 | 500-600 | 卡片左上标签、表头（大写 + 0.06em 字距）、面包屑、徽章 |
| 辅助 | 12px / 0.75rem | 1.5 | 400 | 次要正文、表格说明、AI 决策描述、空状态说明 |
| 紧凑 | 13px / 0.8125rem | 1.5 | 400-500 | 表格单元格、导航项、ticker 价格 |
| 正文 | 14px / 0.875rem | 1.5-1.6 | 400 | 页面基准正文、卡片标题 |
| 强调 | 16px / 1rem | 1.4 | 600 | 面板标题、对话框标题 |
| 页头 | 17px / 1.0625rem | 1.3 | 600 | 页头条带页面名（白字） |
| 统计数字 | 28px / 1.75rem | 1.15 | 600 | 统计卡主数字（墨色、等宽） |

**排版纪律：**

- 行高：中文正文 ≥1.5；表内 34px 行高 + 垂直居中，杜绝拥挤。
- 表格数字右对齐 + 等宽；表头 11px 大写 + `letter-spacing 0.06em` 灰字。
- 字距：ticker 紧凑（`letter-spacing 0.01em`）；英文副标宽字距（0.12-0.16em）制造「研究机构」感。
- 留白：卡片 padding 20px、列间距 16px、区块间距 16px——「可导出研报」的底气来自留白。

## 6. 组件规范

**侧边栏**：浅灰底 `#EEF0F4`；品牌区 64px，32px 墨色圆角方块内放白色「α」字标 + 「曙光研究院 / DAWN RESEARCH」；分组标题 11px 大写灰字；导航项高 32px、13px 墨灰蓝，hover 白 65% 底。激活态 = 白色卡片浮起（轻投影）+ 左侧 3px 靛蓝色条 + 靛蓝文字 600 字重，比深色主题的「选中」更清晰。右侧 hover 时浮现路由小字（`/dashboard`）。折叠 64px 时仅保留图标。

**顶栏**：52px 白底墨字、底部 1px 边框。左侧 320px 搜索框（白底灰边，聚焦 3px 靛蓝 ring + 边框转主色，`Ctrl K` kbd 角标）；右侧依次：WS 状态（绿点 + 绿色「实时」、灰字「轮询中」）、分隔线、版本号（等宽）、「检查更新」白底灰边次要按钮、铃铛（红色报错角标 `3`）、分隔线、时钟（等宽 tabular-nums）、用户（靛蓝首字母头像 + 昵称 + 浅灰等级胶囊「Lv.6」）+ 退出图标。

**ticker 行情条**：白底卡片、1px 边框、38px 高；每项 = 符号（12px 700）+ 价格（13px 等宽）+ 涨跌（12px，小三角 + 百分比）；项间 1px 细分隔线；字距紧凑。末尾「● LIVE」绿色胶囊徽标。涨绿跌红，变化时可用现有 `flash-profit / flash-loss` 动画（把 oklch 背景色换成浅色 10% 透明版）。

**统计卡**：白卡 + 1px 边框 + 极轻投影，padding 16-18px；左上 11px 灰小标签（中英双语）；主数字 28px 墨色 600 等宽；副行 11.5px 灰（delta 变动值用涨跌色）；右侧 72×36 迷你柱状图 SVG（主色靛蓝，8 根圆角柱、透明度渐变）。hover：投影加深 + 上浮 1px。

**表格**：白底、表头 `#F8F9FB` + 11px 大写灰字（0.06em 字距）、行高 34px、单元格 13px；斑马纹 `#FAFBFC`（可选）；数字右对齐等宽；**异常值处理**：红色文字 + 「数据异常」琥珀徽章（防御性显示，如胜率 2518.0% 这种脏数据，宁可用徽章明示也不裸显）；hover 行 `#F5F7FB`，150ms。状态列用徽章（运行中绿 / 已停止灰）。

**徽章**：胶囊形（radius 999、高 20px、10.5px 600 字重）。SELL 红 10% 底 + 红字 + 红 25% 边框；BUY 绿同构；「数据异常」琥珀；「运行中」绿、「已停止」灰；等级徽章浅灰底墨字。小号、高对比、语义一眼可辨。

**按钮**：主按钮 32px 靛蓝实底白字、hover `#2B46B8` 加深 + 投影，active 回弹；次要按钮白底灰边、hover 浅灰底；页头「导出研报」为深色带上的白底墨字实体按钮。统一 150ms ease-out。

**输入**：白底、1px `--input` 灰边、8px 圆角；hover 边加深；聚焦 = 边框转靛蓝 + 3px 半透明 ring（`--ring`）。placeholder 用 `--muted-foreground`。

**Tab**：下划线式（浅色下不用深色主题的填充胶囊）——未选中 13px 灰字 + 2px 透明下边线，选中靛蓝字 + 靛蓝 2px 下边线，hover 浅灰。适合长列表切换（如策略/因子 Tab）。

**图表**：白底、细灰网格线（1px `#E3E7EE`）、坐标轴 9.5-11px 等宽灰字；主序列靛蓝 2px 实线 + 主色 10% → 0 渐变面积填充；基准线灰虚线；末端数据点靛蓝圆点 + 白描边。图例 11.5px 灰。预留「导出 PNG」等研报工具按钮位。

**空状态**：虚线框（1.5px `#C9D2E2`）+ 浅靛蓝圆角方底（44px `--accent` 底 + 靛蓝图标）+ 标题 + 12px 说明 + 靛蓝主按钮引导（如「前往配置」）。不是留白，是引导下一步的路径。

## 7. 动效规范

| 项 | 值 |
|---|---|
| 时长 | 150ms，全部 `ease-out`（克制） |
| 卡片 hover | 上浮 1px + 投影加深（`0 4px 12px rgba(16,24,40,0.08)`） |
| 行 hover | 背景 150ms 渐入 `#F5F7FB` |
| 按钮 | hover 加深 / active 回弹（translateY(0)） |
| 聚焦 | 3px ring 渐现（`--ring`） |
| 价格变化 | 复用现有 `flash-profit / flash-loss`（改为浅色 10% 透明底色，400ms） |
| 不做 | 不做入场动画堆砌、不做缩放弹跳、不做玻璃模糊 |

原则：动效只负责「告诉你哪个可点、哪个变了」，不负责「好看」。

## 8. 无障碍与对比度（WCAG AA）

浅色模式天然具备对比度优势——深色主题里 `--muted-foreground` 类弱文字在浅底上更容易达标：

| 前景 / 背景 | 对比度 | AA 结果 |
|---|---|---|
| `#182230` / `#FFFFFF`（主文字/白卡） | ≈16.0:1 | ✅ 远超 AA |
| `#5E6B82` / `#FFFFFF`（次要文字） | ≈5.4:1 | ✅ AA |
| `#3456D9` / `#FFFFFF`（靛蓝主色/白底） | ≈6.0:1 | ✅ AA（白字压靛蓝同值） |
| `#3A4558` / `#EEF0F4`（侧栏文字） | ≈8.5:1 | ✅ AA |
| `#DC2626` / `#FFFFFF`（跌红） | ≈4.8:1 | ✅ AA |
| `#059669` / `#FFFFFF`（涨绿） | ≈3.8:1 | ⚠️ 大字/加粗数字达标；**小字改用 `#047857`** |
| `#D97706` / `#FFFFFF`（琥珀） | ≈3.2:1 | ⚠️ 徽章文字改用 `#B45309`（≈5.0:1） |

**规则落地：** 涨跌色用于 13px+ 加粗数字/徽章时用 `--profit/--loss`；用于 11-12px 小字时建议 `--profit-strong: #047857`、`--warning-strong: #B45309`（浅色主题可增加这两个扩展 token）。语义色不得作为唯一信息通道：涨跌同时配小三角图标，异常值同时配徽章文字。焦点可见：所有可交互元素 focus 出 3px `--ring` 环；中文正文行高 ≥1.5 利于长文阅读。

## 9. 落地实施

### 9.1 globals.css 替换步骤（约 10 分钟，零组件改动）

1. 打开 `frontend-next/src/app/globals.css`，将 `:root, .dark { ... }` 块整体替换为 `previews/tokens-03.css` 的 `:root { ... }` 内容（角色名完全一致，`@theme inline` 映射无需改动）。
2. 删除 `html { color-scheme: dark; }`，改为 `color-scheme: light;`（浅色时系统原生控件随主题）。保留 `font-variant-numeric: tabular-nums` 与 `-webkit-font-smoothing: antialiased`。
3. 滚动条 thumb 从 `oklch(0.30...)` 深色值改为浅灰（如 `#D4D9E3` / hover `#BFC7D5`）；`flash-profit / flash-loss` 动画背景改为 `rgba(5,150,105,0.15)` / `rgba(220,38,38,0.15)`。
4. 若保留深色主题：把两套值分别放进 `:root`（浅色）与 `.dark`（深色），页面根节点切换 class 即可实现双主题（推荐路线：先固定浅色验收，再做 `.dark` 分支）。

### 9.3 先切浅色的页面（推荐顺序）

1. **`/risk` 风控监控** — 风险面板以阅读与核对为主，纸白底 + 红/琥珀语义色在浅色下警示更强，适合首个验证。
2. **`/intel` 全市场数据中台** — 长时间扫读数据，浅色抗疲劳优势最大。
3. **`/charts`（净值/回撤图表区）** — 图表白底 + 靛蓝主线是浅色主题的招牌，视觉收益最高。
4. **`/settings` 设置** — 低密度表单页，风险最小，可最先合并进双主题切换。

建议同时维护「按路由支持双主题」：深色页保留终端沉浸感（监控/交易执行），浅色页提供研究阅读体验（风控/情报/图表/设置）。

## 10. 风险与取舍

| 风险 | 分析 | 缓解 |
|---|---|---|
| **光敏 / 长时间盯盘疲劳** | 纯白背景亮度高，连续数小时盯盘（尤其夜晚）反光刺眼 | ① 背景用 `#F5F6F8` 而非纯白，全页面无 100% 纯白大区域；② 卡片白底 + 浅灰页面底的两级层次减少眩光；③ 与深色模式并存，按页面/时段切换；④ 统计数字 28px 墨色而非纯黑 `#000`，对比 16:1 已达标且不刺眼 |
| **涨绿跌红的文化歧义** | 中国市场习惯红涨绿跌 | 本项目沿用全球惯例（绿涨红跌），与现有深色主题一致；若需国内发行版，仅需交换 `--profit/--loss` 两个 token |
| **浅色下「脏数据」更显眼** | 异常值（如胜率 2518.0%）在浅色下突兀 | 正是防御性显示的目标：红色 + 「数据异常」徽章明示，不做静默处理；同时反推后端校验胜率上限 100% |
| **动效过度风险** | 浅色高亮下动效易廉价 | 统一 150ms ease-out + 上浮 ≤1px + 不做入场堆叠，动效只响应 hover/focus |
| **等宽字体覆盖不全** | JetBrains Mono 不含中文 | 数字/符号走等宽族，中文走 Noto Sans SC，混排由字体栈自动回退，无需额外处理 |
| **双主题维护成本** | 新增浅色后 token 分叉 | 严格只改 `:root` / `.dark` 两个变量块；设计评审以「同一角色同一语义」为验收线，禁止在组件里写死色值 |
