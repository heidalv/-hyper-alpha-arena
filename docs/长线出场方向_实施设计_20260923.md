## 设计 1：影子模式（D1b / D2b 只记录不拦截）

### 1.1 目标参数（被影子观察的变体，来自 §6 双源一致的 E1 正收益组）

- **V1 = D1b**：部分止盈 50%@+5%、25%@+8%，余仓追踪 3.0/1.5；
- **V2 = D2b**：全仓追踪 3.0/1.5（无部分止盈）。
（对照基线 = 现行：仅 Chandelier 每日上移，无追踪/无部分止盈。）

### 1.2 挂点（只读记录，不改任何交易决策）

| 挂点 | 位置 | 记录内容 |
|---|---|---|
| 持仓 30s 慢 tick | `paper_trading_engine.py` `_run_v2_protection`（≈3947 peak 采样处） | 对 tier=long 仓：当根 mark、峰值、V1/V2 规则当前"虚拟止盈线/虚拟追踪线/虚拟减仓份额" |
| 每 tick 判定 | 同上 | V1/V2 是否"虚拟触发"（触发时间、触发价、触发类型）——**与实际平仓逻辑并行执行，结果只写日志** |
| 实际平仓时 | `close_position`（≈2445 起） | 对照行：实际 reason/价格 vs V1/V2 虚拟触发状态；若 V1/V2 更早触发，记"早 N 分钟 / 价格差 pp / 省(亏)多少" |
| E1 日任务 | `trend_e1_engine.py:369-381` Chandelier 上移处 | 当日每仓 Chandelier 值快照（供复算"若用 V2 追踪会差多少"） |

落盘：`data/long_exit_shadow.jsonl`（追加，每行：`ts, position_id, tier, symbol, side, entry, mark, peak_pct, v1_state, v2_state, actual_event`），
复用现有审计 jsonl 惯例（参考 `data/midlong_direction_audit.jsonl`）。开关 `LONG_EXIT_SHADOW=false`（默认关）。

### 1.3 晋升验收标准（写死，防止事后拍脑袋）

累计 **≥30 笔 tier=long 实际平仓**、其中 **≥10 笔的入场时 4h ADX<25 或 BTC 日线在 SMA50 下方**（=震荡/下行 regime 桶），
且满足全部三条才谈"把 V1/V2 变体转为真实参数"：
1. 双价源复算的 Δ 方向一致；
2. **两个 regime 桶（趋势桶 + 震荡桶）的 Δ 都非负**；
3. 最差单笔不显著恶化。
未达标 = 永远只记录。

## 设计 2：D5 挂单出场（maker 路由，纸面层）

### 2.1 原则（论文 C6 + §1.4 实测）

- 可等待的出场 → **maker（post-only 限价）**：入场（trend_e1 日任务本就是"次日价"限价风格）、
  部分止盈档、时间上限出场、rebalance/rule_exit；
- 风险出口 → **永远 taker**：Chandelier/SL 触发、LLM 平仓（trend_broken/weaken/thesis_*）、爆仓/强平。

### 2.2 改动点（全部在纸面模拟层，不动任何交易决策阈值）

| 位置 | 改动 | 说明 |
|---|---|---|
| `paper_exchange_simulator.py` 费率表 | 复用现有 `maker_fee_rate/taker_fee_rate`（asterdex 0%/0.04% 已配置） | 无需改费率 |
| `paper_trading_engine.py:2803-2805`（`_partial_close` 费率处）与 `close_position` 的 `_simulate_reduce_fill` 费率处 | 增加 `is_maker` 判定：`reason ∈ MAKER_ELIGIBLE_EXITS` 时按 maker 取费 | `MAKER_ELIGIBLE_EXITS = {tp, staged_tp*, partial_*, time_limit, rebalance, rule_exit, dust_cleanup, symbol_removed}`；SL/LLM/爆仓类一律 taker |
| 开关 | `.env` `PAPER_MAKER_EXITS=false`（默认关）；`PAPER_MAKER_ENTRY_TIMEOUT_MIN=3`（入场挂单 3 分钟未成交转 taker——入口用 `_partial_close` 同款判定的镜像逻辑） | 回滚 = 改一个值 + 重启 |

### 2.3 验收

1. `paper_orders.fee`：出场为 maker 的单 fee=0（asterdex）、taker 单保持 4bp；风险出口全部仍是 taker；
2. 与 §1.4 底座对齐：长线全量出场费从 $39.44 降至 ≈ 与 maker 占比成比例（预期节省 ≤ $17.5/90 天）；
3. 平仓时点/价格**不得改变**（仅费率口径变）——用 §6 脚本基线对拍（Δ 应只差费用）。
