## 二、修复内容

1. **新增 `factor_engine/code_safety.py`**：AST 白名单校验——禁 import/ImportFrom、禁 dunder 属性与命名、属性链根只允许 {np,pd,df,data,self,result,series,close,high,low,volume,open,values,index}、全局函数调用只允许安全内建白名单。与黑名单构成两道防线。
2. **P1-F1（云端同步注入面）**：`_localize_factor` 所有元数据改用 `json.dumps` 生成字符串字面量（docstring 用剥外层引号版——修复"值以引号结尾时与三重引号终止符粘连"导致的 unterminated string literal）；factor_id 拒绝 `/`、`\`、`..`；`_register_localized_factor` 模块名清洗。
3. **P1-E5（绕过闸门）**：本地化产物写入 `factors/_cloud_pending/`（下划线前缀 → FactorLoader 跳过）；状态=candidate；**不再注册进 live Registry、不再置 active**；新增 `promote_cloud_factor(confirm=True)` 显式晋升（移 external/ → 注册 → 检查返回值 → active，任何一步失败保持 candidate）；`FACTOR_CLOUD_SYNC_ENABLED` 总开关默认关闭。
4. **P1-F2（AI 生成因子）**：`validate_generated_factor` 增加 AST 白名单 + factor_id 路径穿越拒绝（旧黑名单可被 `import os`/`os.popen`/`getattr` 绕过）；`inject_factor` 文件名清洗兜底。
