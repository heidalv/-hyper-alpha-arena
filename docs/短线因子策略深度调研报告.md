## 1. 执行摘要

### 结论速览

| 维度 | 现状 | 评估 |
|------|------|------|
| **7天净盈亏** | **-21.29 USDT**（125笔） | 🔴 亏损 |
| **胜率** | 41.6% | 🟡 接近行业中等 |
| **盈亏比** | 0.36（赚$0.18 vs 亏$0.50） | 🔴 严重失衡 |
| **手续费占比** | 1.3%（0.27/21.29） | 🟢 非主因 |
| **TP/SL 配置** | TP 3.6% / SL 3.6%（≈1:1） | 🔴 远离最优点 |
| **因子有效性校准** | 冷启动线性映射，样本不足 | 🔴 无参考价值 |
| **主动平仓** | ai_reverse/liq_magnet 亏损放大 | 🔴 需重构 |

### 三句话总结

1. **当前短线策略不赚钱的核心原因不是手续费（仅占1.3%），而是 TP/SL 比率配置错误**——止盈距离和止损距离几乎相等（1:1），导致需要 50%+ 胜率才能盈利，但实际胜率只有 41.6%。
2. **实测数据明确指向最优区间**：TP=1-2% 的窄止盈胜率达 73% 且唯一盈利；而 TP≥4% 的远止盈胜率骤降至 33%、亏损占总亏损 78%。
3. **"每日2%"在数学上不可持续**（年化 137,000%），但**每日 0.3-1% 的净收益在改进后是可期的**——前提是把 TP/SL 从 1:1 改为 1.5:1 配合窄止盈（1-2%），并修复 AI 反向平仓的亏损放大器。

## 2. 当前策略全链路分析

### 2.1 因子选择

**参与短线决策的因子**（排除 PATTERN/BEHAVIORAL 后的 21 个硬编码因子）：

| 类别 | 因子 | 方向映射公式 | 备注 |
|------|------|-------------|------|
| **MOMENTUM** | RSI | `(50-value)/50` | 超卖看多 |
| | MACD | `sign(value)×min(1,\|value\|×10)` | 动量方向 |
| | momentum | `value/5.0` | 价格动量 |
| | ROC | `value/5.0` | 变化率 |
| | ADX | `0.0`（无方向） | 仅强度 |
| **MEAN_REVERSION** | bb_width | `-value/4.0` | 布林带宽度 |
| | zscore | `-value/4.0` | 标准分 |
| | atr_ratio | `0.0`（无方向） | 波动率 |
| **VOLATILITY** | ATR/HV/Parkinson | `0.0`（无方向） | 仅强度 |
| **VOLUME** | OBV | `value/5.0` | 能量潮 |
| | VWAP | 直接 value | 成交量加权 |
| | volume_zscore | `0.0` | |
| | cvd_ratio | 直接 value | 累积量差 |
| **TREND** | sma_cross | 直接 value | 均线交叉 |
| | ema_trend | 直接 value | EMA趋势 |
| | supertrend | 直接 value | 超级趋势 |
| **MARKET_FLOW** | taker_ratio | 直接 value | 主动买卖比 |
| | oi_delta | 直接 value | OI变化 |
| | funding_rate | `-value×100` | 反向 |

> ⚠️ **问题**: MARKET_FLOW 类因子（CVD/OI/Taker/Funding）声明了 `required_keys`，当 market_data 缺少对应键时 `has_data=False`，权重被设为 0、不参与决策。实测中 `inject_orderflow_for_factors` 经常注入失败（DB 连接竞争）→ **4 个高价值订单流因子形同虚设**。

### 2.2 方向合成公式

```
composite_direction = Σ(direction_i × weight_i × |direction_i|) / Σ(weight_i × |direction_i|)
                     ↑ 取 top-15 强因子，同类权重上限 40%
composite_strength  = Σ(strength_i × weight_i × |direction_i|) / Σ(weight_i × |direction_i|)
confidence          = 1 - std(directions)   ← 因子一致性
```

**factor_score = |composite_direction| × 100**（0-100 分制）

### 2.3 信号触发

| 阈值 | 值 | 行为 |
|------|-----|------|
| < 25 | 探索区下限 | hold |
| 25-35 | CONFIRM 阈值 | 需 LLM 确认（或自适应阈值） |
| 35-45 | 探索区 | 条件放行 |
| ≥ 45 | EXECUTE 阈值 | 直通放行 |

**自适应门槛**: 近3天该币 scalp 胜率 <30% → 门槛提到 50；>60% → 降到 30。

### 2.4 TP/SL 计算（当前实现）

```
atr_pct = max(0.008, min(0.035, volatility × 1.5))    # 0.8% ~ 3.5%
SL = max(1.0%, min(4.0%, atr_pct))                     # [2026-07-10改: 1%-4%]
if SL ≤ 3.2%: TP = min(8%, SL × 2.5)                   # 窄SL→2.5:1
else:         TP = min(10%, SL × 2.0)                   # 宽SL→2:1
```

> ⚠️ **问题**: 虽然公式写的 2:1~2.5:1，但实测数据（第3章）显示平均 TP=3.6% / SL=3.6%（≈1:1），原因是**加仓后均价恶化 + 减仓后剩余仓位按不同价格平**导致最终盈亏比远低于设计值。

## 4. 行业调研：虚拟币短线策略最佳实践

### 4.1 每日 2% 的现实性

| 来源 | 结论 |
|------|------|
| [r/Daytrading](https://www.reddit.com/r/Daytrading/comments/wp3gsx/you_can_make_2_a_day/) | 2% 在好日子可行，但无法持续 |
| [ForTraders](https://www.fortraders.com/blog/is-crypto-day-trading-worth-it) | 90% 的人亏钱，80% 两年内退出 |
| 复利数学 | 2%/天 = 年化 137,000%（不现实） |

**结论**: 每日 2% 作为持续目标是不可行的。但**改进后每日 0.3-1% 的净收益是可期的**——对应月化 10-30%，这在量化交易中已经是优秀水平。

### 4.2 短线胜率基准

| 来源 | 胜率范围 |
|------|---------|
| 专业 scalper | 55-65% |
| 高频策略 | 70-80%+（需 HFT 基础设施） |
| 本项目 | **41.6%** |
| 行业中位 | 50-55% |

> 本项目胜率低于行业中位 10 个百分点，有改进空间但不离谱。

### 4.3 GitHub 开源项目参考

| 项目 | 特点 | 可借鉴 |
|------|------|--------|
| [Freqtrade](https://github.com/freqtrade/freqtrade) | 最成熟的 Python 加密交易框架 | ROI table 分时间段递减、trailing stop、hyperopt 超参优化 |
| [OctoBot](https://github.com/drakkar-software/octobot) | AI+DCA+Grid | 多策略混合 |
| [jita3](https://github.com/molbal/jita3) | MACD+RSI 简单 scalping | 指标组合验证 |

**Freqtrade 的关键设计**:
- **ROI table**: `"0: 0.02, 30: 0.01, 60: 0.005"` —— 刚开仓时目标高，随时间递减，强制短线快速止盈
- **Trailing stop**: 盈利后自动收紧止损，锁定利润
- **Hyperopt**: 用历史数据自动优化参数，而非拍脑袋

### 4.4 CVD/订单流信号

[Bookmap CVD 策略](https://bookmap.com/blog/how-cumulative-volume-delta-transform-your-trading-strategy):
- **看涨背离**: 价格创新低但 CVD 创更高低点 → 有大单在吸筹
- **看跌背离**: 价格创新高但 CVD 创更低高点 → 有大单在出货

> 本项目有 CVD 因子但经常因 DB 连接问题注入失败，需要确保订单流数据稳定。

### 4.5 止损猎杀（Stop Hunting）防护

加密货币交易所的插针/扫止损是短线策略的头号杀手（[Binance Square](https://www.binance.com/en/square/post/19868879969745)、[CertiK](https://www.certik.com/blog/unmasking-crypto-market-manipulation-wash-trading-spoofing-and-more)）：

**防护建议**:
1. 避免在明显的支撑/阻力位（整数关口）放置硬止损
2. 止损距离至少 1.5×ATR，避免被常规波动扫掉
3. 用清算集群数据检测止损密集区，主动避让
4. 10x 杠杆下 1% 的止损 = 10% 保证金亏损——容易被连环爆

## 5. TP/SL 参数专项研究

### 5.1 学术研究

[MDPI 论文（2018）](https://www.mdpi.com/1911-8074/11/3/56)系统性测试了 6 种 TP/SL 策略在 MACD 交易系统中的表现：

**核心发现**:
- 固定 TP/SL 比率中，**1:1.5 到 1:2 表现最稳定**
- 过高的 RR（1:3+）看似诱人，但胜率骤降导致总期望为负
- **ATR 自适应止损优于固定百分比**——能适应不同波动环境

[arXiv 2024 论文](https://arxiv.org/html/2604.27150v1)推荐默认值: 10% SL + 3% trailing activation + 5% trailing（适用于持仓型，短线需缩小）。

### 5.2 本项目数据指向的最优参数

基于第3章实测数据，**最优配置**:

| 参数 | 当前 | 实测最优 | 依据 |
|------|------|---------|------|
| **TP 距离** | 3.6%（平均） | **1.5-2.0%** | 1-2% 桶胜率 73%、唯一盈利 |
| **SL 距离** | 3.6%（平均） | **1.5-2.0%**（窄）或 **4%+**（宽） | 2-4% 是死亡区间 |
| **RR 比率** | ≈1:1 | **1.2:1 ~ 1.5:1** | RR=1.2-2 桶亏损最小 |
| **持仓上限** | 无（实测 15.8h） | **2 小时** | scalp 应快速退出 |

### 5.3 为什么 RR=2-3 灾难性失败

本项目数据中 RR=2-3 的 17 笔单胜率仅 6%，这看似违反理论。原因：

1. **止损设在 2-4% 的"死亡区间"**——正好是插针高频扫损区
2. **止盈设在 4-6%**——在当前低波动环境（BTC 日振幅 2-3%）很难达到
3. **结果**: 止损被扫 → 止盈永远等不到 → 胜率崩塌

**修正方向**: 不是 RR 有问题，是 SL 的绝对位置有问题。把 SL 从 2-4% 改到 <1.5% 或 >4%，配合 TP 1.5-2%。

### 6.2 AI 反向平仓（ai_reverse）问题

`ai_reverse` 是 AI 实时复审认为方向错了、主动反向平仓。但实测胜率仅 10%，10 笔亏了 4.34——**AI 的反向判断比原始信号更差**。

**根因分析**:
- AI 复审用的是 `trend_agent.review_position`，LLM 在短线场景的判断延迟高（分析耗时 30-90 秒）、数据不完整
- 反向平仓时机往往是价格已经大幅不利移动后（事后诸葛亮）
- 短线持仓时间短，AI 来不及做出准确判断

**建议**: 禁用短线持仓中的 AI 反向平仓。让 TP/SL 和简单的超时规则管理退出。

### 6.3 插针反转（liq_magnet_reversal）问题

`liq_magnet_reversal` 检测到清算磁吸信号时主动反转持仓。18 笔胜率 17%，亏 -2.69。

**根因**:
- 清算磁吸信号本身就是高噪音的——插针后价格往往继续原方向而非反转
- 反向开仓时机差（在极端波动中追单）
- 这个功能的设计假设"插针=反转"，但实际"插针=继续趋势"的概率更高

**建议**: 将 liq_magnet_reversal 从"反转开仓"改为"只平仓不开新仓"——用磁吸信号保护性地退出，而不是反向追击。

### 6.4 动态止盈止损的 ATR 配置

当前: `atr_pct = max(0.008, min(0.035, volatility × 1.5))`，即 0.8%-3.5%。

**实测表明**:
- SL=2-4% 是死亡区间（胜率 18%）
- SL<1.5% 胜率 50%
- SL>4% 胜率 69%

**建议调整**: ATR 倍数从 1.5 降到 1.0（让 SL 更紧），并跳过 2-4% 区间:
```
atr_pct = max(0.006, min(0.015, volatility × 1.0))  # 0.6%-1.5% 窄止损
# 或
atr_pct = max(0.040, min(0.060, volatility × 2.5))  # 4%-6% 宽止损（适合趋势）
```

| 1 | **TP 设太远（≥4% 占 78% 亏损）** | 🔴 致命 | 低（改配置） |
| 2 | **ai_reverse 亏损放大器** | 🔴 高 | 低（禁用） |
| 3 | **liq_magnet_reversal 反转开仓** | 🔴 高 | 低（改为只平仓） |
| 4 | **SL 2-4% 死亡区间** | 🔴 高 | 中（改 ATR 逻辑） |
| 5 | **持仓时间过长（平均 2.5h）** | 🟡 中 | 中（加时间衰减 TP） |
| 6 | **订单流因子注入不稳定** | 🟡 中 | 中（DB 优化） |
| 7 | **CHIP 等低流动性币插针** | 🟡 中 | 低（黑名单/流动性过滤） |
| 8 | **EV 模型冷启动无参考价值** | 🟡 中 | 高（需积累样本） |

### 7.2 具体改进方案

#### 改进 1: TP/SL 窄止盈策略（最高优先）

```
TP = 1.5%（固定，配合快速退出）
SL = 1.2%（RR ≈ 1.25:1）
最大持仓 = 45 分钟（超时强制平仓）
```

**理论期望值**（假设胜率 60%，基于 1-2% TP 桶实测）:
```
EV = 0.60 × 1.5% × 0.85(实现率) - 0.40 × 1.2% × 1.0 - 0.15%(成本)
   = 0.765% - 0.48% - 0.15%
   = +0.135% / 笔
```
10x 杠杆下 = +1.35% 保证金收益 / 笔。每天 2-3 笔 → **日化 2.7-4%**（理论值，实际打折扣）。

#### 改进 2: 禁用 ai_reverse + liq_magnet 反转开仓

从数据看，这两个功能合计亏 -7.03（占总亏损 33%），禁用后直接减亏。

#### 改进 3: ROI 时间衰减表（借鉴 Freqtrade）

```
0-15min:  TP = 2.0%
15-30min: TP = 1.0%
30-45min: TP = 0.5%
45min+:   强制平仓（不论盈亏）
```

这确保短线快速退出，不让亏损仓位拖延。

#### 改进 4: 流动性过滤

排除日成交量 < $50M 的币种（如 CHIP）。只在 BTC/ETH/SOL/BNB 等高流动性品种交易短线。

#### 改进 5: 确保订单流因子稳定

修复 `inject_orderflow_for_factors` 的 DB 连接问题，让 CVD/OI/Taker 因子稳定参与决策。

## 8. 每日 2% 目标的可行性分析

### 8.1 数学分析

| 参数 | 值 |
|------|-----|
| 账户权益 | $483 |
| 杠杆 | 10x |
| 仓位比例 | 30%（$145 保证金，$1450 名义） |
| 每日目标 | 2% × $483 = **$9.66** |

### 8.2 需要的交易表现

假设改进后参数: TP=1.5%, SL=1.2%, 胜率=55%, 每日 3 笔:

```
每笔期望 = 0.55 × 1.5% - 0.45 × 1.2% - 0.15%(成本)
         = 0.825% - 0.54% - 0.15%
         = +0.135%（名义仓位）
10x → +1.35%（保证金）
$483 × 30% × 1.35% = $1.95 / 笔
3笔 → $5.86 / 天 → 1.21% / 天
```

**结论**: 在 55% 胜率 + 1.5%/1.2% TP/SL + 每日 3 笔的条件下，**日化约 1.2%**，接近但未达 2%。

### 8.3 达到 2% 需要的条件

| 调节方向 | 效果 |
|---------|------|
| 胜率提到 60% | 日化 → 1.8% |
| 每日 4 笔 | 日化 → 1.6% |
| 仓位提到 40% | 日化 → 1.6% |
| 全部叠加 | 日化 → **2.4%** |

**结论**: 2%/天在理论上可达，但需要 **60%+ 胜率 + 4 笔/天 + 40% 仓位**同时满足。这需要因子精度大幅提升。更现实的目标是 **日化 0.5-1.5%**。

### 8.4 风险提示

- 55% 胜率在当前因子体系下尚未验证（当前 41.6%）
- 高频交易（4+ 笔/天）需要信号频率提升，当前受 EV 门控限制
- 加密市场的周末/假期流动性下降会恶化表现
- 连续亏损日（drawdown）的心理和资金压力
