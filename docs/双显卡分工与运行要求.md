### 运行要求（单卡口径）

1. 训练显存预算 ≤4GB（余量给桌面与 CUDA context）
2. GPU 训练任务总串行：`resource_guard.gpu_training_operation` 全局互斥锁（新增，非阻塞）——ML 深度模型重训（`activation_service._run_deep_for_symbol`）与 DRL 训练（`rl_optimizer.train`）同一时刻只允许一个持有 GPU，被占用方跳过本次、下轮周期再试；热路径守卫 `guard_training_operation` 原机制不变
3. 深度模型 device 策略：`ML_TRAIN_DEVICE=auto`（cuda:0 可用且显存 ≥2GB 才用，否则 cpu；训练中 OOM 捕获 → 自动降级 CPU 重训）；推理 `ML_INFER_DEVICE=auto`（推理后立即回 CPU 释放显存）
4. DRL 训练 `DRL_DEVICE=cuda:0`（小网络 <1GB）
5. gpu_guard 巡检：显存下限告警 512MB → 1024MB（深度模型/DRL 训练保底余量）
6. RAG 嵌入保持 CPU，不与训练争显存（双卡后移 GPU 1）

### .env 配置（已写入）

```ini
# --- 2026-08-09 单卡 GPU 训练配置（双卡阶段仅需改值，分卡走显式 device） ---
DRL_DEVICE=cuda:0
ML_TRAIN_DEVICE=auto
ML_INFER_DEVICE=auto
ML_DEEP_MODEL_ENABLED=true
LEARNING_LOOP_ENABLED=true
DRL_SHADOW_MODE=true
DRL_RETRAIN_AUTO=true
```

分卡原则：后端不设 CUDA_VISIBLE_DEVICES（两卡可见），分卡走代码显式 device——因为 drl_train_job 是后端进程内线程，环境变量无法对线程分卡。单卡阶段已把 device 参数位全部预留（rl_optimizer.train / PyTorchGRUModel._resolve_device），双卡阶段只需改 .env 值。

### B. DRL 决策链路（2026-06-11 下线 → 2026-08-09 恢复）

**下线原因**：1722 条影子预测 is_correct 从未回填 → 准确率恒 0 → 误触发重训。

**本次修复（先修后开）**：
1. 新增 `backend/services/rl/drl_performance_backfill.py`：
   - `backfill_pending()`：预测后 5 根 1h bar 落定，用同期 K 线收益回填 actual_direction/actual_pnl/is_correct（hold 预测不计入准确率；无 K 线/未到验证期跳过）
   - `accuracy_summary()`：近 7 天回填率 + 方向准确率统计
   - **2026-08-09 验证期修复（2 处）**：① `crypto_klines.timestamp` 为 epoch 秒（Integer），`_fwd_return_at` 原按 datetime 处理会抛 AttributeError——已统一转 naive UTC 再比较；② 回填查询补 `actual_direction IS NULL` 条件，防止已回填的 hold 记录（is_correct 保持 NULL）在下次 tick 被重复处理计数（幂等性）
2. `system_coordinator._should_retrain_drl` 恢复（原恒 False）：判定样本 ≥30、回填率 ≥80%、准确率 >0.52 才触发；<0.45 暂停；叠加 2h 冷却
3. learning_loop `_do_outcome_batch` 尾部接入回填兜底（每 5min 同频，extra.drl_backfilled 计数）
4. 开关（.env）：`DRL_SHADOW_MODE=true`（shadow 采样重建统计，不影响决策）；`DRL_RETRAIN_AUTO=true`（coordinator 触发后允许自动训练）；`ENABLE_DRL_INTEGRATION=false`（**保持**——shadow 采集 1-2 周、准确率达标后再灰度接管）

**Shadow 语义**（system_coordinator P1-fix）：DRL_SHADOW_MODE=true 时无论 integration 开关，都构建 observation 并调用模型/momentum baseline 采样，返回 disabled 建议不影响决策。
