# 混合打分中心 × AI选币子系统 —— 实际结合分析

日期：2026-09-17 ｜ 性质：集成映射分析（实证）
输入：《混合打分中心_双通道证据融合_论文驱动设计_2026-09-17.md》（ADR-23 评审稿）+ 本仓库 AI 选币子系统实测
核心判断：**混合打分中心在本项目的落点就是 AI 选币子系统的打分层**；该子系统比外部设计预想的完整得多
（IC 加权、相关性去重、LLM 组合决策、ROI 问责闭环都已存在），但也有明确的断点和一次真实的降级史——
这些决定了双通道架构的正确接入方式。

---

## 0. 结论（TL;DR）

1. **对应关系成立**：混合打分中心 = AI 选币的打分核心。通道A（数值排序）↔ `coin_rank` 引擎，
   通道B（LLM 打分器）↔ 三层 AI 审核 + `llm_compose`，融合层 ↔ composite 公式 + IC 加权，
   影子通道 ↔ ROI 问责与降级/复位机制，消融矩阵 ↔ `auto_coin_selections.factor_snapshot_json + hit_24h` 反馈数据。
2. **现状比设计文档假设的好**：S2-9 已落地"IC 加权 + 组合相关性去重 + LLM 组合决策"三件
   （`coin_rank/ic_weights.py`），mid 档选币输入本就是分析师 thesis（midlong_board approve，min_conf=0.4）——
   "thesis 信号数值化"已存在一半。
3. **最大的一个断点**：因子库→选币的接线是"软匹配"而非"打分"——`factor_soft` 调
   `summarize_exposure`（ACTIVE 因子 → match_score∈[-1,1] 软融合），且总开关
   `FEATURE_FACTOR_EXPOSURE_ENABLED` **默认 false**。生产因子库实质上没有参与选币排序。
4. **接入纪律由降级史决定**：选币曾在 W33/W34 连续两周负 ROI 被自动降级关闭（2026-08-28 落地机制，
   2026-09-14 复位，今日已恢复注入）。混合打分中心必须**影子先行**：并行打分不接管注入，
   攒 hit_24h/IC 证据，走既有 ROI 问责门晋级——不另造评审流程。

### 1.3 打分公式现状（score.py）

`composite = clip01(base × decay)`，其中 base = CS/TS 动量 + 流动性分 + 图信号软融合
（`(1−w)·base + w·graph_comp`），`factor_soft` 以 explain 形式附带（受开关控制）；
IC 加权作用在因子维度层（ic_weights）。**没有**：LTR 排序目标、regime gate、
通道级 James-Stein 融合、TabPFN/深度模型对照。

## 3. 真正要建的五件事（按依赖序）

1. **打通因子通道（最高优先）**：开 `FEATURE_FACTOR_EXPOSURE_ENABLED` 之外，把 `factor_soft` 的
   单币软匹配升级为**横截面排序打分**——通道A 的 LTR 模型（LightGBM-lambdarank，训练于 L1 采集宇宙
   200+ 币面板）输出 hybrid_score_A，进 composite 的融合位。这一步是"混合"二字从口号变现实的位置。
2. **证据包升级通道B**：三层 AI 审核与 `llm_compose` 的输入从"ticker 表"扩为证据包
   （因子暴露摘要 + thesis/辩论记录 + 记忆库该类 thesis 历史准确率 + 舆情事件精评，evidence_refs 锚定）。
   LLM 输出保留 conf 语义（0=拒绝注入）——与 08-26 重设计的"0.5 假中性根治"纪律连续。
3. **融合层升级**：composite 位替换为 regime-gated 双通道融合（James-Stein 收缩滚动 IC 加权）；
   维度级 ic_weights 保留（两层自适应不冲突：维度层管因子权重，通道层管 A/B 权重）。
4. **影子模式开关**：`HYBRID_SCORE_MODE=shadow|fusion`——shadow 期 hybrid_score 只落盘只统计
   hit_24h/IC，不接管注入决策；晋级条件走既有 ROI 问责门（攒 2 周对比证据），复用
   `auto_coin_roi` 的报告与降级机制，不另造评审流程。
5. **消融报告**：基于 `auto_coin_selections.factor_snapshot_json` 扩展记录档位标签
   （纯因子/+thesis/+LLM综合器/全开），四档 × 市场状态出周报——挂进现有周一 08:00 周报任务。

## 4. 与既有文档的关系

- **ADR-21 五 agent 闭环**（因子研究部）是通道A的上游供血者：factors_lab 晋级的 LLM alpha 因子
  经同一 `exposure_service` 通道进入选币打分——影子通道的 hit_24h 数据同时回馈因子晋级评审，
  两个 ADR 共享同一条证据流。
- **ADR-23 混合打分中心**（本文系列）在选币子系统内的落地版本 = §3 五件事；
  宇宙口径沿用 §2.1 四层结构（L1 训练 / L2+L3 部署与证据包覆盖）。
- 里程碑对齐原 HC-1~HC-4，但 HC-1 的落点明确为 coin_rank 集成（非独立新建模块），
  HC-3 增加"影子 2 周证据门"为晋级前置。

## 5. 风险补充（选币特有）

| 风险 | 对策 |
|---|---|
| 选币刚从降级复位（9-14），再引入大改易复发信任问题 | 影子模式硬隔离（只打分不接管）；晋级走既有 ROI 门 |
| L1 面板训练的 LTR 对 L3 注入层分布漂移（小币新币） | 注入层特征缺失时回退现有 composite（fail-safe 先例：emergency_fallback 标记） |
| hit_24h 反馈稀疏（IC 加权样本少） | ic_weights 已有静态权重兜底先例；影子期同步积累 factor_snapshot |
| LLM 审核成本随证据包膨胀 | 证据包只覆盖 L2+L3（≈23 币）；token 纳入 `llm_quota_usage` 计量 |

### 6.2 真实影子轮结果（2026-09-17）

30 币干净宇宙，15.7s；regime=unknown → 双通道 50/50；融合头部：ZEC/ETH/BTC/SOL/BNB。
LLM 评语实际消费了证据包（例：ZEC "排名1，5/20日动量极强，但短期反转与RSI超买提示回调风险"）。
通道B失败纪律生效路径验证：无配置→缺席（单测），不出 0.5 假中性。

### 6.3 实测发现（重要）

1. **宇宙污染比 08-26 认知的更深**：`symbol_catalog` 各所均含代币化股票/指数永续
   （SKHYNIX/SNDK/SOXL/MU/DRAM/TAC 及变体 SKHY/SNXX…），`crypto_klines.market` 列恒为
   'CRYPTO' 无结构判别。首训 top60 混入 4 只股票。已修：**正向策展白名单（板块映射56 ∪
   流动性偏好30 ∪ 核心观察18 ∪ env 扩展）∩ catalog − 股票黑名单**。⚠️ 现有选币子系统
   的 `list_universe_symbols` catalog 过滤同样含股票——建议另行整改。
2. **1d 横截面信号诚实结论：弱**。清洗宇宙（40币×403日）+ 12 特征：LTR valid/test RankIC
   在 ±0.04 噪声区反号，best_iteration=5。已上**模型稳定性门**（valid/test 双正 + best_iter≥20
   才上岗），当前走 IC 加权兜底。这正是影子模式存在的意义——用 hit_24h 实证积累，不硬上弱模型。
3. L1 200+ 扩容的前置：需外部 crypto 资产主数据做正向白名单（策展表只有 ~75 币）。

### 6.4 运维口径

- 触发：选币扫描自动（30min 节流）；手动 `POST /api/coin-select/hybrid/run`；
- **自动调度（main.py cron 已注册）**：每日 08:05 命中回填（`hybrid_score_evaluate_daily`）、
  周一 08:10 消融周报（`hybrid_score_report_weekly`）；off 模式自动跳过；
- 状态：`GET /api/coin-select/hybrid/status`；手动回填：`POST /hybrid/evaluate`；周报：`GET /hybrid/report`；
- 重训：`python -m backend.services.hybrid_scoring.train_cli --universe 60`；
- 晋级 fusion：影子期滚动 RankIC ≥ 0.05 → 提交 ROI 问责门人工复核 → `HYBRID_SCORE_MODE=fusion`
  （消费位权重封顶 0.3）。**当前默认 shadow，选币行为零变化。**
