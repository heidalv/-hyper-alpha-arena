# 混合打分中心 × AI选币 —— 实施设计（HC-v1）

日期：2026-09-17 ｜ 依据：《混合打分中心与AI选币集成分析_2026-09-17.md》§3 五件事
目标：让 AI 选币的打分层真正带上"生产因子 + LLM 证据"双通道，并以影子模式安全接入现有选币循环。

---

## 1. 新增包：`backend/services/hybrid_scoring/`

| 模块 | 职责 | 关键接口 |
|---|---|---|
| `config.py` | 开关与路径（全部 env 可调） | `mode()` → off/shadow/fusion（默认 **shadow**） |
| `kpanel.py` | K线面板装载（alpha_market Postgres 直连，`MARKET_DATABASE_URL`） | `load_klines(symbol, period, bars)` / `top_liquid_symbols(n, days)` |
| `features.py` | 特征工程（formula_ops 同源算子，防前视：t 时刻只用 ≤t 数据） | `FEATURES`（10 维）/ `build_panel(symbols, period)` / `live_features(symbol)` |
| `ltr.py` | 通道A模型：LightGBM lambdarank（时间切分 train/valid/test）+ IC 加权兜底 | `train(...)` → 落盘模型+指标 / `score(rows)` / `ic_weight_score(rows)` |
| `channel_a.py` | 数值通道编排 | `run(symbols) -> {sym: {score, rank, features, backend}}` |
| `evidence.py` | 证据包构建（因子摘要 + thesis + 命中统计，evidence_refs 锚定，≤4k token） | `build_packs(channel_a_rows)` / `to_prompt(pack)` |
| `channel_b.py` | LLM 综合器（租户级配置，批量单次调用；**失败→整通道缺席，绝不出 0.5 假中性**） | `run(packs) -> {sym: {score, confidence, rationale}}` |
| `fusion.py` | 双通道融合：横截面秩归一 + James-Stein 收缩 + regime gate | `fuse(a, b, ic_stats) -> {sym: hybrid}` |
| `service.py` | 影子编排：周期运行/节流/落盘/命中评估/状态 | `maybe_shadow_hook(symbols)`（选币循环钩子）/ `run_cycle()` / `evaluate_hits()` / `status()` |
| `report.py` | 消融周报（臂 × regime × 周：IC/命中率/头部价差） | `weekly_report()` |
| `train_cli.py` | 命令行训练入口 | `python -m backend.services.hybrid_scoring.train_cli` |

数据落盘（全部增量，不碰主库 schema）：`backend/data/hybrid_scoring/`：
`ltr_model.txt`（模型）+ `model_meta.json`（特征表+指标）+ `latest.json`（最近一轮全量打分）
+ `score_log.jsonl`（逐轮逐币：A/A2/A3 三臂分数）+ `ic_stats.json`（滚动 IC/权重证据）+ `hybrid_ablation_report.json`。

## 2. 数据流

```
auto_coin_selector._scan_candidates_via_rank（Phase 1 粗分完成）
  └─ maybe_shadow_hook(top候选)      ← 节流(默认30min)+后台线程，零阻塞零影响
       └─ run_cycle:
            kpanel.top_liquid_symbols(30)   ← L2+L3 部署口径（也可用传入候选）
            channel_a.run ── LTR 模型（无模型/过期 → IC加权兜底 → 都无 → 均匀分）
            evidence.build_packs ← 通道A特征 + ai_coin_unified(mid=thesis) + score_log 命中统计
            channel_b.run ────── 单次批量 LLM（租户配置；失败→缺席）
            fusion.fuse ──────── James-Stein(λ=IC方差驱动) + regime gate
            落盘 latest.json + score_log.jsonl（A0/A2/A3 三臂同轮记录）
  （≥24h 后）evaluate_hits：1h K线算 24h 前瞻收益 → 回填 outcome + 更新 ic_stats
  （周一）report.weekly_report：臂×regime×周 的 IC/命中率消融表
```

## 3. 关键设计决策

1. **特征与标签防前视**：特征 t 时刻只用 ≤t 的 OHLCV（formula_ops 滚动算子天然满足）；标签 = t+1 收益的
   横截面十分位（lambdarank 的 label_gain 0..9）；训练集按**日期**切块（70/15/15），禁随机行分割。
2. **通道B纪律**（继承 08-26 重设计）：LLM 失败/超时/解析失败 → 通道B本轮缺席（融合层自动退化为纯A），
   不存在 0.5 假中性；输出 score∈[0,10] 归一后用，confidence 仅供展示与审计。
3. **融合公式**：`w = (1-λ)·w_ic + λ·w_prior`，`w_prior=(0.5,0.5)`，λ = min(1, k·std(IC_滚动))；
   regime gate：趋势态偏A、震荡态均衡、高波/未知态强收缩。IC 统计不足 20 个有效日 → 全收缩到先验。
4. **fusion 消费位**（晋级后才生效）：`HYBRID_SCORE_MODE=fusion` 且影子期滚动 IC 达标时，
   候选分以 `score=(1-w)·composite + w·hybrid百分位`，**w 封顶 0.3**；晋级条件与流程走既有 ROI 问责门，
   本实现不新增评审机制。
5. **宇宙**：训练 = L1 采集宇宙按流动性取 top（≤80，1d 面板）；部署/证据包 = 传入候选或 top30（L2+L3 口径）。
6. **RLS 规避**：选币打分链只读 alpha_market（无 RLS）+ 本地 jsonl；不直连 alpha_arena 业务库。

## 5. 验收

1. 单测（合成数据，无 LLM）：面板无前视（特征与标签时间隔离断言）；植入信号的 LTR 训练 valid RankIC>0.15；
   James-Stein 两端行为；通道B解析与失败缺席；影子全链路落盘；节流生效；周报产出。
2. 真实训练：1d 面板（top 流动币）训练，test RankIC 与 NDCG 落盘 model_meta.json。
3. 真实影子轮：run_cycle 产出 latest.json（含证据包与 LLM 评分），score_log 追加，三臂同轮在册。
4. 现有选币行为零变化（默认 shadow；钩子异常静默）。
