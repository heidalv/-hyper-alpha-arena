## 0. 结论先行（三条硬结论 + 三个手术点）

**硬结论**
1. **赚小大失在"净口径"上铁证如山**：近 30 天 mid 180 笔平仓，净胜 78/负 102（WR 43.3%），净盈亏比 **+1.90 / −4.22 = 0.45**；全量 60 天 gross 口径 +6.60/−5.04（盈亏比 1.31，仍为负期望）。**不是入场全错，是出场把"赢"变"亏"**：65 笔 `breakeven_tp` 净 +540（+8.31/笔）是最大盈利源，53 笔 `sl` 净 −431（−8.13/笔）是最大亏损源——同一批入场，命运由出场方式决定。
2. **系统当前是"负 Kelly"**：f* = p − q/b，代入 p=0.40、b=0.45 ⇒ **f* ≈ −0.9 < 0**——任何仓位都是负期望，与"加大资金使用率"直接冲突。p=0.40 转正需要 **b ≥ 1.5**（赢均 ≥6.3 USD 或亏均 ≤1.27 USD）（Thorp 2006，`docs/论文调研_20260929.md` 二/四节）。**反事实回放实测（§5.6）证明：单独换出场规则只能把 mid 净损失减 37%（−396.79→−249.11，b 0.93→0.90~1.1）；叠加入场过滤（BTC 1d 动量闸 + 剔微盘币）减损 82%（→−45.99，b=1.12）；翻正必须靠入场边际本身（§5.3 错价/显著性 + bear regime 空头侧）——"出场+过滤=止血，入场边际=造血"。**
3. **灾难日不是市场暴跌日，是"账面全多头 × 山寨 beta 失血"日**：09-16 mid 单日 −142.53（10 笔**全部做多**），当日 BTC +0.55%；09-28 mid −79.04（5 笔全多头），当日 BTC −1.24%。系统在 BTC 平盘的日子里被 ASTER/VIRTUAL/SOL 等小币拖死。
4. **账户已亏 −9.8%**（5000 → 4511.89，realized −352.21 + 手续费 111.92 + 浮亏 −23.98），session 最大回撤 61%。**在负期望结构修复之前扩大仓位 = 加速失血**，所以"资金使用率太低"必须放在"盈亏比修复"之后解决（§11 顺序）。

**三个手术点（对应 §3.4/§4/§7）**
- 手术 A：出场改为**最优障碍**（1R 锁本 → 2R 放利润 → Chandelier 尾随），止损按**波动率定价**（σ̂ 乘数），废除"SL 地板让位于层上限"（证据：SL 平仓单平均 trough −5.93，64% 曾浮盈）。**注意（§5.6 反事实回放）：手术 A 单独只减损 37%，不翻正——它是止血，不是造血。**
- 手术 B：增加**账面级 regime + 入场过滤**（BTC 1d 动量闸 + 剔微盘币 + 全多头日禁新多），把 09-16 这类日子从 −142 变成 −30 以内（回放实测 F1+F2 合计减损 82%）。
- 手术 C：**策略工厂治理**——AI 自动策略必须参数受界（SL/TP 来自标定网格，不是 LLM 拍脑袋）+ 强制 learning_enabled。证据：最佳 mid 策略 `tpl_mid_range_444876`（UNI，SL 2.4%/TP 8%，学习开）= +30.65；最差 `auto_efd68a88ca`（VIRTUAL，SL 5.1%/TP 20.8%，学习关）= −66.20。
- 手术 D（新增，造血）：**入场边际本身**——§5.3 错价/显著性三重检验 + bear regime 用空头侧表达。回放证明 A+B 都只是止血，翻正的唯一来源是入场信号在 24-48h 上的正漂移。

## 4. 为什么"被广泛使用的模型"基本是亏钱（含本仓实测铁证）

1. **同质化拥挤**（v1 论证保留）：公共指标人人同向，手续费面前零和必负。
2. **把 beta 当 alpha**：`min_roi_decay` 反事实 55% 被市场 beta 解释（台账 §96）。
3. **无停止规则**：公共模型只给"买/卖"，不给"这笔在什么条件下必须走"。本仓数据：出场方式决定 80% 盈亏（§2.1）。
4. **AI 策略工厂 = 公共模型的工业化放大器**：`ai_strategies` 共 **3394 个，97% 已归档**，57 active。最差案例 `auto_efd68a88ca`（AI_中线_VIRTUAL）：**同一币 VIRTUAL 连开 19 笔 long，净 −66.20**，参数 SL 5.1%/TP 20.8%（LLM 拍脑袋，从未触及 TP），learning 关。对比最佳案例 `tpl_mid_range_444876`（[range] UNI mid）：SL 2.4%/TP 8%，learning 开，31 笔 +30.65。**同样的模板族（range），UNI 开学习赚 30.65，SOL 关学习亏 24.68。**
5. **参数过拟合**：本仓 WFO/PBO/DSR/CSCV 工具链齐全（`backtest_engine/walk_forward.py`、`overfitting_metrics.py`、`factor_engine/dsr_pbo.py`、`purge_pipeline.py`、`midlong_walk_forward_hook.py`）——这些闸门管住了因子管线，**却没有管住交易执行层**：策略工厂的 SL/TP、软出场阈值、滚动规则从未进过 WFO 网格。

## 5. 底层数学模型（五层，逐层给规格）

### 5.1 数据生成过程（jump-diffusion + HMM regime）——只做风险定价，不做价格预测
```
d log P_t = μ(R_t) dt + σ(R_t) dW_t + J_t dN_t
R_t ∈ {trend, chop, crash}，状态转移矩阵 A（周度 EM 重估）
J_t ~ 非对称双指数（跳幅均值为 0 时不设，暴涨暴跌对应厚尾）
```
**在线估计（全部用已有数据）**：
- `σ̂_t`：1h 收益 EWMA（λ=0.94），逐币；**升级为跳稳健估计（bipower variation，Cont & Tankov 2004）**——否则跳跃被吸收进 σ̂，会削弱 jump 检测功效（Scaillet et al. 2020 教训）；
- `R_t`：HMM 滤波，观测 = {σ̂ 相对水平、趋势 ADX、1d/4h 动量}——**注意本仓 `market_regime_history` 表为空（0 行），`macro_regime_states`（alpha_analytics）有 2036 行宏观 regime**，本模型用后者做先验，不复用空表；
- jump 判定：|ΔlogP| > 3.5σ̂（单根 K 线）+ **状态确认/FDR 防伪跳**（加密数据固定 1% 显著水平会产生大量伪跳，Scaillet 用 FDR 校正）；跳到达强聚簇 ⇒ **λ 状态依赖（crash 状态 λ↑）**，跳幅用 Kou 左偏双指数而非对称正态；波动率自身可跳（Chaim & Laurini 2018）⇒ crash 后 σ̂ 持续上修、止损距离自然变宽。

用途只有两个（不预测方向）：
- **止损距离** `d = k·σ̂_t`（k ∈ [1.5, 2.5]，由 §5.4 标定），**废除固定 3% 与"SL 地板让位于层上限"**；
- **名义仓位** = 风险预算 / d（vol targeting，§5.5）。

### 5.3 显著性检验（"固定策略"的筛选器）
```
δ(X) = E[r_{t+h} | X] − E[r_{t+h}]，t = δ/se(δ)
准入：① 样本外 |t|≥2；② 扣费+滑点后 δ>0；③ 与在库信号 |corr|<0.6
```
数据源直接可用：`smart_money_moves` 已带 ret_4h/ret_24h；因子侧复用 `factor_backtest_scorer._walk_forward_backtest` + DSR/PBO 闸门。**不通过即退役**（与 purge_pipeline 语义一致）。

**预验证（本仓 255 行实测，样本小但方向一致）**：smart_money `open short` 后 24h 平均 −0.65%、`decrease short`（回补空头）后 24h 平均 **−2.85%**（n=7）、`open long` 后 24h −0.10%（反向信号）——聪明钱动作在 4h/24h 前向收益上存在可检验的结构，§5.3 的三重检验正好把它变成正式信号而非轶事。

**P3 预研实测（301 笔 mid 入场 × 11 特征，`docs/P3_造血信号预研_20260929.md`）**：
- ✅ 晋升：`btc_1d_mom`（t=4.00，OOS t=3.57）、`funding_z7d`（t=1.32，OOS 同向）——二者正交（−0.04），等权边际分数 m 的三分桶 24h 前向收益单调：低 −0.47% → 中 +1.11% → 高 +2.28%（净成本）。
- ❌ 退役：`ret_24h`（train t=3.10 但 OOS **反向** −2.29，追涨陷阱）、`oi_chg24_pct`（OOS 反向）。
- ⏸ 样本不足：taker_imb_1h（n=68）、liq_imb_4h（n=52）——历史 <40 天，4-8 周后复验再定权重。
- **联合回放**：高 m ∩ price≥$1 ∩ 仅做多（n=48）→ 每笔 −0.00（WR 45.8%、盈亏比 1.18），从全样本 −1.06 全部止血；翻正的最后一步 = bear regime 空头表达。

### 5.4 出场 = 最优障碍问题（手术 A 的完整规格）
```
max_{sl, tp1, r1, tp2, τ}  ĝ = (1/n) Σ log(1 + f·r_i)      —— Kelly 口径，天然惩罚"赚小大失"
约束：
  sl ∈ [1.2σ̂, 3σ̂]                       （止损在赢家逆行与结构位之间；对标：最佳策略 SL 2.4%）
  tp1 = 1R（平 50%，SL 移至成本）         （锁本；对标 breakeven_tp 每笔 +8.31 是最大盈利源）
  tp2 = 2R~3R（平 30%，余 20% 跟 Chandelier 3σ̂）  （对标 MFE p90 = +12 USD，让利润跑到该处）
  τ = 时间止损 {mid 24h, long 不设}       （对标 mid 赢单中位 13.4h；禁止"死扛"）
标定器：本仓 WFO 引擎 + 轮110 的 MAE/MFE 网格方法学推广（sl×tp1×tp2×τ 网格，purged CV，每周滚动）；
出场裁决唯一化：同一时刻只允许一个模块平仓（废除 sl/decay/trailing/thesis 多头共管的现状）。
```
数据事实直接进入约束：**SL 平仓单 64% 曾浮盈、平均 trough −5.93** ⇒ 新 SL 必须 ≤ 2σ̂ 并禁止地板抬升；**mid 曾浮盈单的中位实现率 −0.17** ⇒ tp1 锁本档必须无条件先平一半。

**反事实回放实测（§5.6，`docs/出场反事实回放_20260929.md`）——对 §5.4 的证伪与修正**：
- 12 组障碍网格在 60 天真实路径上**全部负期望**：最优 k=1.0·r2=2·τ=24h 净 −249.11（每笔 −1.06）、b=0.90，比实际（−396.79、b=0.93）好 37% 但**不翻正**。⇒ "出场手术单独把 b 提到 ≥1.5"的原假设被推翻（与 Carr & Jarrow 1990 一致：止损不创造 alpha）。
- k 越紧越好（k=1.0 > 1.5 > 2.0，方向与赢家模板 SL 2.4% 一致）；τ 与 r2 是平坦参数（τ 24/48、r2 2/3 差异 <2%）。
- **长线车道反向验证**：ATR 阶梯在 long 上伤害大于保护（−107.74 → −122~−138）——长线盈利来自跨日趋势，止损尺度应是日线级；长线保留 trend_e1+breakeven_tp，不套用 mid 手术。

**文献支撑（见 `docs/论文调研_20260929.md` 二/四节）**：
- Kaminski & Lo 2014：**止损有效性是 regime 依赖的**——动量/regime 持续时止损增值，均值回归/震荡市有害 ⇒ §5.1 的 chop 状态收紧或禁用 k×σ 止损，改由时间止损兜底（§6 响应表已列）。
- **TP/SL 必须联合定价**（Leung & Li 2015：止损越紧⇒最优止盈越低，单调联动）⇒ 标定网格把 (sl, tp1, tp2, τ) 作为**一个联合优化问题**求解（Helmes 2004 同构），禁止分开拍脑袋；Chandelier 乘数 k 做**区域选择**并报告整区间稳健性（Fonseca 2026：k∈[3.5,7.0] CAGR 平台、M_eff≈1.09，单点精调 PBO≈0.93 必过拟合）。
- **出场与入场 alpha 类型匹配**（Carr & Jarrow 1990：止损不创造优势；Henderson 2012：优势消失即认赔）⇒ P1 前置一步"mid 信号趋势 vs 反转分类"，并增加**信号失效即平仓**中间条件（不只三条价格线）。
- Henderson-Hobson-Tse 2018（CPT 最优停止解 = 硬止损 + 右偏长尾盈利分布）——§5.4 结构有行为最优理论背书；**锁本后禁止任何规则破坏盈利分布右偏性**。
- Kelly 系（Thorp 2006；MacLean-Thorp-Ziemba 2011；Browne 2000）：回撤约束下最优策略恰是 fractional Kelly；half-Kelly 保留 75% 增长率、方差降为 1/4、触及半仓概率 12.5%（全 Kelly 为 50%）。**ĝ 的估计误差应驱动下注收缩**（over-bet 是唯一致命失败模式）⇒ 标定器输出 ĝ 的 bootstrap 标准误，样本短/试验多时自动向 1/4 Kelly 收缩。
- Harvey et al. 2018 / Barroso & Santa-Clara 2015：vol targeting 的第一收益是左尾/灾难日防御——与 §5.5 同向叠加。

### 5.5 仓位 = 风险预算（一次定价，无乘子链）
```
notional_i = equity × risk_pct(lane) / d_i      d_i = k·σ̂_i（§5.1）
mid: risk_pct = 0.5%    long: risk_pct = 1.0%
上限：单币权重 ≤ 30% 总保证金；单仓保证金 ≤ 8% 权益；总保证金 ∈ [30%, 50%]（利用率目标带）
杠杆：固定不动（BTC/ETH 5×，其余 4×——用户口径）
```
- 对标：当前每仓保证金 80（1.8% 权益）、总占用 6.5%。新定价下 mid 每仓保证金 ≈ 0.5%×4512/(2.4%×4) ≈ 235（5.2% 权益），5~8 仓并发 = 30~40% 利用率。
- **顺序铁律：先过 §11 P1-P3 的门禁（联合回放盈亏比 ≥1.5 且 OOS 正），才允许把利用率从 6.5% 抬到 30%+**。负期望结构里加钱 = 加速失血（当前 −9.8% 就是这么来的）。
- 可复用资产（避免重造）：`mlto/sizing_overlay.py::vol_target_scale`（vol 目标缩放已存在）、`position_construction.py` 与 `trend_core.py::size_one`（vol_target/realized_vol 定价）、`research/trend_sleeve_backtest.py`（Chandelier 尾随回测原型）。缺口：bipower/跳稳健 σ̂ 与 Lee-Mykland 类跳检验**尚不存在**（论文调研 §1 建议，见 `docs/论文调研_20260929.md`）。

## 6. 暴涨暴跌与账面压力：机械响应表（手术 B 完整规格）
