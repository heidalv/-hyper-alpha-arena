# 数据库备份与恢复手册

> 关联：整改项 R2（备份自动化）｜脚本：`scripts/db_backup.ps1`
> 4 库：`alpha_arena`（主）/ `alpha_market`（行情）/ `alpha_analytics`（分析）/ `alpha_snapshots`（快照）

## 1. 前置条件（一次性）

备份账号必须能读取全部表。应用库启用了**租户 RLS**（`account_asset_snapshots` 等表带行级安全策略），
普通应用账号（如 `laobao`，无 `BYPASSRLS`）执行 `pg_dump` 会报
`查询将被表 ... 的行级安全性策略所影响`。

**二选一（需 PostgreSQL 超级用户执行）：**

```sql
-- 方案 A（最简单）：给应用账号加 BYPASSRLS
--   注意：应用代码本身按 tenant_id 过滤（README 租户隔离），RLS 是纵深防御；
--   BYPASSRLS 只影响「该账号连库时的 RLS 豁免」，不改变应用内过滤逻辑。
ALTER ROLE laobao BYPASSRLS;

-- 方案 B（更严格）：专用备份角色
CREATE ROLE arena_backup LOGIN PASSWORD '生成一个强密码' BYPASSRLS;
GRANT CONNECT ON DATABASE alpha_arena, alpha_market, alpha_analytics, alpha_snapshots TO arena_backup;
-- 对每个库：
-- \c alpha_arena
GRANT USAGE ON SCHEMA public TO arena_backup;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO arena_backup;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO arena_backup;
```

选方案 B 时，在 `.env` 增加 `BACKUP_DATABASE_URL=postgresql://arena_backup:<密码>@localhost:5432/alpha_arena`
（脚本会优先使用它解析账号；当前脚本读取 4 个业务 URL 的账号，需相应调整）。

## 2. 每日备份

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\db_backup.ps1
```

- 输出：`postgres_backup\<yyyyMMdd>\<库名>.dump`（`-Fc` 自定义格式）
- 保留：7 天（`-RetentionDays` 可调）；每周日额外 `postgres_backup\globals\globals_<日期>.sql`
- 日志：`logs/db_backup.log`
- 任务计划（每日 02:00，脚本验证通过后创建）：

```powershell
schtasks /Create /TN "AlphaArena-DailyDBBackup" /SC DAILY /ST 02:00 `
  /TR "powershell -NoProfile -ExecutionPolicy Bypass -File D:\001Alpha\Hyper-Alpha-Arena\scripts\db_backup.ps1"
```

## 3. 恢复步骤（演练用）

```powershell
# 1) 建临时恢复库（用超级用户）
psql -h localhost -U postgres -c "CREATE DATABASE alpha_arena_restore_test;"

# 2) 恢复
set PGPASSWORD=<密码>
"C:\Program Files\PostgreSQL\15\bin\pg_restore.exe" -h localhost -U laobao -d alpha_arena_restore_test --no-owner "postgres_backup\<日期>\alpha_arena.dump"

# 3) 校验行数（主表）
psql -h localhost -U laobao -d alpha_arena_restore_test -c "SELECT count(*) FROM users; SELECT count(*) FROM positions;"

# 4) 清理
psql -h localhost -U postgres -c "DROP DATABASE alpha_arena_restore_test;"
```

## 4. 每月演练清单

- [ ] 按 §3 恢复 `alpha_arena` 到临时库成功，`users`/`positions` 行数 >0
- [ ] 恢复库立即删除（避免数据泄漏面）
